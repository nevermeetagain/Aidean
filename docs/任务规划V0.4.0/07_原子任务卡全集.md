## 7.1 三级结构

- **Work Package** = 切片 S0–S9（06）；**Atomic Task** = 本表每行（可独立验证的交付）；**Execution Step** = 每卡「Execution Steps」小节（怎么做）。
- 执行者口径（用户指令）：核心任务 + 高难度任务（尤其 **全部 UI 设计与实现**）→ `Hark(主Agent)`；中等及简单任务 → `外部Agent`（发布规划后等待其完成）。**本轮只规划，实施需用户 APPROVE**（03 §3.3 C-8）。
