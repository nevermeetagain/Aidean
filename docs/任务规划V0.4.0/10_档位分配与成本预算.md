## 10.3 券制度

- opus：每切片 ≤3 次额外调用（切片前契约审 / 卡住升级 / 高风险 review）；执行档已为 opus 的卡不重复计券。
- fable：每切片 ≤1 次，仅在需要动需求或已冻结契约时启用；超出需用户批准。

## 10.4 熔断规则

同一任务连续 2 次验收失败 → 停止改代码 → 改为：重写任务书 / 升级档位 / 标记 blocked。禁止换提示词硬撞第 3 次。
