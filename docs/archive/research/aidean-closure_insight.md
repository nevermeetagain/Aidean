# 洞察（aidean-closure）

1. **项目真实状态 = "功能建设基本完成、发布工程未启动"**。建设期四模块 + SSO + admin + 评估 + API Key + 资讯 CMS 全部落码并有测试；但发布三要素（真实支付、生产部署、数据可恢复）全部未动，且身份撤销契约存在系统性缺口。
2. **最大风险不在代码而在工程管理**：84 项未提交的工作树承载了最近三轮全部交付；台账/审计/验收三方对同一事项状态口径不一（#8、#7、L1.1）；验收基线（806eba6）落后于工作树演进。若不先"固化基线 + 统一口径"，后续任何验收都缺乏分母。
3. **技术栈锁定与实现脱节是发布前必须裁决的第一类决策**：Next 14.2.5 实际 vs ADR-0001 锁 Next 15。升级是大工程（App Router 行为、缓存语义、Turbopack），不升级则需修 ADR。该决策阻塞 Q1.1/Q1.2/R1.1 整条链。
4. **资金类静态发现必须"先复现后修复"**：F1.1/F2.1/W1.x 均为静态推演，直接改代码可能修不存在的问题；隔离库复现是唯一可信路径，且复现用例本身即回归护栏。
5. **用户可见缺口（补充.txt 两批需求）已基本收口**，剩余为视觉审美用户判定、二维码真图替换、`.next-renamed-*` 清理等小尾巴，不应再占用主线资源。
6. **外部依赖是 P0 关键路径**：#5/#6（支付/微信凭据）取决于服务商资质申请周期，应立即启动申请，与内部工程并行，避免"内部全绿、外部卡壳"。
