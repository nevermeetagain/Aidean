## 0. 关键发现（影响全局）

1. **Prisma schema 已在源仓库成熟**：早期发现"无 schema.prisma"（原生 SQL 阶段）；后源已长出完整 schema（52 表/7 命名空间，100KB）+ seed。→ 已整体迁入 `prisma/schema.prisma`、`prisma/seed.ts`。
2. **多版本组件债**：11 个首页组件、重复的 DemoHeaderV5 等仍存在于源码（HomeA~V7、demo/、ladder/ 多版本）。→ 整体迁移保留（引用链自洽，构建通过）；后续清理按"一组件一版本"原则另行处理。
3. **i18n 为 stub 实现**：`useTranslations` hook 返回 key 原样。→ 已迁移，功能重做留待迭代。
4. **两处环境坑**：compose 数据卷写死 WSL2 by-uuid 路径；`transactions` 分区依赖未启用的 pg_partman。→ 见坑位表 §6。
