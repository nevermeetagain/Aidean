## 4.1 唯一源声明（V0.7.0 不新增第二份）

- **唯一源 = `docs/任务规划V0.5.0/contracts/`**（zod + TypeScript，机器可校验）：01-api、02-errors、03-identity、04-resources、05-events、06-ux-states、07-monitoring + selfcheck.ts / selfcheck-monitoring.ts + tsconfig.json。
- 落地目标：各契约在实施后以 `packages/shared/src/`（zod）为运行时唯一源（ADR-P001）；规划目录仅作冻结稿与审计参考。
- V0.7.0 **不复制** contracts：若复制，镜像将出现 V0.1/V0.2/V0.4/V0.5/V0.7 五份同名契约稿，且他线 CI（D7-04）读的是 V0.5.0 路径 → 双源。V0.6.0 已作同样处理（V0.6.0 README §二）。
- 本轮校验：`tsc -p docs/任务规划V0.5.0/contracts/tsconfig.json --noEmit` exit 0（EVD-BASELINE-V7/contracts-tsc.txt）；导出符号数：01-api 26 / 02-errors 10 / 03-identity 12 / 04-resources 4 / 05-events 6 / 06-ux-states 4 / 07-monitoring 31。
