## 3.1 复述与拆解

Aidean 是「AI 模型/工具天梯图 + 统一网关」平台：前台让用户按性能/价格/阵营比较模型与 API 站点、查看详情与历史测评、通过统一网关调用并按 ¥/M Tokens 计费；后台让管理员维护模型/价格/厂商/菜单/权限/内容与功能开关；模型源监控体系自动采集多源目录与价格变化。

- 用户：访客（看天梯/详情/资讯）、注册用户（控制台、API Key、充值、调用、收藏）。
- 管理端：admin（全部域）、moderator（只读，排除 reports，见 packages/shared/src/permissions.ts）。
- 系统边界：Aidean 主站 + 网关（3000–3100）；子平台（BotHot 3200–3300、AideanBot 3333 待 P-2）只经 OIDC 对接；外部数据源（OpenRouter/AIHubMix/Quanzil/llmtest/AA）只读采集。
- 关键词：天梯、生效价、¥/M、限时优惠、功能开关、收藏、顶栏搜索、监控源、OIDC、契约唯一源、双端一致。
