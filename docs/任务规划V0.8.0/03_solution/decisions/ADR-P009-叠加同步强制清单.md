# ADR-P009 · 叠加同步强制清单

> 版本: v0.8 | 更新: 2026-10-19 | 变更: 任务规划V0.8.0（基线 nevermeetagain/Aidean main@c2da219：镜像已叠加他线 S0–S3 源码）

- 状态：提议（随 B-0' 裁决生效；A' 下仅约束 085 的一次性回补）
- 背景：F8-02、D8-01/02/03——只叠源码导致配套工件与文档锚掉队，镜像 CI 的单测与文档两步在 c2da219 上必红。
- 决策：叠加以「整树减规划目录」为单位，而不是「源码目录白名单」；叠加后三项门禁（docs-rule、docs-facts、web 单测带占位 DATABASE_URL）必须 exit 0 才可推送。
- 后果：叠加体量变大但不再漏配套；docs/ 非规划目录在两线之间需要先合并（TASK-090 首次回灌）。
- 反证：若他线 docs/ 与镜像 docs/ 有对立改动，整树叠加会覆盖镜像侧 → 090 规定冲突两侧保留并登记。
- 关联：TASK-085、089、090；24_叠加同步与开发线裁决.md。
