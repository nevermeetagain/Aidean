== 3. 实现口径（卡面逐条）==
1) 目录 public-pricing/**；无 API Key、无密钥读取、无凭证分支；authRequired=false。
2) 首批源: siliconflow-pricing（https://siliconflow.cn/pricing，CNY/每百万）与 deepseek-pricing
   （https://api-docs.deepseek.com/zh-cn/quick_start/pricing，双币取 CNY，缓存命中价 → priceCacheRead）；tosStatus 未确认前记 pending。
3) fetch 由调用方注入（TextFetcher），模块不发起网络；单测只读 fixture，卡内不联网。
4) 解析 0 条或页面结构变化 → { ok:false, reason }，不以空列表冒充成功；fetch 异常 → ok:false + fetch_failed。 
5) 命中登录/反爬标记（请先登录/登录后查看/人机验证/验证码/captcha）→ 该源 ok:false 停止并回报；调用方按源独立处理，其余源继续。
6) 价格一律原币 + 原单位（cny_per_1m_tokens）十进制字符串，规范化仅去尾随 0（"2.00"→"2"）；零汇率、零单位换算（归 Hark 047/048）。
7) 缺缓存价 / 上下文长度 → null，不写 0；SiliconFlow 页面无上下文列 → contextLength=null。
8) 分时段/分档多价（SiliconFlow 时段价与上下文档、DeepSeek 空闲/高峰）卡面未给口径 → 统一取每列最大值（高峰/标准档上限，保守），代码注释与本文件登记。
9) DeepSeek 上下文 1M/128K 按 1024 进制展开（1M = 1048576 tokens，上下文窗口惯例）；仅计数换算，价格零换算。
10) 免费/非 token 计价（“免费”/“-”/按张/按字符）行跳过；生图/语音/视频段不进入对话观测。
