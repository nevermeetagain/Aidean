== 2. 实现口径（卡面逐条）==
1) 鉴权：读端点 requireAdminApi("admin.sync.read")，写端点 ("admin.sync.write")；
   复用既有权限码（E9-09，无新增码）。未登录 10004→401、越权 10008→403 由 ApiError 映射。
2) GET sources：仅 deletedAt=null，orderBy key asc；DTO 不含内部 id（审计用 id 不外泄）；
   lastRunAt Date→ISO，null 保留；响应 AdminMonitoringSourceListResponse.parse 收口。
3) PATCH sources/{key}：
   - body 用 AdminMonitoringSourcePatchBody（strict + refine 至少一字段）→ 非白名单字段/空体 400；
   - 仅未软删 key 命中，否则 MONITOR_SOURCE_NOT_FOUND(20004, 404)；
   - 只写 enabled/cadenceCron（端点不可改，DESIGN-004 §8 防 SSRF 跳板）；
   - 成功后 writeAudit(tableName=monitoring_sources, action=2, recordId=源 uuid,
     changedFields=实际提交字段, oldData/newData=enabled+cadenceCron, requestId 透传)；
   - lastStatus/lastRunAt 由调度器维护，本端点不触碰；响应 MonitoringSourceSchema.parse。
4) POST run：
   - authRequired=true → MONITOR_SOURCE_CREDENTIAL_MISSING(50012, 503)，不取锁不外连
     （TASK-070 改写后本版本仅公开页源，无 keyed collector）；
   - Redis SETNX lock:monitor:run:{key} TTL=300s；已被占用（null）→ 10006(429)；
   - 未配置 REDIS_URL（getRedis()=null）→ fail-open 直受理（与 lib/db/redis 可失组件口径一致）；
   - 成功 202 + AdminMonitoringRunResponse（accepted=true / sourceKey / lockTtlSeconds=300），
     x-request-id 透传入站值；本端点按设计只受理并占锁，实际采集由 monitor_catalogs.ts 执行。
5) GET changes：
   - AdminMonitoringChangeQuery：page≥1 默认 1、pageSize 1..50 默认 20、sourceKey/kind/since(ISO datetime)；
     越界/日期格式错误 → 400；
   - where：source.key / kind / detectedAt.gte；orderBy detectedAt desc + id desc（同毫秒分页稳定）；
   - Decimal→原币十进制字符串；仅 price_changed 携带 priceUnit/before/after/deltaPct（discriminatedUnion），
     其余 kind 不带价格键；totalPages=ceil(total/pageSize)（total=0 → 0）；
   - 响应 AdminMonitoringChangeListResponse.parse 收口；未知 kind / price_changed 缺价直接抛错→50000（不伪造默认值）。
