== 2. 实现口径（卡面逐条）==
1) 权限门（RSC）：session = getSession()；perms = getAdminPermissions(session.userId)；
   canRead = hasPermission(perms, "admin.sync.read")；canWrite = hasPermission(perms, "admin.sync.write")。
   页面 force-dynamic，未登录由既有 admin 布局/中间件处理；无读权限渲染 forbidden 态，不发请求。
2) 五态优先级（MonitoringPanel，testid 与 MONITORING_UX_STATES 一致）：
   - !canRead || denied(403/10008)                         → monitoring-forbidden
   - !sourcesLoaded || !changesLoaded                      → monitoring-loading
   - sourcesError || (changesError && changes.items 为空)  → monitoring-error
   - sources 为空 && changes 为空                          → monitoring-empty
   - 其余                                                  → monitoring-ready
   额外 monitoring-notice（aria-live）承载操作结果提示。
3) 数据读取：adminFetch 解信封/401 刷新；GET sources；GET changes?page&pageSize&sourceKey&kind；
   403 置 denied；变更流筛选变化从第 1 页重取。
4) 启停：PATCH sources/{key} {enabled}；用响应 DTO 就地替换（不整表重取）；请求中禁用对应开关；
   成功后 notice 提示；失败提示错误并保留原状态。
5) 手动运行：POST sources/{key}/run → 202 accepted；以当前 lastRunAt 为基线，每 5s 轮询 sources，
   上限 12 次（60s）。lastRunAt 变化后按 lastStatus 提示 ok/partial/error，静默刷新 changes 并回到第 1 页；
   超时提示「已触发，60s 内未见新运行结果」；锁冲突 10006/429 按错误提示。
6) 源表：tier 徽章；kind/authRequired/enabled；lastRunAt（全量 YYYY-MM-DD HH:mm，窄屏 MM-DD HH:mm）；
   lastStatus 中文徽章 + lastCount；lastError 截断（title 全量）。运行按钮互斥：!canWrite / authRequired /
   另一源运行中 三种禁用原因分别给出 title；操作列 sticky right，窄屏不横向溢出。
   窄屏（<lg）隐藏 kind/auth/tier 列，tier 徽章内联到源名旁；已停用标签仅宽屏显示。
7) 变更流：listed/delisted/model_first_seen/price_changed 四类标签与配色；price_changed 展示
   priceUnit（cny/usd per 1m tokens）、before→after、deltaPct（涨红跌绿）；证据外链 target=_blank rel=noopener；
   kind/sourceKey 筛选 + 分页（上一页/下一页，页码/总数）。
8) 分级语义：TierBadge 仅表示结构性分级（S1 官方源 → C 中转），非实测 SLA；页头与表头均有说明。
