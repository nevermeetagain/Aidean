## 11.3 完成定义（DoD，全项目唯一口径；沿用 V0.1.0 并修订两处）

Done ≠ 模型说完成 ≠ 代码写完 ≠ 推送到 GitHub。**Done =**
1. 所有权内 diff 符合任务（`git diff --name-only` ⊆ 卡内「允许修改」）；
2. 验收条目逐条有结果（证据 `EVD-xxx/commands.md`）；
3. 自动测试或脚本可复现；
4. 证据可让一周后的人复现；
5. **守卫通过**（无 Makefile，「make guard」等价）：`node scripts/check-docs-rule.mjs && node scripts/check-docs-facts.mjs && node scripts/guard/run-all.mjs（TASK-007 后）&& pnpm --filter @aidean/shared exec tsc --noEmit && pnpm --filter web exec tsc --noEmit && pnpm --filter web lint && pnpm --filter @aidean/shared test && pnpm --filter web test && pnpm --filter @aidean/ui exec vitest run`（**V0.2.0 加入 lint 与 ui 测试**）；
6. 无新增同类错误（lint warning ≤1、单测数不减少、facts 断言不减少、First Load JS 不超过 11.1 基线 +5%）；
7. 未修改冻结契约（`docs/任务规划V0.2.0/contracts/**`）除非本任务就是改契约；
8. **（V0.2.0 新增）RTM 同步**：任务关闭时，03a/`需求追溯矩阵.md` 中对应 REQ 行的状态与证据列同步更新（TASK-051 入库后由 facts 门禁断言）。

切片级 Done：阶段文件全部条目由独立验证者判 PASS；切片在分支内完成后一次性合入 main。

## 11.4 防自证循环
- 验收标准由本规划确定，执行者不得修改；执行由 Hark 或外部 Agent；判定由**独立验证者**只看 `git diff` + 验证命令结果，输出 `PASS / FAIL / UNKNOWN` + 失败条目号，写 `EVD-xxx/verdict.md`。
- Hark 执行的 16 张卡必须由非 Hark 验证者判定；外部 Agent 的卡不得由同一执行实例判定。
