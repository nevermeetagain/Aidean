## 异常：V0.1.0 规划提交不在远端（已确认）

| 证据 | 结果 |
|---|---|
| `git rev-parse HEAD origin/main` | `59e83dd…` / `77c7952…` |
| `git ls-remote origin` | `refs/heads/main = 77c7952…` |
| `git reflog` | `59e83dd HEAD@{0}: commit: docs: 任务规划V0.1.0 …`；`77c7952 HEAD@{1}: clone` |

**影响**：上一轮报告的「推送成功、双端一致」与远端现状不符（原因未知：推送未生效，或远端被重置——**证据不足**，无法区分）。本轮推送 V0.2.0 时，`git push` 会把 59e83dd（V0.1.0）连同 V0.2.0 提交一起推到远端；V0.2.0 文件大量引用 V0.1.0 目录，推送 V0.1.0 是保持链接可达所必需的。若用户当初是有意从远端移除 V0.1.0，需要用户另行说明（已登记 12 §12.3 U-17）。
