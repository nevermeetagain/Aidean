# 03 · 需求基线复核

> 版本: v0.1 | 更新: 2026-10-13 | 变更: 首次落档（任务规划V0.1.0）——独立复核需求文档 v1.14 与台账，不默认其完整无歧义

## 3.1 复述与拆解

**一句话复述**：Aidean 是面向开发者/企业的 AI 模型与云服务「天梯图」选型平台——免费看可视化排行与详情，付费按次对比测评；以「一次充值、统一计费网关」打通多家模型服务平台调用，并作为 Aidean 生态子平台（AideanWiki/AideanBot/Fleet/Thesis/SkillsCloud）的门户与统一身份（OIDC）提供方。

**关键词**：天梯图、两榜（模型/云服务站）、专业版/应用版、五维筛选、五种排序、分度值、模型详情、对比测评 ¥2/模型/次、余额预付费、统一计费网关、优先级降级、free 兜底、协议中转、自定义渠道、限时优惠、套餐直连、兑换码、功能开关、后台管理、排名权重、provenance、价格透明、浅色多主题、SSO。

**角色与边界**：
- 用户端：访客 / 注册用户（NORMAL）/ Pro / Max（`AccountTier`）→ 前台 `(site)` + `/user/*` + 网关 API。
- 管理端：MODERATOR / ADMIN / SUPER_ADMIN（`UserRole`）+ 30 域细粒度权限 → `/admin/*` + `/api/v1/admin/*`。
- 系统边界：本仓 = 主平台；子平台源码在各自仓库，主平台只做展示页 + OIDC IdP（需求 §3.4「范围边界」）。外部依赖：上游模型平台 API、SMTP、（暂停的）支付/微信。

**本次需求（用户指令）拆解**：明确进度与未完成项 → 基于最新代码出完整规划（重点：核心功能 + 测试）→ 分步骤、每步一个 md → 存 `docs/任务规划V0.1.0/` 并推送 → 核心/高难度（尤其 UI）由主 Agent 完成，中/简单由外部 Agent 完成。

## 3.5 隐含要求与前置条件

- **隐含要求**：新 admin 写端点必须写 AuditLog（需求 §3.10 R-07）；新配置/开关变更必须即时失效缓存（既有 revalidateTag 模式）；新 UI 必须带 data-testid（e2e 惯例）、三套浅色主题对比度 ≥4.5:1（N7）、移动端可用（S8.2 先例）；新端点须登记 API 文档并双向锚（铁律2），否则 CI 文档门禁/人工评审阻断；新增目录须回写《目录结构文档》（铁律6）。
- **前置条件**：PG16 + Redis 可用（e2e/集成测试）；`AIDEAN_ENABLE_MOCK_UPSTREAM=1`（网关 e2e，台账 §7.31）；`AIDEAN_BYPASS_LOGIN_RATE_LIMIT=1` 仅测试（`constants.ts:141` 生产恒 false）；`db:seed` 后须补跑 `seed-navigation-menu.ts` + `seed-rbac.ts`（CHANGELOG S4「⚠ 陷阱」）。
- **歧义表述**：「功能开关关闭则页面 403」——Next RSC 页面需自定义 403 呈现（非 notFound）；「限时优惠随上游价格采集同步展示价」——采集写价不得覆盖 PROMOTION 行（S1/S4 共同约束）；「收藏」对象仅 MODEL / API_STATION（枚举既定）。
- **失败边界**：开关读库失败（U-7）；优惠窗口边界（`from<=at<until`，半开区间）与时区（存 UTC、展示 Asia/Shanghai）；收藏目标被软删；搜索 q 为空白；并发两次收藏（唯一键幂等）；迁移在存量库遇重复数据（TASK-011 前置核验）。
- **模块依赖**：S4 依赖 S1（多价格行）；S2 的 `requireFeature` 被 S3 复用；S5 与 S2 同改 SiteHeader（串行）；S3 与 S4 同改模型详情页（串行）。
