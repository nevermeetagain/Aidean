## 11.3 完成定义（DoD，全项目唯一口径）

Done ≠ 模型说完成 ≠ 代码写完 ≠ 推送到 GitHub。

**Done =**
1. 所有权内 diff 符合任务（`git diff --name-only` ⊆ 任务卡「允许修改」）；
2. 验收条目逐条有结果（证据目录 `commands.md`）；
3. 自动测试或脚本可复现（验证命令在干净 checkout 上可跑）；
4. 证据能让一周后的人复现，不用问原作者；
5. **守卫通过**——本项目无 Makefile，「make guard」等价为：`node scripts/check-docs-rule.mjs && node scripts/check-docs-facts.mjs && node scripts/guard/run-all.mjs（TASK-007 后）&& pnpm --filter @aidean/shared exec tsc --noEmit && pnpm --filter web exec tsc --noEmit && pnpm --filter @aidean/shared test && pnpm --filter web test`；
6. 无新增同类错误记录（lint warning 数 ≤1、单测数不减少、facts 断言不减少）；
7. 未修改冻结契约（`docs/任务规划V0.1.0/contracts/**` 与已落地契约），除非本任务就是改契约。

切片级 Done 另加：切片阶段文件（`04_planning/stages/STAGE-Sx.md`）全部条目由独立验证者判 PASS；切片在分支内完成后一次性合入 main（避免中间态让 docs-facts 计数门禁变红）。

## 11.4 防自证循环

- 验收标准由规划阶段确定（本目录任务卡，执行者不得修改）。
- 执行由开发 CLI（Hark 或外部 Agent）完成。
- 判定由**独立验证者**完成：只看 `git diff` + 运行验证命令的结果；输出只有 `PASS` / `FAIL` / `UNKNOWN` + 失败条目编号，写入 `EVD-xxx/verdict.md`。
- Hark 执行的卡（13 张）必须由非 Hark 的验证者判定；外部 Agent 执行的卡可由 Hark 或另一外部 Agent 判定，但不得是同一执行实例。
