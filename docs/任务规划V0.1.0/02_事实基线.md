### 数据层潜在缺陷（部分确认）
`model_prices` 存在唯一索引 `(model_id, is_current)`（`schema.prisma:480` + 迁移 `20260925170000_align_unique_indexes`），而 `lib/sync/writers/index.ts:74-95 persistPrices` 每次同步先把当前行 `updateMany → is_current=false` 再插新行：当同一模型已有一条历史行（is_current=false）时，第二次 updateMany 将产生第二条 is_current=false → **违反唯一索引（P2002）**；且 `prices` 数组 >1 条时多条 `is_current` 默认 true 亦冲突。该推理来自静态代码，**未在真实库复现**（沙箱无 PG）→ TASK-010 先复现再修。它同时阻断「限时优惠需多条价格行并存」（S4）。
