## 一页结论
- **现状**：主体功能（天梯、认证/SSO、余额账本、统一计费网关、测评、套餐兑换、后台 RBAC/CMS/日志/报表）已实现；单测 1,203 例、类型检查、lint、生产构建、文档门禁全部实测通过。
- **缺口**：功能开关运行时（MUST）、限时优惠计费（MUST）、收藏（SHOULD）、顶栏搜索（SHOULD，待确认）；数据层疑似唯一约束缺陷（待复现）；e2e 不进 CI、错误码多源冲突、无覆盖率/量级基线；生产未部署。
- **规划**：10 个垂直切片、46 张原子任务卡（Hark 主Agent 13 张：契约/迁移/资金路径/全部 UI/需求修订/部署；外部Agent 33 张）；第一刀 = S0 步行骨架与契约守卫。
- **门禁**：本目录为六步循环的 PLAN+SPEC 产物，**需用户 APPROVE 后才实施**；BLOCKING 裁决见 `12_风险与待裁决.md §12.3`。
