# 04 · 契约冻结包（六份，全量）

> 版本: v0.1 | 更新: 2026-10-13 | 变更: 首次冻结（任务规划V0.1.0）——六份契约以 TypeScript + zod 形式落盘，可编译、可自检

## 4.0 唯一源声明（ADR-P001）

- **运行时唯一源 = `packages/shared/src/**`（zod + TS 常量）**。理由（本项目证据）：开发流程.md §五.2 已规定「公开接口变更先更新 packages/shared 的 Zod Schema」；现有 20 个 schema 文件与 `permissions.ts` 已是事实上的契约层；web 侧 1,081 例单测依赖它们。不引入 OpenAPI/JSON Schema 第二源。
- **冻结稿**：`docs/任务规划V0.1.0/contracts/0{1..6}-*.contract.ts` 是「待落地」的精确内容。每份冻结稿指定落地任务（TASK-001/014/021/026/032/044），落地后冻结稿转为只读参考，**以 packages/shared 为准**；冻结稿与 packages/shared 不得长期并存为两个可编辑源。
- **机器可校验**：冻结稿可直接编译与运行自检——

```bash
cd "docs/任务规划V0.1.0/contracts"
../../../node_modules/.bin/tsc -p tsconfig.json                                  # 本规划实测 exit 0
../../../apps/web/node_modules/.bin/tsx --tsconfig tsconfig.json selfcheck.ts    # 实测输出见下
# {"total":25,"web":22,"dup":[],"mism":0,"missingPres":[],"failurePaths":13,"sample":true,"bad":false}
```
  含义：冻结码表 25 码、与 web 运行时 22 码逐值一致（mism=0）、无重复、每码都有前端展示策略、13 条失败路径有码覆盖、错误体 schema 能接受已登记码（50011）且拒绝未登记码（50003）。
- **契约测试自动生成**：TASK-004 的生成器从 packages/shared 导出物生成 `packages/shared/src/__tests__/contract/*.generated.spec.ts`，CI 以 `git diff --exit-code` 防手改。
- **统一口径**（全部沿用现行代码）：字段 camelCase；时间 ISO-8601 UTC；金额存「分」、对外字符串「元」（`fenToYuan`）、单价 Decimal→string（¥/M Tokens）；枚举取 Prisma 枚举名大写（`MODEL`、`PRO`）；功能开关码 `domain.name` 小写点分。

## 4.2 ② Errors（`contracts/02-errors.contract.ts`）

既有 22 码逐字沿用（值与 HTTP 映射不得改）+ 新增 3 码：

| 码 | 标识 | HTTP | 语义 | 前端展示 |
|---|---|---|---|---|
| 20003 | FAVORITE_TARGET_NOT_FOUND | 400 | 收藏目标不存在/已下线 | toast |
| 50010 | SERVICE_UNAVAILABLE | 503 | 就绪探针：DB/Redis 不可达 | page（维护态） |
| 50011 | FEATURE_DISABLED | 403 | 功能开关关闭 | page（功能关闭态） |

新码刻意避开 shared 旧表中的 50001–50003（旧表将被 TASK-001 删除，避免语义混淆）。错误体 `{code,message,data:null,requestId}`；展示策略 `ERROR_PRESENTATION`（toast/inline/redirect/page）对 25 码全覆盖；失败路径覆盖表 `FAILURE_PATHS` 13 条。

## 4.3 ③ Identity（`contracts/03-identity.contract.ts`）

- 用户 ID：UUIDv7 字符串；角色 GUEST/USER/MODERATOR/ADMIN/SUPER_ADMIN；等级 NORMAL/PRO/MAX；staff = MODERATOR/ADMIN/SUPER_ADMIN。
- JWT：RS256；access 声明 `sub/tier/ver/jti/clientId?/iss/aud/iat/exp`；refresh `typ=refresh/ver/jti/clientId?`；Cookie `aidean_token`/`aidean_refresh`；TTL access 5–60min（默认15）、refresh 1–30 天（默认7）。
- 权限码 `admin.<domain>.<read|write>`，SUPER_ADMIN 通配 `*`；**本规划不新增权限域**（开关复用 configs，优惠复用 models）。
- **管理端/用户端越权禁止清单 `AUTHZ_BOUNDARY`（10 条）**：匿名访问 user/admin → 10004；USER 访问 admin → 10008；MODERATOR 访问 roles/reports → 10008；缺码 → 10008；超管改自身分配 → 40000；删他人收藏 → 40000；用户面出现 markup/multiplier/secretHash → 序列化白名单剔除（一票否决）；开关/优惠管理缺写权限 → 10008。

## 4.4 ④ Resources（`contracts/04-resources.contract.ts`）

本规划**不新增上传端点**（无对象存储，ADR-0001 未含）。唯一 multipart 入口仍为 benchmarks CSV 导入（≤500 行）。图片 = `/public/(images|brands)/**` 或 http/https 外链，经 SafeImage 兜底渲染；服务端拉外链必须经 `lib/security/url-policy.ts`（SSRF 守卫）。S9 截图只存 URL，托管方式待 U-4。

## 4.5 ⑤ Events（`contracts/05-events.contract.ts`）

无消息队列。异步面：Next 缓存标签（新增 `feature-flags`）、OIDC back-channel logout、scheduler run-due（Redis SETNX 锁）、账务 hold/capture 幂等键。新增事件 `feature-flags.changed`：写库成功 → `revalidateTag('feature-flags')` + 审计；幂等键 `${flagId}:${updatedAt}`；重复失效无副作用。限时优惠**不引入定时任务**（读时按窗口计算）。
