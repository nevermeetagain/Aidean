# 证据目录（evidence）

> 版本: v0.1 | 更新: 2026-10-13 | 变更: 首次落档（任务规划V0.1.0）

- 每张任务卡独占 `EVD-<任务号>/`，由该任务执行者写入，其他人只读。
- 必含：`commands.md`（逐条命令 + 退出码 + 关键输出）、`diff-files.txt`（`git diff --name-only` 输出，用于核对允许修改范围）、必要时截图/日志。
- 独立验证者在同目录写 `verdict.md`，内容仅一行：`PASS` / `FAIL` / `UNKNOWN` + 失败的验收条目编号。
- 证据须让一周后的人不问原作者即可复现（DoD 条款）。
- 规划阶段基线证据见 `EVD-BASELINE/`。
