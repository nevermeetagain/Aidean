# 05 · 数据模型基线（含迁移版本号编排）

> 版本: v0.1 | 更新: 2026-10-13 | 变更: 首次落档（任务规划V0.1.0）

## 5.1 基线与唯一 DDL 源

- **DDL 唯一源 = `apps/web/prisma/schema.prisma` + `apps/web/prisma/migrations/**`**（68 model / 37 enum / 16 条迁移；`prisma validate` 本规划实测 valid）。`database/baseline/*.sql` 为 rel01 历史底稿，不是当前源。
- 本规划**不新建任何表**（§13.13 禁止「为未来可能需要」建表）。四个新功能全部复用既有表：
  - 功能开关 → `feature_flags`（0000_init 已建，7 条种子）
  - 收藏 → `favorites`（0000_init 已建，唯一键 `(user_id, refType, ref_id)`）
  - 限时优惠 → `model_prices`（`source_type=PROMOTION(5)` + `effective_from/until`，schema 注释原意即如此）
  - 搜索 → 只读 `ai_models` / `products` / `news_items`
- 唯一 DDL 变更：**M-001**（修复唯一约束缺陷，见 5.4）。

## 5.2 本规划触达的核心实体（字段级）

### model_prices（`ModelPrice`，schema.prisma:450-484）
| 字段 | 类型 | 可空 | 默认 | 约束/说明 |
|---|---|---|---|---|
| id | uuid(v7) text | 否 | uuid(7) | PK |
| model_id | text | 否 | — | FK ai_models ON DELETE CASCADE |
| price_input / price_output | DECIMAL(19,6) | 否 | — | ¥/M Tokens；PROMOTION 行可为 0（限时免费） |
| price_cache / price_per_request | DECIMAL(19,6) | 是 | — | |
| billing_mode | enum BillingMode | 否 | PER_TOKEN | |
| billing_currency / billing_unit | text | 否 | CNY / per_1k_tokens | |
| effective_from | timestamptz | 否 | — | 优惠窗口起（含） |
| effective_until | timestamptz | 是 | — | 优惠窗口止（不含）；PROMOTION 行**必填**（契约层强制） |
| is_current | bool | 否 | true | 当前官方价标记；PROMOTION 行恒 false |
| source_type | enum PriceSource | 否 | OFFICIAL | PROMOTION=5 |
| 索引 | — | — | — | model_id；is_current；effective_from；**现**唯一 (model_id,is_current) → **M-001 后**部分唯一 (model_id) WHERE is_current |

### feature_flags（`FeatureFlag`，schema.prisma:1520-1546）
flag_code text UNIQUE；name text；name_cn/description text 可空；is_enabled bool 默认 false；enabled_roles int[]；rollout_percentage int 默认 100；rollout_strategy text 默认 'all'；config jsonb 可空；enable_from/enable_until timestamptz 可空；category text 可空；priority int 默认 0；索引 is_enabled、category。**本规划仅读写 is_enabled/description，并在读侧尊重 enable_from/until；rollout_* 不实现（无需求来源）。**

### favorites（`Favorite`，schema.prisma:1307-1320）
id uuid；user_id FK users CASCADE；refType enum FavoriteType(MODEL/API_STATION)；ref_id text；note text 可空；created_at；UNIQUE(user_id,refType,ref_id)；INDEX(user_id)、(refType,ref_id)。

### 搜索读源（只读）
`ai_models`（name_display/name_cn/name_en/slug；status、is_active、deleted_at 过滤）、`products`（slug/name/display_name；status=ACTIVE、deleted_at 为空）、`news_items`（slug/title；status=PUBLISHED）。

## 5.3 索引策略（按查询路径）

| 查询路径 | 现有索引 | 结论 |
|---|---|---|
| 收藏列表 `WHERE user_id=? ORDER BY created_at DESC LIMIT` | favorites(user_id) | 足够（单用户收藏量级小） |
| 收藏幂等 upsert | UNIQUE(user_id,refType,ref_id) | 足够 |
| 开关读取 `WHERE flag_code IN (...)` / 全表 7 行 | UNIQUE(flag_code) | 足够，且有 unstable_cache |
| 生效价 `WHERE model_id=? AND source_type=5 AND effective_from<=? AND effective_until>?` | model_prices(model_id) | 足够（单模型价格行数为个位数）；**无基线不加复合索引** |
| 网关当前价 `WHERE model_id=? AND is_current` | M-001 部分唯一索引同时服务该查询 | M-001 后更优 |
| 搜索 `ILIKE '%q%'` | 无 | 当前 78 模型级数据量不需索引；**TASK-039 测出千级基线前禁止加 pg_trgm** |

## 5.4 迁移策略与版本号编排（★ 串行）

| 序 | 版本号（目录名） | 内容 | 任务 | 所有者 | 状态 |
|---|---|---|---|---|---|
| 0–15 | `0000_init` … `20261012082315_rbac_role_permission_user_role` | 既有 16 条 | — | — | 已在库 |
| **M-001** | `20261014000000_model_prices_partial_current_unique` | DROP INDEX `model_prices_model_id_is_current_key`；CREATE UNIQUE INDEX `model_prices_model_id_current_key` ON model_prices(model_id) WHERE is_current = true | TASK-011 | Agent-Data（唯一持有者） | 待 TASK-010 复现后执行 |

规则：
1. 迁移只能由 Agent-Data 在串行队列中创建；本规划只预留 M-001 一个版本号，后续新增必须 > `20261014000000` 并在本表登记后才可开工。
2. 既有 16 条迁移只读（TASK-011「禁止修改」已列）。
3. 每条迁移须：前置核验 SQL（写入迁移注释）+ 空库重放（CI e2e-skeleton job）+ 存量库升级演练。
4. Prisma 不能表达部分唯一索引 → schema.prisma 移除 `@@unique([modelId,isCurrent])` 并注释；`prisma migrate diff` 对该索引的差异在 ADR-P003 中登记为已知豁免。

## 5.5 软删除与数据生命周期

| 数据 | 策略 | 依据 |
|---|---|---|
| 用户/模型/产品/站点 | 软删 `deleted_at`（既有） | schema 现状 |
| 收藏 | 物理删除（本人数据、无审计价值）；用户删除时 CASCADE | favorites FK onDelete Cascade |
| 功能开关 | 不删除，仅开/关；变更写 AuditLog | 需求 §3.10 留痕 |
| 限时优惠行 | 允许物理删除（仅 PROMOTION 行），删除前 oldData 入 AuditLog；过期行保留为价格历史 | 价格历史可追溯 + 审计 |
| 账本 LedgerEntry | 只增不改不删（既有铁律） | CHANGELOG S6 |
| 演示 seed 数据 | 生产上线前人工逐条审核 verifiedStatus | 需求 §3.4.1 过渡期 |
