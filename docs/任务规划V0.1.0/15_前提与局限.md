## 15.3 局限
1. **无数据库运行**：e2e、带库集成、`prisma migrate diff` 未执行；唯一约束缺陷为「部分确认」；K2/K4/K5 运行时指标为「尚无基线」。
2. **子平台不在本仓**：AideanBot 3333 只能核验本仓引用面。
3. **仓库仅 1 个镜像提交**：演进史来自 CHANGELOG/台账（文档证据），无法用 git 交叉验证。
4. **工时为估算**：无历史速度数据，仅用于排序与关键路径，不作承诺。
5. **未纳入的已知挂起项**（#13/#34/#35/#43/#77/#78、R-09）：无足够需求或外部输入，按「宁少勿假」不立卡，见 12 §12.2。
