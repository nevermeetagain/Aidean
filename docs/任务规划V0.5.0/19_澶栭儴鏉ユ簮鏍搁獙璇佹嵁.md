## 一、核验口径

- **核验时间**：2026-10-14 15:20–15:35（Asia/Shanghai，UTC+8）。直连探针原始输出：`06_validation/evidence/EVD-BASELINE-V4/probes.txt`（含 `fetched_at` 行）。
- **方法**：①对 API 端点在沙箱内 `curl` 无凭证直连（看 HTTP 码与响应形状）；②对文档页 `web_fetch` 全文读取；③第三方测评页（Veridrop）全文读取。**检索摘要不作证据**，只用打开过的页面。
