## Execution Steps
1. [ ] probe：仅 https；DNS 解析后拒绝私网/回环/链路本地/元数据地址（IPv4+IPv6）；禁止重定向；3s 超时；只发 GET /models
2. [ ] 端点限流：每用户 10/分钟
3. [ ] 结果写渠道 lastProbe*（复用现有列，若无则只返回不落库）
4. [ ] UI 保存后行内显示结果徽标

- [ ] 错误码 30005 契约测
- [ ] UI 四种结果可见
- [ ] 全量 `tsc` / `lint` / 相关 vitest exit=0；`check-docs-rule` 与 `check-docs-facts` exit=0（推送前一次）
