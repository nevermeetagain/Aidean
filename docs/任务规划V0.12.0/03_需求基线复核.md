# 03 · 需求基线复核

> 版本: v1.0 | 更新: 2026-10-23 | 变更: V0.12.0 规划首版（基线 main@3b9f88c）

## 3.1 复述与拆解
**核心问题**：Aidean 是面向国内开发者的 AI 模型 / 工具「天梯图」评测与调用平台——让用户一眼比较模型的能力、价格与可用性，并通过统一网关以人民币计价调用；管理端负责数据源、价格、内容与用户的运营。
- **用户**：匿名访客（浏览天梯、模型、价格、资讯）；注册用户（收藏、对比、API Key、余额、自定义渠道、测评）。
- **管理端**：`isStaff` + 权限码的运营人员（34 个后台页：模型、价格、监控、兼容矩阵、内容、用户、钱包、配置…）。
- **系统边界**：主平台（本仓）+ OIDC 发证给子平台（BotHot 3200 等，子平台实现在各自仓库）；外部数据源（OpenRouter、AIHubMix、quanzil、llmtest、Artificial Analysis 等）只读采集。
- **关键词**：天梯 · 生效价（CNY/百万 Token）· 多源可调用 · 可靠性 · 五态 · 三主题浅色 · 默认中文。

## 3.5 隐含要求与前置条件
- **隐含**：改密 / 重置后必须让其他设备立即失效——否则「改密」对被盗号场景无意义（推导出 T120-18 先于 T120-19/20）。
- **隐含**：可靠性缺数据时不能显示 0%（0% 会被读作「完全不可用」），必须显示空态（T120-14 验收句）。
- **隐含**：立即运行必须能回答「我点的那次跑完了吗」（推导出意图表，00_ Q4）。
- **前置**：契约 T120-10 合并；`test:int` 入口（T120-01）是所有迁移卡的验证命令前提。
- **歧义**：「每日自动采集」中的「每日」——以各源 `cadenceCron`（默认 `15 2 * * *`，上海时间）为准，不是固定 24h 间隔。
- **边界**：cron 判定以 Asia/Shanghai 为时区（无夏令时）；非法 cron 不得让整批采集失败。
- **依赖**：Dock 收藏依赖既有 `/api/v1/user/favorites` 与 `FAVORITE_TARGET_NOT_FOUND(20003)`；渠道探测依赖 `custom-channels` 现有归属校验。
