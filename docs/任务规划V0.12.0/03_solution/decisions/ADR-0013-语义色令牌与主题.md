# ADR-0013（草案）：语义色令牌与主题

> 版本: v1.0 | 更新: 2026-10-23 | 变更: V0.12.0 规划首版（基线 main@3b9f88c）

- 状态：提议（T120-25 落地时改为已接受）
- 背景：`globals.css` 新旧命名并存；对比度靠重定义 slate-400/500 维持；硬编码色板 2011 处；三主题切换时状态色不跟随；packages/ui 用 Tailwind ^3.4 与 apps/web 4.0 不一致（D-17）。
- 决策：①唯一命名 `--color-*`，旧名作别名保留一个版本并加弃用注释；②语义类六族：surface / fg / muted / line / accent / status(success|warning|danger|info)，每族随 `[data-theme]` 切换；③取消对 slate-* 的值重定义，改由 codemod 把用法迁到语义类；④`scripts/guard/raw-palette.mjs` 设上限（用户端 0、管理端迁移后 0）；⑤monorepo 内 Tailwind 与 vitest 对齐到 apps/web 的大版本（失败 >20 例则保留差异并记录）。
- 对比度：三主题 × 六族 18 组均需 ≥4.5:1（正文）/ ≥3:1（大字与图形），表格写入本 ADR 终稿。
- 后果：新组件无法再引入不跟随主题的颜色；一次性迁移成本由 codemod 承担。
