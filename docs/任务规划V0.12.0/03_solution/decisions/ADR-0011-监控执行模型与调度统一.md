# ADR-0011（草案）：监控执行模型与调度统一

> 版本: v1.0 | 更新: 2026-10-23 | 变更: V0.12.0 规划首版（基线 main@3b9f88c）

- 状态：提议（T120-10 落地到 `docs/ADR/` 时改为已接受）
- 背景：`POST /admin/monitoring/sources/{key}/run` 只占 Redis 锁、全仓无消费者；monitor_catalogs 未登记 ScheduledScript；`cadenceCron` 无读取方（REQ-M-002/009/011）。
- 决策：①monitor_catalogs 以 15 分钟扫描节拍登记为 ScheduledScript，每次只采集 `dueSources(cadenceCron, now)`（Asia/Shanghai）与已被领取的立即运行请求；②立即运行写 `monitor_run_requests`（部分唯一索引作幂等键），调度原子领取；③Redis 锁降级为可失的辅助防线。
- 备选：A 仅 `nextRunAt=now`（无法指定单源、无法回答「那次跑完没」，否决）；B Redis 队列（Redis fail-open 时丢请求，否决）。
- 后果：+1 表 +1 数据迁移；立即运行延迟上限 = 1 个节拍；后台可展示状态与历史。
