# DESIGN-004-自定义渠道探测与SSRF防护

> 版本: v1.0 | 更新: 2026-10-23 | 变更: V0.12.0 规划首版（基线 main@3b9f88c）

- 关联：T120-23

## 设计要点
仅 https；不跟随重定向；DNS 解析得到的每个地址都须为公网（拒绝 10/8、172.16/12、192.168/16、127/8、169.254/16、100.64/10、0/8、::1、fc00::/7、fe80::/10、::ffff:映射私网、云元数据 169.254.169.254 / fd00:ec2::254）；以解析得到的 IP 直连并带 Host/SNI，防 DNS 重绑定；3s 总超时；只发 GET {base}/models，响应体上限 256 KB；每用户 10 次/分钟；结果只返回不落库（若渠道表已有 lastProbe 列则写入）。
