## 三级执行大纲（6.卡序.步骤序）
#### T120-18 会话校验比对 tokenVersion（改密/封禁全端即时失效）
- 6.1.1 requireUserApi/requireAdminApi：回库投影加 tokenVersion，与 claims.ver 不等 → UNAUTHENTICATED
- 6.1.2 在既有回库查询（status/deletedAt）中追加 tokenVersion 投影——不新增往返；仅当该查询被测为热点时才启用 Redis user:ver:{id}（60s，自增处同步 DEL）
- 6.1.3 单测：ver 相等 / 不等 / 用户已删除 / admin 路径四类
#### T120-19 已登录改密 API（旧密校验 + tokenVersion++ + 刷新令牌吊销）

- 6.2.3 签发新令牌对写 Cookie
- 6.2.4 审计：password.change
#### T120-20 找回密码（邮件验证码 purpose=reset，防枚举，限流）

- 6.3.3 reset：校验码（5 次错误即作废）→ 改哈希 → tokenVersion++ → 吊销 refresh
- 6.3.4 审计：password.reset
#### T120-21 改密 / 找回密码页面（用户端）
