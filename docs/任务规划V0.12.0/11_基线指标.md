## 二、被下线的候选指标（证明不了与用户可感耗时的关系）
- 共享 First Load JS 体积（102 kB）：变化 3 kB 量级时与 LCP/TBT 的关系在本项目无证据 → 只记录，不作为优化目标。
- middleware 体积（163 kB）：影响冷启动而非页面交互；T120-02 降它的理由是**移除 Edge 不兼容依赖**（正确性），不是性能目标。
- vitest 用时（333 s）、build 用时（364 s）：开发者体验，非用户可感 → 只要求 T120-30 增幅 ≤15%。
