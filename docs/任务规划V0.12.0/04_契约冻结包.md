# 04 · 契约冻结包（V0.12.0 增量）

> 版本: v1.0 | 更新: 2026-10-23 | 变更: V0.12.0 规划首版（基线 main@3b9f88c）

## 一、唯一源与形式
- **唯一源**：`packages/shared`（zod schema + `errors.ts`）。既有契约（V0.5.0 contracts 01–07 已落地）保持冻结；本版增量草案在 `contracts/`，由 **T120-10** 原样落地，落地后草案只读。
- **机器可校验**：`contracts/*.contract.ts` 均可被 `tsc --strict` 解析（2026-10-23 实测：拷入 `packages/shared` 临时目录后 0 类型错误）；`contracts/selfcheck.ts` 8 条正/反例断言 **8/8 PASS**（命令见 `tools/contract-check.sh`）。T120-10 将其扩展为 `packages/shared/src/__tests__/contract/v120.contract.spec.ts`（≥10 例）。
- **全项目统一口径**：时间 ISO-8601（UTC 存储、上海日边界用于统计窗口）；金额整数分；分页 `{items,total,page,pageSize≤50}`、非法参数 400（B11-11）；成功 `{code:0,data}`，失败 `{code,message,details?}`（B11-10）；405 由 `methodNotAllowed()` 统一生成。

## 二、六份契约

### ① API（新增 5 个端点，修改 1 个语义）
| 方法 路径 | 鉴权 | 请求 | 响应 | 幂等 | 文件 |
|---|---|---|---|---|---|
| POST `/api/v1/auth/password` | 已登录 | `ChangePasswordRequest` | `ChangePasswordResponse` + Set-Cookie 新令牌对 | 非幂等（第二次旧密不匹配→10003） | 03b |
| POST `/api/v1/auth/password/reset/code` | 匿名，开关 `auth.password_reset` | `ResetCodeRequest` | `{sent:true}`（恒定，防枚举） | 幂等（限流内） | 03b |
| POST `/api/v1/auth/password/reset` | 匿名，同上开关 | `ResetPasswordRequest` | `{reset:true}` | 验证码一次性 | 03b |
| POST `/api/v1/user/custom-channels/{id}/probe` | 已登录，仅本人渠道 | path `id` | `ChannelProbeResponse` | 只读外连，可重试；10 次/分钟 | 01b |
| GET `/api/v1/admin/monitoring/sources/{key}/runs` | `admin.sync.read` | page/pageSize | `AdminMonitoringRunsResponse` | 只读 | 07b |
| GET `/api/v1/stations/{id}/reliability?days` | 匿名 | days∈[1,30] | `StationReliabilityResponse` | 只读，缓存 10 分钟 | 07c |
| **语义变更** POST `/api/v1/admin/monitoring/sources/{key}/run` | `admin.sync.write` | — | 202 `{accepted:true, requestId}`（兼容旧字段） | 同源仅 1 个未完成请求（DB 部分唯一索引） | 07b / 05b |

所有新端点：未实现方法 → 405 信封（`api-method-coverage --fix` 生成）；分页走 `lib/http/pagination.ts`。

### ② Errors
- 新增 **1** 个码：`CHANNEL_PROBE_TARGET_FORBIDDEN = 30005`（400，inline）。既有 27 码值零改动（T120-10 验收用 diff 断言）。
- 失败路径增量 10 条，全部映射到既有码（见 `02b` 的 `V120_FAILURE_PATHS`）：旧密错/重置码错 → 10003；新密弱 → 40000；发码限流 / 重复立即运行 → 10006；ver 不等 → 10004；站点不存在 → 30001；渠道非本人 → 40000（不暴露存在性）；开关关 → 50011。
- 前端展示：10003/40000 表单 inline；10006 toast + 倒计时；10004 跳登录；30005 渠道行 inline。

### ③ Identity
- 用户 ID：uuid v7 文本；角色：`isStaff` + 权限码（`packages/shared/src/permissions.ts`，本版无新增权限码，复用 `admin.sync.read/write`）。
- JWT claims 不变（`sub, tier, ver, jti, clientId`）；**新增校验规则**：`claims.ver !== users.token_version → 10004`，适用于 requireUserApi 与 requireAdminApi。
- token_version 自增的三处：管理员封禁（既有）、改密、重置；每处同事务吊销该用户全部 refresh。
- **管理端越权禁止（显式）**：①改密端点只作用于会话主体，不接受 userId 参数；②管理员不能经用户端端点代他人改密或探测他人渠道；③`/admin/monitoring/**` 非 staff 一律 403（T120-33 e2e 覆盖），staff 缺 `admin.sync.write` 调 run → 403。

### ④ Resources
本版**无新增**文件 / 图片资源、上传端点或 URL 规则（`04b` 显式声明）。可靠性迷你图为前端绘制，不产生资源文件。

### ⑤ Events
无消息总线。唯一的异步链是「监控立即运行」，以 DB 行为事件（`05b`）：`pending → running → done|failed`；领取用 `UPDATE … WHERE status='pending' RETURNING`（原子）；幂等键 = 部分唯一索引 `(source_key) WHERE status IN ('pending','running')`；running 超 30 分钟回收为 `failed(stale)`。ScheduledScript 执行记录（ScriptExecution）口径沿用 B11-08。

### ⑥ UX States
通用五态 `PanelState`（`06b`）上移到 `@aidean/ui`（T120-26）。规则：失败必须是 error 且带重试，**禁止渲染为 empty**；401 跳登录；403 forbidden 无重试；empty 仅在 2xx 且 total=0；loading >300ms 才显示骨架。V0.12 新增 6 个界面，每个五态截图入 EVD。
