## 切片质量自检
- 每刀可独立验收：每刀的「可演示行为」都对应至少一条 e2e 或集成测验收句（见各卡）。
- 刀的规模：最小 S12-4（≈3.5h，含条件卡），最大 S12-7（≈35h，7 卡但每卡 ≤7h、≤2 天）。<2h 的改动均已并入相邻卡（如 3333 清理并入 T120-03、model-change-log 注释并入 T120-28）。
- 第一刀是步行骨架：S12-0 覆盖「健康检查 + 鉴权写接口（e2e 已有）+ 表 + 迁移 + 前端打真实 API + 统一错误响应」的**验证面**——这些能力在 V0.1–V0.11 已存在，本版的骨架是让它们在 HEAD 上同时被证明。
