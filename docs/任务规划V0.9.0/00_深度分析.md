**Where / When**

- D8-02：`scripts/check-docs-*.mjs` 读取 `docs/architecture/*`、`docs/product/design/功能设计文档.md` 的数字锚。

- 端口：Aidean 入口仍为 3000（package.json dev/start、seed OIDC 3000），区间 3000–3100 不变；AideanBot 3333 仍待 P-2；BotHot 回调 3200 已在 seed。

**Who**
- 执行：Hark（核心 31 卡，含全部未落地 UI 与独立验收）＋ P1/P2/P3 三条外部线（61 卡，含他线已落地的 018/023/078）。

**How**

**What if**
- 配置缺失（无 DATABASE_URL）：int spec skip，不影响单测；有占位值则失败（D8-01）。
- 依赖服务不可用：`/system/ready` 设计返回 503（单测覆盖），真依赖场景未测。
- 他线继续开发 S4：若镜像也开工 S4，下次叠加互相覆盖 → B-0' 必须先裁决。
- 测试通过但运行失败：UI 卡只有代码证据 → TASK-092 运行态验收兜底。
- 原始前提不成立（若 huaweicloud 已废弃）：B-0' 选 A'，085 退化为「回补 + 归档 tag」，其余卡照常。

## 3. 第三轮 · 双向钢人

**方案：镜像继续接受叠加（B'）**
- 支持：他线已产出 S0–S3 且单测全绿；叠加两次都是快进、未改写历史；Hark 不需读私有仓。

- 处置：A' 下 085 = 回补一次 + 给 huaweicloud 打归档 tag。
