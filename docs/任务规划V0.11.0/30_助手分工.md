### 标准 Git 流程（每张卡都照做）
1. 只用自己的独立克隆（如 `E:/Code/Aidean-ui`），远端只认 `origin = nevermeetagain/Aidean`，分支只推 `main`。
2. 开卡前：`git status` 必须干净 → `git fetch origin` → `git rebase origin/main`（或 `git pull --rebase`）。
3. 开发中：小步提交，一卡一提交（可多个，但提交信息以卡号开头）。
4. 推送前：再 `git fetch origin && git rebase origin/main` → 只跑与改动相关的门禁 + 全量 `tsc`/`lint`/vitest 一次 → `git push origin HEAD:main`。
5. 推送被拒（non-fast-forward）：重复第 4 步，**禁止** `--force` / `--force-with-lease`、禁止 merge 远端到本地后硬推。
6. 推送 403 / 认证失败：立即停手报用户，不碰凭据、不换远端、不推 `aideanew/Aidean`。
7. 冲突只在自己改过的文件里解；碰到别人（Hark）刚改的文件，停下来报 Hark。
