## 三、失败回退

- 任一卡核验 FAIL：在本目录 `25_执行记录.md` 追加 `Fix:` 条目（引用失败检查点），修复后**重验**，不得跳过进入下一卡（六步循环 VERIFY 的闭环要求）。
- B11-01 若外网与兜底均失败：降级为"仅补脚本入口 + 文档登记为运维前置"，并把运行态断言标 `待确认`，**不得**宣称 DEF-011-01 已闭环。
- **实际路径与预案不同**：源可达（HTTP 200）、且「自动兜底写值」被判定为违反 fail-closed 契约 → 改为显式 `--rate` 人工发布（见 deviation §一）。B11-01 未落入该回退分支。
- B11-02 若 e2e 出现因价格改动导致的失败：优先回退 seed 配比（而非改 e2e），除非确认该 e2e 断言本身依赖"全免费"这一错误前提。
- 任何卡若需要推翻已冻结契约（`packages/shared/src`），一律先升格为 `12_` 中的裁决项，不得直接改。
