## 3.1 复述与拆解

**一句话复述**（复核沿用 V0.1.0，无变化）：Aidean 是面向开发者/企业的 AI 模型与云服务「天梯图」选型平台——免费看排行与详情，付费按次对比测评；以「一次充值、统一计费网关」打通多家模型平台调用；并作为生态子平台（AideanWiki / AideanBot·BotHot / AideanFleet / AideanThesis / SkillsCloud）的门户与 OIDC 身份提供方。

**角色与边界**：访客 / 注册用户（NORMAL）/ Pro / Max → `(site)` + `/user/*` + 网关；MODERATOR / ADMIN / SUPER_ADMIN + 30 权限域 → `/admin/*`；本仓只做子平台展示页 + OIDC IdP，子平台源码在各自仓库。

**本次需求拆解**（用户 2026-10-14 指令）：
1. 拉取并钉住快照（01）；2. **穷尽核对每一条需求与真实代码**，产出唯一的需求→状态→任务矩阵（03a，本轮核心交付）；3. 在 V0.1.0 基础上复核、增删任务（17 差异表）；4. 核心/高难度（尤其 UI）标为 Hark(主Agent)，中/简单标为外部Agent；5. 落盘 `docs/任务规划V0.2.0/`、推送、打包。

**需求来源（全量检索，非抽样）**：需求文档 v1.14 全文；项目需求更新分析 v7.1；未完成事项目录 v2.35 全部编号行（脚本解析 L1–L600，状态列 ⬜/❌/🟡/⏸）；待执行任务大纲 v7.6；待决事项决策说明 v1.2 §四；控制台7项反馈大纲 v1.5 §7.3；26 个 specs 的 tasks/checklist 未勾项（脚本计数）；CHANGELOG [Unreleased]；开发流程 §五；AGENTS.md；用户本次端口口径。
