# 合作产品内容配置

> 版本: v1.0 | 更新: 2026-09-17 | 变更: 登记 partners-only 实装、媒体边界与未完成运行验收

## 范围与决策

[合作产品](../../governance/术语表.md#合作产品)仅指 `/partners` 的学历助手、论文辅导、科研知识库三个展示位。使用既有 [SystemConfig](../../governance/术语表.md#systemconfig)，不新增 Product 字段、产品记录或数据库迁移；原因是 `/products` 会读取全部 ACTIVE Product，混用会污染平台产品列表。`/admin/products` 不负责合作内容。

管理员在 `/admin/configs` 的 `SiteContentEditor` 编辑，经既有 `GET/PUT /api/v1/admin/configs` 保存。固定键依次为 `partners.education`、`partners.paper`、`partners.research`，每键保存一份 JSON 字符串。接口与错误码权威见 [API 契约](../../architecture/API接口文档.md#partner-content-api)，隔离约束见 [API 架构](../../architecture/API架构设计方案.md#partner-content-architecture)。

## 内容与媒体

| 字段 | 约束 |
|---|---|
| enabled | 布尔，缺省 true；合法 false 不回退为展示 |
| title | 去首尾空白，1–120 字符 |
| subtitle / description / notes | 分别最多 200 / 2000 / 1000 字符，可空 |
| coverUrl / videoUrl | 可空，单条最多 500 字符 |
| images | 最多 6 条非空图片 URL，每条最多 500 字符 |

JSON 拒绝未知字段；整体字符串最多 10000 字符。图片仅 PNG/JPEG/WebP/GIF/AVIF，视频仅 MP4/WebM；根据 URL 路径后缀校验，不证明远端真实 MIME 或文件字节大小。允许 HTTP(S)（禁止凭据）或 `/images/`、`/media/` 安全本地路径；拒绝协议相对路径、反斜杠、控制字符、目录穿越等。浏览器原生加载媒体，不通过服务端代理、抓取或 Next 图片优化获取任意 URL。不提供上传、转码、文件容量检测。

[SafeImage](../../governance/术语表.md#safeimage) 位于 `apps/web/components/common/SafeImage.tsx`，命名导出；必填 `alt`，可选 `src`、`ratio=video|square|photo`、`fit=cover|contain`、`className`、`placeholder`。比例分别 16:9、1:1、4:3；square 最大宽 200px，其余 960px。默认 cover；无图、非法 URL 或加载失败呈现文字占位。视频 16:9、最大高度 432px、最大宽度使用 max-w-3xl，controls/playsInline/preload=none，不自动播放。

## 读写与管理交互

- GET 返回完整配置元数据，缺行用注册表默认值；没有更改既有响应形态。
- PUT 管理员守卫后校验 JSON，再 upsert 与审计，成功触发 `/partners` revalidate。每个产品独立保存。
- 公共页 force-dynamic，只查询这三个键；逐项严格解析。缺失、非法内容或查询失败回退对应默认资料；合法 enabled=false 隐藏，全关闭显示空态。
- 默认文案仅说明资料待完善，不宣称上线、资质、奖项或效果。合作咨询邮箱当前硬编码 `591547726@qq.com`，并非已实现关于页配置。
- 表单用描述性中文标签，加载成功前不可保存；封面、多图、备注及视频均可编辑。失败提示不等于保存成功。
- seed 仅同步默认声明，未执行；实际使用缺省即可展示，管理员显式保存才落库。部署本功能不需要运行 seed、迁移或生成 Prisma client；既有 seed 有破坏性操作，不作上线命令。
