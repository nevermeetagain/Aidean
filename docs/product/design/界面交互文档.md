## 一、全局导航规范

- **一级导航（八项）**：首页 / 模型 / 产品 / 价格 / 文档 / 路线图 / 合作 / 关于；「产品」悬停或键盘聚焦展开二级下拉（纯 CSS 实现，无客户端 JS），子项 AideanWiki 跳 `/products#aideanwiki` 锚点区块；**Logo 点击回首页**。
- **Logo 居左**，文字统一 "Aidean"；导航栏居左，与 Logo 保持间距。
- **用户设置居右**：主题 + 语言 + 登录/注册（+ 余额/头像）。
- **搜索框唯一位置**：仅在顶部导航栏；筛选栏内禁止第二个搜索框。
- **导航栏上方**：不得出现数据条 / 统计 / 日期等元素。
- **多套浅色主题**：整体永远浅色，不提供深色模式；主题切换为浅色主题（主色色相）间切换，即时生效。
- **默认中文**；语言切换（中/英）即时生效。
- **页脚（v1.9）**：产品 / 资源 / 公司三栏共占整体宽度 50% 居中（窄屏退化为全宽堆叠）；版权行居中；**天梯图页面（/models、/ladder）不渲染页脚**。
- **一级页面页头卡契约（v2.10，全量统一）**：所有一级内容页（`/products`、`/pricing`、`/docs`、`/roadmap`、`/partners`、`/about`、`/news`、`/providers`）的页头**必须**为「产品化页头卡」`PagePlaceholder`（面包屑胶囊 + 主色竖条 + 大标题 + 网格纹理氛围层）；**禁止**裸 `<header class="mb-12 max-w-2xl">` 等自定义页头。首页不适用（区块化长页）。运行取证（2026-09-23）：7 页 `breadcrumbCard`/`gridTexture` 均为 True。
- **内容页缓存策略（v2.10）**：一级内容页默认 **ISR（`export const revalidate = 300`）**——使 `<Link>` 预取得以复用、消除首入须先看 `loading.tsx` 骨架的体感卡顿；仅当页面消费 `searchParams`（如 `/news?cat=`）时才用 `export const dynamic = "force-dynamic"`。后台配置/数据保存后须经 `revalidatePath("<路径>")` 主动失效（见 `app/api/v1/admin/configs/route.ts` 的 `applyConfig`）。天梯图页（`/models`、`/ladder`）沿用其自带缓存口径。

## 二、首页结构（区块化长页）

- **自上而下区块顺序**：多级菜单栏 → banner 图 → 平台介绍 → 模型 → 产品 → 路线图 → 合作 → 关于（关于置底）。
- **滚动动态加载**：往下翻时区块随滚动进入视口动态加载/渐显（参考 SiliconFlow），加载自然不突兀；禁止一次性渲染全部区块。
- **正文留白**：banner 之下的正文区块左右统一留白（容器最大宽度居中，规格见《UI 设计文档》）。
- **模型部分**：模型天梯图、模型对比、模型可使用 API 对应的平台详情页入口、大模型云服务平台天梯图。
- **产品部分**：AideanWiki 知识库（原 AideanRag）/ WeChatRag 自媒体知识库（含分级权益提示）/ SkillsCloud（标注"规划中"）。
- **合作部分**：合作企业 logo 多行排列、交替循环滑动——第一行从右到左、第二行从左到右，依此类推；悬停暂停，便于查看。
- **路线图部分**：产品路线图时间线（版本里程碑）；真源为共用组件 `components/site/RoadmapTimeline.tsx`（`ROADMAP_MILESTONES`），首页 `RoadmapSection` 与 `/roadmap` 共用同一份（v2.10 消除两处重复）。
- **关于部分**：置于首页最底部。

## 三、天梯图交互

### 3.1 版本与视图
- `/models` 页**首屏直达**：无面包屑 / H1 / 介绍文案，进入即见筛选栏与天梯图上半区（高分明星模型）。
- 筛选/排序/版本/视图切换工具栏**吸顶**（sticky top-0）：纵向滚动天梯图时始终可达。
- **工具栏三行制（v2.3 纵向重排）**：吸顶工具栏自上而下三行——**行1**：专业版 / 应用版 切换（即时，左）｜五组筛选栏（右）；**行2**：天梯图（默认）/ 柱状图 切换（左起首位）+ 排序栏 + **分度值下拉**（排序右方）+ 阵营开关（国外（左）/国内（右））；**行3**：「模型性能天梯图」标题（含副注）（左）+ 「数据更新于 …」时间戳（右）。

### 2.2 筛选栏（五组筛选项，v1.9）
- **快速筛选 chips 已移除**（v1.8）：最新 / 热门迁入标签组下拉**置顶**、冷门**置底**，作为内置伪标签（随 tags 进 URL 可回放）；三者互斥（勾选替换其余伪标签、再点取消），用户显式改排序时剥离伪标签。透镜语义不变：热门=服务端现行排序（综合分降序）、最新=publishedAt 降序、冷门=综合分升序；透镜为纯客户端重排、零请求（天梯矩阵图按分数档定位不受重排影响，柱状图按新序取 Top N）。原国外/国内 chips 升级为阵营开关（见 2.4）。
- **五组筛选（v1.9）**：类型 / 协议 / 测评 / 标签 / 时间，与排序栏同行。**开源下拉框已移除**——「开源 / 闭源」作为真实过滤标签并入标签组（勾选即过滤 `isOpenSource`，同选或未选=不过滤；旧 `isOpenSource` 参数仅作 URL 回放兼容）。
- 点击展开当前面板；点其他按钮收起当前、展开新面板（单次仅一个展开）。
- **各组面板首项为「不限」**：点击清空该组（未选时高亮）；未说明的组默认不限，**类型组默认「推理」**。
- **多选 / 单选语义（v1.9）**：类型、协议、标签、时间四组均**多选**（组内 OR、组间 AND）；**测评组单选**（exclusive：点选替换、再点取消）。
- **测评组（v1.8）**：首项「综合」**默认选中**——综合分口径 = 四维测评分数（官方/实测/评测/自测）的平均值；服务端对 benchmark 透传不过滤（综合=全量口径）。其余选项：MMLU / HumanEval / MATH。
- 协议选项（v1.7）：Anthropic Messages / OpenAI Chat Completions / OpenAI Responses API / Gemini Native generateContent / 自定义HTTP。
- 时间选项（v1.7）：不限 / 30天内 / 90天内 / 半年内 / 一年内 / 两年内（按 `publishedAt` 发布时间窗过滤，服务端生效；多选取并集窗口）。
- 选择**立即生效**，无确认按钮；首页数据走缓存。
- 面板不自动收起。

### 2.3 排序栏（五种）
- 位于筛选栏最右侧，宽 180px；默认"基准排序（综合评分）"。
- 自定义排序：输入公式实时解析（变量 + 运算符），错误提示不阻断其他排序。
- 筛选变更后保留当前排序方式；点击外部收起面板。
- **行2 布局（v2.3）**：天梯图/柱状图切换居行2左起首位，其后依次排序栏、分度值下拉、阵营开关（左起顺排、不两端对齐）。
- **分度值下拉（v2.1 口径）**：位于排序下拉右方，标签「分度值」——**相邻两行之间的性能差值（行距）**。选项 = 常见档位（0.1 / 0.2 / 0.5 / 1 / 2 / 5）∪ 后台配置默认值，**默认 = 后台配置**（`ladder_score_granularity`，SSR 注入）；切换为纯呈现层状态（客户端即时改档、零网络请求、不进 URL），**天梯图即时重排**（轴刻度密度与卡片档位随之变化）。

### 2.4 天梯图 / 柱状图
- 标题（v2.0 移位）：**「模型性能天梯图」**（原「性能天梯图」更名）+ 副注"卡片越靠上综合分越高 · 点击卡片查看详情"，自矩阵容器上方**上移至工具栏行3**，与「数据更新于 …」时间戳同行。
- 天梯图（快科技 CPU 天梯图式）：橙色渐变性能轴（上=高性能，带综合分刻度），**左=国外产品系列列、右=国内产品系列列**（按 `vendors.country=CN` 划分，系列名由模型名推导：ChatGPT/Claude/GLM/Qwen…，兜底厂商名）。
- **列排序=厂商优先级贴轴（v1.9）**：各系列列按所属厂商 `priority`（1-99，**数值越小优先级越高、离性能轴/分隔栏越近**，后台管理员可配）排序，同优先级按列内最高综合分降序、系列名兜底；左侧最强优先级系列置于最左（开屏即明星系列），右侧最强优先级系列紧贴性能轴。
- **性能轴固定颗粒分割（v2.0 修订）**：轴刻度/卡片分数档按**固定颗粒值**分割（默认 0.1，即 98.9 与 98.8 为相邻档位；不再按量程自适应），后台配置为默认值，用户可经「分度值」下拉即时改档（见 2.3）；档位以整数百分位参与运算，规避浮点漂移。**全量程（v2.0）**：性能轴量程恒为 **0 → 顶格**（顶格=最高综合分向上取整到颗粒整数倍）——**下拉到底部时轴分恒达 0**；**每档一枚刻度且全部标注性能值**（顶=顶格、底=0，不再按高度抽稀；首格标签列线下方对齐避免吸顶裁切）。
- **轴位三态（v1.8）**：图例「国外（左）/国内（右）」色块升级为**可点击开关**（仅 models 双侧数据，勾选=彩色、取消=白色空心格）——只勾国内 → 性能轴/分隔栏**居左**；只勾国外 → **居右**；双勾或双不勾 → **居中**（双不勾仅呈现轴与刻度、两侧留白）。开关仅呈现层显隐，布局高度与轴刻度按全量数据推导、切换不跳变；stations 榜与单阵营数据不受开关影响（恒对称布局）。
- **卡片两行制（v1.8）**：行1=模型名；行2=名次徽章（Top1 实底）+ 综合分·说明（价格/响应速度等说明口径不变）。**名次支持同分并列**（服务端 competition ranking：1,2,2,4），悬停 title 显示完整参数（含并列名次）；点击跳模型详情。
- 卡片按综合分落入固定颗粒档（列内碰撞自动下移防重叠）。
- **无限滚动（v2.0 修订）**：矩阵容器**下拉近底部（240px 阈值）自动追加加载下一页**（offset/limit 分页，页大小 100），无需翻页；**自动续载链（v2.0）**——全量程布局下容器 scrollHeight 不随追加增长，每页数据到达后复检离底距离、仍近底部则续拉，直至穷尽；**整页零新增（去重后）即判定穷尽**防空转。加载中底部显示「加载中…」，穷尽后底部常驻**「到底了 · 已展示全部 N 个条目」**（恒呈现于轴分 0 处）。
- **列宽自适应**（v1.7）：各列 flex 均分容器宽度，**不支持横向滚动**；列头吸顶（限高纵向滚动容器）。阵营开关隐藏某一侧时，该侧留白、轴位按三态规则移位。
- 云服务榜无国别 → 退化为对称布局（每站一列，按最强分对半分列轴两侧）。
- 柱状图：横轴模型、纵轴评分（0–100）；点击柱体跳对应模型详情。
- 两视图共用同一份数据，切换不重复请求。

## 七、用户控制台（统一计费网关）

- **入口**：登录后右上角头像 → 控制台；一级导航不新增入口。
- **页头**：产品化页头卡（面包屑胶囊 + 主色竖条 + 大标题「控制台」），与其他一级页面（产品/价格/文档等）同构；页头下方保留三张核心信息卡（余额 / 等级 / 今日 Token 用量）。
- **功能板块切换**：页头下方为五个功能板块标签栏（模型配置 / 免费额度 / 平台密钥 / 自有密钥 / 调用测试台），点击切换、同屏仅呈现当前板块；非活动板块以 `hidden` 保持挂载——表单草稿与调用台状态不丢失；支持 `?tab=` 深链（config/quotas/platformKeys/stationKeys/playground）与标签栏左右方向键导航，默认激活「模型配置」。
- **双形态切换**：「通用版 / 专业版」分段切换器右置于「模型配置」板块标题行（其余板块不出现）；两形态共享同一份底层路由配置，切换无副作用、即时生效，选择经 localStorage 持久化。
- **通用版**：用户将具体模型绑定至四个等级档（Opus / Sonnet / Fable / Haiku），可不配置；固定序 Opus > Sonnet > Fable > Haiku；当前档位以轻量徽标在对话入口透出。
- **专业版**：具体模型优先级列表（1~99，1 最高），支持输入 / 拖拽调整；等级默认映射 Opus=1 / Sonnet=2 / Fable=3 / Haiku=4，可覆盖。
- **Free 等级**：由系统后台定义默认免费模型，控制台自动加载为最低优先级，只读展示（含剩余额度），不可配置。
- **自定义渠道**：卡片式管理（名称 / base_url / API Key / 格式选择 OpenAI 或 Anthropic），保存时自动测连通并回显结果；标注"费用自理、免费中转"。
- **免费额度**：「免费额度」板块展示各 free 模型剩余额度与刷新周期（天 / 周 / 月），进度条呈现。
- **兜底提示**：余额不足且未配置私有模型自动切 free 模型时，以响应内轻提示告知（不弹窗、不阻断对话）。
- **价格透明**：控制台与对话计费明细仅展示上游官方单价与实际 Token 数；平台加价率与 Token 倍率任何界面不可见。
- **核心信息特效**：余额、等级、用量等核心信息卡片背景应用「流动模糊渐变」动效（视觉规格与实现方案见《UI 设计文档》§7）；`prefers-reduced-motion` 时降级为静态渐变。


## 八、管理控制台（(admin) 路由组）

- **入口与守卫**：`/admin` 起独立路由组，与前台 `(site)` 头尾完全隔离；RSC 守卫验签 + 回库复核角色（ADMIN / SUPER_ADMIN），未登录 → `/admin/login?redirect=…`，非管理员 → `/admin/login?denied=1`（不暴露后台存在）。封禁/停用管理员在 API 层同样被 `requireAdminApi` 拒绝（10008）。
- **视觉口径**：浅色冷色外壳——页面底 `slate-100/80`、内容白卡分层、主色（indigo）强调；顶栏白色半透明 + backdrop-blur。全站不提供深色模式（`dark:` 变体已清零，TierBadge 为最后一处残留并已于 v2.4 移除）。
- **布局**：左侧 `AdminSidebar` 两级手风琴（运营管理 / 财务与配置两组，组头 aria-expanded；收起态图标纵列带 aria-label/title，localStorage 持久化）；右侧顶栏（身份 + 角色徽标 + 返回主站 + 退出）+ 内容区。无前台 Header/Footer。
- **登录页**：`/admin/login` 居中极简白卡（与前台 AuthForm 共用 LoginSchema 与 `POST /api/v1/auth/login` 契约，但视觉独立）；错误行内红条提示；`denied=1` 显示琥珀色「权限不足」提示。
- **概览**：四统计卡为 prisma 实时聚合（用户/模型/厂商/兑换码）+ 快捷入口。
- **用户管理**：分页表格（搜索/等级/状态/角色/余额列）；行操作 = 调 tier、封禁/解封（封禁即 `tokenVersion++` 全端令牌失效）、详情抽屉。
- **用户详情抽屉**：右侧滑出白卡（`aside role=dialog`，aria-label 含邮箱），余额只读 + 「余额调账」表单（金额 + 备注必填）；提交调账进入**二次确认**（文案含「不可逆」），确认后 POST `/api/v1/admin/wallets/adjust`；成功横幅「调账成功，当前余额 ¥x」在随后的列表刷新中保留（v2.4 修复：此前会被 load 成功回调清空）。
- **其余管理域**：模型上下架（翻转触发 `/models` revalidate）、提供商 CRUD（软删 + code 查重）、产品/套餐 CRUD（元↔分互转、有码引用仅 DISABLED）、兑换码批次（≤500/批 + CSV 导出 + 单码禁用）、站点配置（PUT 即时生效）。全部写路径落 audit_logs。

## 九、等级徽章（TierBadge）

- 位置：前台 Header 会话区（登录后头像旁）；NORMAL 中性灰 / PRO 品牌蓝 / MAX 琥珀金（浅色语义色阶，无 dark: 变体）。
- 行为：SSR 数据驱动；匿名用户不渲染徽章（HTML 中无 `tier-badge` 标记）；容器固定高度 h-5，登录态出现时不引起布局跳动。

## 十二、资讯后台化（news-admin-cms，2026-09-18）

- **列表 `/news`**：DB 驱动的 SSR 列表页（force-dynamic），条目来自 NewsItem（见 [术语表 · NewsItem](../../governance/术语表.md#newsitem)）；置顶条目恒为首位并带琥珀「置顶」徽标（Pin 图标），满足《免费模型合集》随时可置顶的需求。列表顶部为分类筛选 chips——「全部」+ [资讯分类](../../governance/术语表.md#资讯分类) 白名单逐项，经 `?cat=` 深链可分享，非法分类值按「全部」渲染不报错；空分类给出空态提示而非空白页。
- **详情 `/news/[slug]`**：后台写的 Markdown 在服务端渲染后展示于 `.news-content` 排版容器（标题层级、列表、表格、代码块统一样式）。图片尺寸纪律在服务端样式层：`max-width:100%`、`max-height:480px`、`object-fit:contain`——原图无论多大都不撑破版式（「把用户当最笨的小孩」约束）。页尾附同分类相关推荐（≤3 条）。未知 slug 或草稿直达时渲染 scoped `not-found.tsx`：文件图标 + 「页面不存在」+「该资讯尚未发布，或已被管理员移除。」+ 返回资讯列表链接，仅此段落触发，不影响其他页面 404。
- **后台 `/admin/news`**（侧边栏「运营管理 → 资讯管理」）：全量表格含草稿（列 = 标题/分类/置顶徽标/状态/发布日期），行操作 = 置顶⇄取消置顶、发布⇄转草稿、编辑、删除；顶栏「新建资讯」计数行显示「共 N 条资讯（置顶恒排最前）」。编辑弹层内正文为 Markdown 原文文本域，编辑↔预览两态切换（预览走与前台同一渲染管线），保存后再次打开回读的是库内 Markdown 原文而非 HTML；删除走 `role=alertdialog` 二次确认，文案明示「前台 /news 立即消失，操作留审计」。
- **口径变更**：本页取代 §十一 中「资讯=静态 items.ts + SSG」旧描述；渲染与 XSS 边界见 [API架构设计方案 §7.3](../../architecture/API架构设计方案.md#news-architecture)。运行验收现状见《[验收复核-20260917](../../archive/验收复核-20260917.md)》§2.4。
