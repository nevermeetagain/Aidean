# 支付渠道集成指南

> 版本: v1.0 | 更新: 2026-09-17 | 变更: 首次建立（CLOSER-07 续轮）

## 1. 现状

`lib/features/billing/service.ts` 的 `channelOf(payMethod)` 函数：

```typescript
function channelOf(payMethod: "WECHAT" | "ALIPAY"): PayChannel {
  if (process.env.NODE_ENV === "production") {
    throw new ApiError(ERROR_CODES.BAD_REQUEST, "支付渠道尚未接入");
  }
  return devMockChannel; // dev/test：自动确认，payUrl=/user/balance?mockOrderId=xxx
}
```

- **dev/test**：`devMockChannel` 自动确认充值（`createPayment` 返回 mock URL，`confirmPayment` 直接到账）
- **production**：抛 `40000 "支付渠道尚未接入"`

## 2. 集成点

### 2.1 PayChannel 接口（`billing/types.ts`）

```typescript
interface PayChannel {
  createPayment(orderId: string): Promise<{ payUrl: string }>;
  confirmPayment(orderId: string): Promise<{ paid: boolean; amountMinor: bigint }>;
}
```

### 2.2 替换 channelOf（`billing/service.ts:200`）

```typescript
function channelOf(payMethod: "WECHAT" | "ALIPAY"): PayChannel {
  if (process.env.NODE_ENV !== "production") return devMockChannel;
  switch (payMethod) {
    case "WECHAT":  return new WeChatPayChannel();
    case "ALIPAY":  return new AlipayChannel();
  }
}
```

### 2.3 微信支付（#5/#6）

| 凭据 | 环境变量 | 说明 |
|---|---|---|
| App ID | `WECHAT_APP_ID` | 公众号/小程序 AppID |
| 商户号 | `WECHAT_MCH_ID` | 微信支付商户号 |
| API Key | `WECHAT_API_KEY` | 商户平台设置的 API 密钥 |
| 证书路径 | `WECHAT_CERT_PATH` | apiclient_cert.p12 路径 |
| 回调地址 | `WECHAT_NOTIFY_URL` | `https://your-domain/api/v1/billing/wechat/notify` |

**实现清单**：
1. 安装 `wechatpay-node-v3`（或直接用 `node:crypto` + `fetch` 签名）
2. `WeChatPayChannel.createPayment`：调统一下单 API → 返回 `weixin://wxpay/bizpayurl?pr=<code_url>`
3. `WeChatPayChannel.confirmPayment`：接收异步回调（POST `/api/v1/billing/wechat/notify`）→ 验签 → 更新订单状态
4. 二维码路由：`/api/v1/billing/qrcode?orderId=xxx` → 生成 QR 图片（`qrcode` npm 包）

### 2.4 支付宝

| 凭据 | 环境变量 | 说明 |
|---|---|---|
| App ID | `ALIPAY_APP_ID` | 开放平台 AppID |
| 私钥 | `ALIPAY_PRIVATE_KEY` | RSA2 私钥 |
| 公钥 | `ALIPAY_PUBLIC_KEY` | 支付宝公钥 |
| 回调地址 | `ALIPAY_NOTIFY_URL` | `https://your-domain/api/v1/billing/alipay/notify` |

**实现清单**：
1. 安装 `alipay-sdk`（官方 Node SDK）
2. `AlipayChannel.createPayment`：调 `alipay.trade.page.pay` → 返回支付宝跳转 URL
3. `AlipayChannel.confirmPayment`：接收异步回调 → 验签 → 更新订单

## 3. 回调路由（新增）

```
POST /api/v1/billing/wechat/notify  → WeChatPayChannel 验签 + confirmPayment
POST /api/v1/billing/alipay/notify  → AlipayChannel 验签 + confirmPayment
GET  /api/v1/billing/qrcode?orderId=xxx → QR 码图片
```

## 4. 测试策略

- 单元测试：`vi.mock` WeChatPayChannel/AlipayChannel，验证 `channelOf` 分发逻辑
- 集成测试：沙箱环境（微信支付沙箱 / 支付宝沙箱）端到端
- dev 回归：`NODE_ENV=development` 仍走 `devMockChannel`，现有测试不受影响

## 5. 安全注意

- 凭据只经环境变量注入，**不入库不入仓**
- 回调验签必须校验签名 + 金额 + 订单号
- `confirmPayment` 幂等（同一 orderId 只确认一次，billing 域已有 `balanceHold` 幂等兜底）
