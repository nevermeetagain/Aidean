# ADR-0013：语义色令牌与主题——单一 --color-* 命名、六族语义类、三主题对比度、工具链同版本

> 状态：已接受 | 日期：2026-10-23 | 关联：V0.12.0 T120-25 / T120-26 / T120-27、UX-13（EVD-UX-01）、UI设计文档 §2

## 一、背景

1. `apps/web/app/globals.css` 新旧命名并存：`@theme` 暴露 `--color-primary/background/card/border…`，组件里又大量直接写 `bg-[var(--primary)]`；为修文字对比度，UX-13 在主题层把 Tailwind 的 `slate-400/500` 重定义成别的颜色，类名与实际颜色脱钩。
2. 只有 `danger` 一个状态色令牌，success / warning / info 散落为 Tailwind 原色。
3. 焦点环 `--ring` 在 teal / orange 主题取亮色（teal-400 / orange-500），对页面底只有 2.38 / 2.68:1，不满足 WCAG 1.4.11 的 3:1。
4. 工具链分叉：`packages/ui` 声明 tailwind ^3.4.10、`packages/ui` 与 `packages/shared` 用 vitest 3.2.7，而 `apps/web` 是 tailwind 4.0.0 / vitest 2.1.9；同一仓库两套测试运行时。

## 二、决策

### 2.1 一套命名、六族语义类
`@theme` 只以 `--color-*` 输出以下语义令牌，新代码只用这些类（`bg-surface`、`text-fg-muted`、`border-line-strong`、`bg-accent-strong text-on-accent`、`text-danger bg-danger-soft`…）：

| 族 | 令牌 | 用途 |
|---|---|---|
| surface | `surface` / `surface-raised` / `surface-sunken` | 页面底 / 卡片与浮层 / 凹陷区 |
| fg | `fg` / `fg-muted` / `fg-subtle` | 主文字 / 次要文字 / 占位与弱提示 |
| muted | `muted` / `muted-fg` | 次要面及其上的文字 |
| line | `line` / `line-strong` | 装饰分隔线（1.4.11 豁免）/ 输入框等交互边界（≥3:1） |
| accent | `accent` / `accent-strong` / `accent-soft` / `on-accent` / `ring` | 装饰亮色（渐变、描边，不承载文字）/ 实底按钮、链接、选中 / 浅底 / 实底上的文字 / 焦点环 |
| status | `success` `warning` `danger` `info` 及各自 `-soft` | 状态文字或图标 / 状态浅底 |

- 原始变量在 `:root`；`[data-theme]`（挂在 `html`）只覆盖 `accent` 族与 `ring`；`info` = `accent-strong`，因此随主题切换。success / warning / danger 跨主题固定（语义色不随品牌色相漂移）。
- `--color-accent` 保留「装饰亮色」原义，避免现有 `to-accent`、`bg-accent` 渐变与描边在本卡内变色；需要承载文字或实底时用 `accent-strong`。

### 2.2 旧名降为弃用别名（保留一个版本）
9 个旧名保留并指向新名，带 `@deprecated` 注释，V0.13 删除；用法由 T120-27 codemod 迁走：
`background→surface`、`foreground→fg`、`primary→accent-strong`、`primary-foreground→on-accent`、`muted-foreground→fg-muted`、`card→surface-raised`、`border→line`、`slate-400→fg-subtle`、`slate-500→fg-muted`。
原始变量名（`--primary`、`--border`…）同样作为别名保留，`[var(--x)]` 写法不受影响。名单的 TS 镜像为 `@aidean/ui` 的 `DEPRECATED_TOKEN_ALIASES`，由单测锁定 9 个。

### 2.3 焦点环改用 accent-strong
三主题 `--ring` = `accent-strong`。这是本卡唯一的可见变化：teal / orange 主题的焦点环由亮色变为品牌深色。

### 2.4 工具链同版本：向 apps/web 对齐
`packages/ui`、`packages/shared` 改用 vitest ^2.1.9（`@vitest/coverage-v8` 2.1.9），`packages/ui` 的 tailwind peer 改为 ^4.0.0。选「降到 web 的版本」而不是「全仓升 vitest 3」：web 有 1800+ 用例，升级属于独立迁移，不应搭在令牌卡上；两个小包降级后全部用例照常通过。全仓升 vitest 3 另起一卡。

## 三、对比度表（三主题 × 六族，WCAG 2.1；正文 ≥4.5，图形与大字 ≥3）

| 族 | 组合 | teal | indigo | orange | 门槛 |
|---|---|---|---|---|---|
| surface | `fg` on `surface` | 17.06 | 17.06 | 17.06 | 4.5 |
| fg | `fg-muted` on `surface-raised` | 6.23 | 6.23 | 6.23 | 4.5 |
| muted | `muted-fg` on `muted` | 5.68 | 5.68 | 5.68 | 4.5 |
| line | `line-strong` on `surface-raised` | 3.19 | 3.19 | 3.19 | 3 |
| accent | `on-accent` on `accent-strong` | 5.47 | 6.29 | 5.18 | 4.5 |
| status | `danger` on `surface-raised` | 4.83 | 4.83 | 4.83 | 4.5 |

补充（不计入 18 组）：`success` 5.02、`warning` 5.02、`info` = accent-strong（5.47 / 6.29 / 5.18）均 ≥4.5；`ring` on `surface` 改后 5.23 / 6.01 / 4.95（改前 teal 2.38、orange 2.68）。

## 四、备选与否决

| 备选 | 否决理由 |
|---|---|
| 一次性删除旧名并全量替换 | 触及 140+ 组件文件，属 T120-27 codemod 的范围；本卡只立底座 |
| `--color-accent` 改为品牌深色 | 现有渐变与描边会在本卡内整体变暗，违背「本卡不改视觉」 |
| 全仓升 vitest 3 | 见 2.4 |

## 五、后果

- 正面：一套命名；状态色有令牌；焦点环达标；三个包同一测试运行时。
- 代价：一个版本内新旧名并存；`packages/ui/tailwind.config.ts`（v3 兼容预设）已无消费方，由 T120-26 / T120-27 一并清理。
