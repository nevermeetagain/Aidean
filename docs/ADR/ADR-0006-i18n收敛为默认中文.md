# ADR-0006：i18n 收敛为默认中文

> 状态：已接受 | 日期：2026-09-22 | 关联：需求文档 §五.1

## 一、背景

需求文档 §五 全局强约束第 1 条明确：「多套浅色主题……默认中文」。

项目历史中曾规划双语（中/英）支持，但从未实装——`i18n` 目录不存在，`next-intl`/`next-i18next` 均未在 `package.json` 中声明，所有 UI 文案为硬编码中文。

## 二、决策

**确认收敛为默认中文，不引入 i18n 框架。**

理由：
1. 目标用户为国内开发者和企业，中文是唯一使用场景。
2. 引入 i18n 框架会增加翻译维护成本和 bundle 体积，当前 ROI 为负。
3. 需求文档已明文「默认中文」，此 ADR 将该隐含约束显式化。

## 三、影响

- 不安装 `next-intl` 或任何 i18n 库。
- UI 文案保持硬编码中文，不抽 `t()` 函数。
- 如未来需要国际化，需新建 ADR 推翻本决策。
- API 响应的错误消息保持中文（与 `ERROR_CODES` 的 message 字段一致）。
