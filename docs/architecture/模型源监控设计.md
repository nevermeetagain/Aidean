## 1. 目标与边界
- 一句话：**每个源每天一次目录快照 → 按源观测 → diff 出变更事件 → 后台可管、前台可查**。
- 只读第三方**公开或授权**的目录/文档接口；不抓需登录/反爬/验证码页面；不代用户调用第三方付费接口（U-M3 批准的探针预算除外）。
- 不替代 `lib/sync`（写 AiModel/ModelPrice 的天梯主链路）与 `lib/discovery`（发现未知平台）；监控只写自己的 4 张表，**不自动合并**到 AiModel、**不自动 promote** 中转站。

## 3. 数据流
```
ScheduledScript(15 2 * * *) → run-due → monitor_catalogs.ts
  └─ for source in monitoring_sources(enabled, deleted_at IS NULL):
       collector = registry[source.key]            # 无 collector 的源 seed 即 enabled=false（E9-08）
       fetchCatalogText(endpoint)                   # safeFetch（SSRF 三层防护）+ 4MB 封顶 + 30s 超时
       sha256(raw) → catalog_snapshots              # UNIQUE(source_id, raw_sha256)：同哈希直接返回，不产生事件
       normalize(raw) → ProviderModelObservation[]  # upsert (source_id, external_model_id)
       detect(prev, curr) → catalog_change_events   # UNIQUE(snapshot_id, normalized_model_id, kind)
       monitoring_sources.last_* ← 结果             # 单源失败只记本源 last_error，继续下一个
```

## 4. 归一规则（冻结）
- `normalizedModelId`：小写 → 去 `vendor/` 前缀（取最后一段）→ 去 `:free|:batch|:beta|:thinking` 等变体后缀（实现另含 OpenRouter 变体 `:extended|:nitro|:floor|:online|:exacto`）→ 空白转 `-`。只用于关联展示。
- 价格：**原币 + 单位**（`price_unit`：`usd_per_1m_tokens` / `cny_per_1m_tokens` / `usd_per_request` / `ratio`），不做汇率换算（U-15 未决）；缺字段、负数（如 OpenRouter 路由器动态价 `-1`）、非 token 计价一律 `null`，不推断。
  - OpenRouter：`pricing.prompt/completion/input_cache_read` 为 USD/token 十进制字符串 → 字符串精确 ×1e6。
  - AIHubMix：`pricing.input/output/cache_read` 为 USD/1M（与 `pricing_lines[].unit=million_tokens` 互证），阶梯价取基础档；`pricing=null`（按张/按字符）→ null。
  - Quanzil `/api/pricing`：New API 倍率体系，`model_ratio=1 ⇔ $2/1M`；按次（`quota_type=1`）→ `usd_per_request`；分组倍率不并入（挂牌价）。
- `vendorHint` 只作线索（REQ-M-014），不作身份证据。

## 5. 事件规则
- `listed`：本次在列、上次不在列；`delisted`：上次在列、本次不在。
- `price_changed`：输入或输出价 |Δ| ≥ 1%（`PRICE_CHANGE_THRESHOLD_PCT`），单位不同不比较。
- `model_first_seen`：normalizedModelId 在所有源观测中首次出现 → 同时写 EvidenceChain（discovery/aggregator）。

## 6. 存储、保留、性能
- 原始响应**不落盘**：仅 sha256 + 字节数 + ≤2KB 采样。保留：快照 180 天、事件 365 天、观测常驻（清理任务待 30 天体量基线后再立卡）。
- 量级：5 源 × 每日 ≤1,000 条观测 upsert（2026-10-19 实测 OpenRouter all 视图 686 条/≈1.0MB、AIHubMix 858 条/≈0.96MB、Quanzil 331 条/≈0.53MB）。
- 前台 offerings 走 Redis 600s 缓存。

## 8. 安全与凭证
- 外连统一 `lib/security/url-policy`（assertSafeUrl / safeFetch / readCappedText）。
- keyed 源凭证只走 env `MONITOR_KEY_<SOURCE>`，不进仓库/日志/快照；缺失 → `50012 MONITOR_SOURCE_CREDENTIAL_MISSING`（HTTP 503）。
- `mapped_entity_id` 为 uuid 列，而 `model_providers.id`/`api_stations.id` 为 text（uuid7 字符串）：只存实体 id、不存 code，联表 `::text`（TASK-068 开工前置 U-24）。
