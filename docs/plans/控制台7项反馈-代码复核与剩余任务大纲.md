## 一、对原始对齐表的修正（证伪清单）

> 原则：现象描述可信，根因推断必须回到代码与编译产物验证。以下 5 条经实测推翻或补正。

### 修正 1 — P3-②「tailwind-merge 冲突合并」不成立

- 原始论断：`cn` 经 tailwind-merge 合并，`bg-transparent` 与 `bg-primary` 冲突去重。
- 反证：`packages/ui/src/lib/cn.ts` 为**手写字符串拼接**，注释原文「后续如需冲突消解可替换为 tailwind-merge」。`tailwind-merge` 仅在 `apps/web/package.json:51` 声明，**未被 `cn` 使用**。
- 结论：`bg-transparent` 与 `bg-primary` **同时保留在 class 属性上**，胜出者由样式表中的规则顺序决定，而非 twMerge 仲裁。

### 修正 2 — P3-③「`--primary-foreground` 未声明」不成立

- 原始论断：`globals.css` `@theme` 只声明 `--color-primary-foreground`，未声明 `--primary-foreground`。
- 反证：`apps/web/app/globals.css` → `:root { --primary-foreground: #ffffff; }`（`[data-theme]` 变体三个——indigo/teal/orange——亦各有一份；v1.3 勘误：原误记「四个」）。
- 补充机制澄清：`@theme` 中的 `--color-*` 是供 `text-primary-foreground` 这类**工具类**生成用的命名空间；而任意值类 `text-[var(--primary-foreground)]` 直接内联 `var()` 引用，走 `:root` 定义，**不依赖 `@theme` 映射**。二者是不同机制，原论断混淆了它们。

### 修正 3 — P3-④「编译产物中出现 0 次」不成立

- 原始论断：`.next/static/css` 中 `text-[var(--primary-foreground)]` 出现 0 次。
- 实测（`apps/web/.next/static/css/app/layout.css`，108,322 字节）：

```css
.text-\[var\(--primary-foreground\)\] { color: var(--primary-foreground); }
```

  生成成功，且被正确解析为 **`color`**（非 `font-size`）。同批生成的还有 `.text-\[var\(--primary-fg\)\] { color: var(--primary-fg); }`。
- 结论：Tailwind 4 对该任意值类处理正常，原论断的"无法编译"不成立。

### 修正 4 — P3 的真正根因（实测定位）

在 `layout.css` 中定位两条冲突规则的首字节偏移：

| 规则 | 首次出现偏移 | 声明 |
|---|---|---|
| `.bg-primary` | **41,885** | `background-color: var(--color-primary)` |
| `.bg-transparent` | **45,604** | `background-color: transparent` |

- 两者均为**单类选择器**，特异性相同 → **样式表中靠后者胜出** → `background-color: transparent` 生效。
- 因果链闭环：
  1. `cn` 不合并 → `class="… bg-transparent … bg-primary …"` 双类共存；
  2. Tailwind 4 输出顺序使 `bg-transparent` 在后 → 按钮背景**透明**；
  3. 文字色 `var(--primary-foreground)` = `#ffffff`（**白色**）；
  4. 父容器 `AuthForm.tsx:109` 为 `bg-white` → **白字落白底 → 呈现"空白圆角矩形"**。
- 该链路与用户截图现象**完全吻合**，且已被编译产物实证。

### 修正 5 — P5「日汇总表字段」与真实 schema 不符

- 原始论断：`usage_daily_stats` 含 `cachedTokens/completionTokens/reasoningTokens/latencyMs/statusCode/isStream`。
- 实测（`apps/web/prisma/schema.prisma:898-915`）：

```prisma
model UsageDailyStat {
  day DateTime @db.Date
  userId String
  model String
  requestCount     Int
  quotaMinor       BigInt
  promptTokens     Int
  completionTokens Int
  @@unique([day, userId, model])
  @@index([userId, day])
}
```

- 被错记的 `cachedTokens/reasoningTokens/latencyMs/statusCode/isStream` 属于 **`usage_logs` 明细表**（`schema.prisma:875-889`），不属于日汇总表。
- 连带缺口（原表未提）：日汇总表**亦无 `billingPath` 字段** → "按计费路径分布"报表无法由该表支撑。

- 事实：`packages/ui/src/components/ui/button.tsx:12` 用 `text-[var(--primary-fg)]`、`badge.tsx:11` 同；`button.tsx:15` 用 `bg-[var(--danger)]`。
