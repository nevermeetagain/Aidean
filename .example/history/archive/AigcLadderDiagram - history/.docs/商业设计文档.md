# AI模型天梯图平台 — 商业设计文档

> 版本：v1.0 | 创建日期：2026-03-30
> 核心原则：余额制（预付费），所有付费服务从用户余额扣除

---

## 一、商业定位

### 1.1 一句话定位

**AI模型与工具的「天梯图」评测平台** — 让开发者和企业扫一眼即完成选型决策。

### 1.2 目标用户

| 用户画像 | 核心诉求 | 付费意愿 |
|---|---|---|
| **AI开发者** | 选模型、选MCP/Skill工具、对比性能 | 高（生产力工具） |
| **企业技术决策者** | 评估模型性价比、选型方案 | 高（预算充足） |
| **AI爱好者/学生** | 浏览排名、了解趋势 | 低→中（试用即可） |
| **MCP/Skill 开发者** | 推广自己的工具、获取用户 | 高（平台推广） |

### 1.3 竞争差异化

| 维度 | 我们 | ai-bot.cn 等竞品 |
|---|---|---|
| 天梯图可视化 | ✅ 核心差异化（图表+排行榜+多维排序） | ❌ 简单列表 |
| 自定义排序 | ✅ 公式自定义排序 | ❌ 固定排序 |
| 扩展天梯图 | ✅ Skill/MCP/Agent/API站 4类 | ❌ 仅模型 |
| 实际对比测评 | ✅ 付费可实时多模型对比 | ❌ 无 |
| 试用机制 | ✅ 余额制，试用即扣费 | ❌ 无试用 |

## 二、MVP 定义（第一版上线范围）

### 2.1 MVP 核心原则

> **MVP = 全套天梯图 + 用户系统 + 余额系统**
> 其他所有功能（测评、对比、资源模块、产品模块、桌面端等）全部延后。

### 2.2 MVP 功能清单

| 模块 | 功能 | 优先级 | 说明 |
|---|---|---|---|
| **大模型天梯图** | 性能/性价比/开源/手机端 4类榜单 | P0 | 核心核心 |
| **大模型天梯图** | 专业版/应用版切换 | P0 | |
| **大模型天梯图** | 排行榜表格/柱状图切换 | P0 | |
| **大模型天梯图** | 6种筛选 + 5种排序（含自定义公式） | P0 | |
| **扩展天梯图** | Skills/MCP/Agent/API站 4类 | P0 | 复用天梯图框架 |
| **用户系统** | 注册/登录（邮箱+密码） | P0 | |
| **用户系统** | 余额充值（微信/支付宝） | P0 | |
| **用户系统** | 余额查询/消费记录 | P0 | |
| **导航与布局** | 首页+天梯图+模型详情+用户中心 | P0 | |
| **导航与布局** | 导航栏、响应式、主题切换 | P0 | |
| **SEO** | ISR/SSR、robots.txt、sitemap.xml | P1 | 上线前必备 |
| **数据管理** | 管理员后台（模型数据CRUD） | P1 | 后台简单版 |

### 2.3 非MVP（延后实现）

| 模块 | 延后原因 |
|---|---|
| 测评功能 | 需要对接外部API，成本高 |
| 模型对比 | 可用天梯图筛选替代 |
| 资讯模块 | 非核心，需要爬虫/同步 |
| 产品模块（RAGFlow） | 独立产品线 |
| 桌面端（Aidean Desktop） | Phase 2 |
| MCP/Skill 试用 | 需要线上开发环境 |
| 微信公众号 | 渠道优先级低 |
| 国际化（i18n） | 先做中文 |

## 三、收入模型

### 3.1 收入来源总览

```
┌─────────────────────────────────────────────────────────┐
│                    收入来源                               │
├─────────────────┬───────────────────┬───────────────────┤
│   余额充值       │   对比测评收费      │   工具试用收费     │
│   (预付费)       │   (按次扣费)       │   (按次扣费)       │
├─────────────────┼───────────────────┼───────────────────┤
│ 用户充值余额      │ 实际对比评测       │ MCP/Skill/Agent   │
│ → 所有付费操作    │ → 从余额扣除       │ /线上开发环境      │
│   从余额扣除     │                   │ → 试用从余额扣除   │
└─────────────────┴───────────────────┴───────────────────┘
```

### 3.2 收入来源详情

#### 来源一：用户充值余额（预付费）

| 充值档位 | 金额 | 赠送 | 实际到账 |
|---|---|---|---|
| 体验包 | ¥10 | — | ¥10 |
| 基础包 | ¥50 | ¥5 | ¥55 |
| 标准包 | ¥100 | ¥15 | ¥115 |
| 专业包 | ¥500 | ¥100 | ¥600 |
| 企业包 | ¥2000 | ¥500 | ¥2500 |

> 赠送比例随档位递增，鼓励大额充值。
> 充值方式：微信支付、支付宝。

#### 来源二：实际对比测评（按次收费）

| 测评类型 | 价格 | 说明 |
|---|---|---|
| 历史测评数据 | **免费** | 平台已有数据，所有用户可查看 |
| 实际对比测评 | **¥2/模型/次** | 自定义提示词，实时调用多模型对比 |

> 示例：用户选择3个模型进行对比测评 → 扣费 ¥6。

#### 来源三：工具试用收费（按次扣费）

| 试用类型 | 价格 | 说明 |
|---|---|---|
| MCP 工具试用 | **¥1~5/次** | 网页内试用，按调用复杂度计费 |
| Skill 试用 | **¥1~5/次** | 网页内试用，按执行复杂度计费 |
| Agent 试用 | **¥3~10/次** | 网页内试用，按任务复杂度计费 |
| 线上开发环境 | **¥0.5~2/分钟** | 在线IDE，按使用时长计费 |

> 试用价格由工具提供者设定，平台抽成 20%。
> 购买前可在网页免费预览工具介绍，试用才扣费。

#### 来源四：工具购买（MVP后期）

| 购买类型 | 说明 |
|---|---|
| MCP/Skill 授权购买 | 一次性买断或订阅，价格由提供者设定 |
| Agent 服务订阅 | 月度/年度订阅，价格由提供者设定 |
| 线上开发环境套餐 | 包月/包年，价格由平台统一定价 |

> 工具购买是后期功能，MVP 不实现。

## 四、付费/免费边界

### 4.1 核心原则

> **基础数据免费，增值服务付费。所有付费操作从用户余额扣除。**

### 4.2 免费 vs 付费矩阵

| 功能 | 未登录 | 免费用户（已登录） | 付费用户（有余额） |
|---|---|---|---|
| 浏览天梯图（所有类型） | ✅ | ✅ | ✅ |
| 筛选/排序（含自定义公式） | ✅ | ✅ | ✅ |
| 查看模型详情 | ✅ | ✅ | ✅ |
| 查看历史测评数据 | ✅ | ✅ | ✅ |
| 模型对比（参数表格） | ✅ | ✅ | ✅ |
| 实际对比测评 | ❌ | ❌（需充值） | ✅（¥2/模型/次） |
| MCP/Skill/Agent 试用 | ❌ | ❌（需充值） | ✅（按次扣费） |
| 线上开发环境 | ❌ | ❌（需充值） | ✅（按时长扣费） |
| 购买工具/服务 | ❌ | ❌（需充值） | ✅ |
| 收藏夹 | ❌ | ✅ | ✅ |
| 余额充值 | ❌ | ✅ | ✅ |
| 消费记录 | ❌ | ✅（登录可见） | ✅ |

### 4.3 余额扣费规则

| 规则 | 说明 |
|---|---|
| 最低余额 | 单次操作需余额 ≥ 该操作费用，否则提示充值 |
| 扣费时机 | 操作开始前预扣费，失败则退还 |
| 扣费记录 | 每笔扣费记录在消费记录中，含时间/金额/操作类型 |
| 退款 | 操作失败自动退款到余额；用户主动退款需联系客服 |

## 五、用户生命周期

### 5.1 用户转化漏斗

```
访客（浏览天梯图）
    ↓ 注册（免费）
免费注册用户（浏览+收藏+查看历史测评）
    ↓ 充值余额（¥10起）
付费用户（测评+试用+购买）
    ↓ 高频使用
活跃用户（持续充值+推荐他人）
```

### 5.2 关键转化点

| 转化点 | 触发条件 | 转化策略 |
|---|---|---|
| 访客→注册 | 想收藏/使用对比功能 | 引导注册弹窗 |
| 注册→充值 | 想实际测评/试用工具 | 余额不足提示 + 充值入口 |
| 充值→复充 | 余额不足 + 有使用需求 | 消费记录 + 剩余余额提醒 |

## 六、冷启动策略

### 6.1 数据冷启动

| 策略 | 说明 |
|---|---|
| 历史数据导入 | 从公开数据源（HuggingFace Open LLM Leaderboard、各模型官网）批量导入模型数据 |
| 定时脚本采集 | 上线前跑一次全量采集脚本，填充天梯图数据 |
| 人工审核入库 | 管理员手动补充重点模型数据 |

### 6.2 用户冷启动

| 策略 | 说明 |
|---|---|
| SEO 导流 | 天梯图页面 SEO 优化，截获「AI模型排名」「模型对比」等搜索流量 |
| 社群推广 | AI开发者社群、即刻、掘金、GitHub |
| 内容营销 | 公众号发布天梯图解读文章，引流到平台 |

## 七、风险与应对

| 风险 | 概率 | 影响 | 应对 |
|---|---|---|---|
| 数据采集被封锁 | 中 | 高 | 多源采集 + 手动补充 + 用户提交 |
| 外部API成本过高 | 中 | 中 | 严格扣费 + 预扣费机制 + 限额 |
| 用户不愿付费试用 | 高 | 高 | ¥10 体验包降低门槛 + 免费历史数据吸引 |
| 竞品抄袭天梯图 | 中 | 中 | 持续更新数据 + 自定义排序差异化 + 扩展天梯图壁垒 |
