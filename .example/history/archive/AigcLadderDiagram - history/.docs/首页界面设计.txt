## 一、设计哲学

### 1.1 核心定位
  首页 = **平台入口 + 天梯图展示** 的双角色页面。
  既要让访客扫一眼对比模型（工具属性），也要传递平台的专业性、
  数据可信度和产品生态感（品牌属性）。

### 1.2 美学方向
  **"数据编辑室"（Data Newsroom）**
  - 灵感来源：Bloomberg Terminal × 数据新闻可视化（如NYT Elections）
  - 色调：冷灰底 + 品牌蓝强调 + 数据绿/红指示器
  - 排版：信息密度高但不拥挤，数据即视觉焦点
  - 动效：克制，数据变化时才有微动效（如排名变化箭头、评分条动画）
  - 字体：思源黑体（正文）+ DIN Alternate（数据数字，版权安全）

### 1.3 用户旅程（首屏 → 转化）

  **默认主题规则**：页面默认使用浅色背景（light mode），深色主题仅为用户可选切换，非默认状态。所有设计规格以浅色为基准。

  ┌────────────────────────────────────────────────────────────┐
  │ 1. 导航栏扫一眼 → 知道这是什么平台                          │
  │ 2. Banner区 → 产生信任感（数据时效性、平台规模）              │
  │ 3. 天梯图核心区 → 直接体验核心功能（筛选/排序/查看）           │
  │ 4. 数据快报区 → 感知平台活跃度                              │
  │ 5. 生态入口区 → 发现更多功能（扩展天梯图/产品/资源）            │
  │ 6. 页脚 → 信任背书（合作/联系方式）                          │
  └────────────────────────────────────────────────────────────┘

## 六、动效规范
================================================================================

### 6.1 页面加载动效
  ### ` src/styles/animations.css `
    #### ```@keyframes fadeInUp```（元素从下方淡入，opacity 0→1, translateY 20px→0）
    #### ```@keyframes countUp```（数字从 0 计数到目标值）
    #### ```@keyframes shimmer```（骨架屏闪烁，background-position 移动）

  - Banner 区数据卡片：交错 fadeInUp（delay 0ms / 100ms / 200ms / 300ms）
  - 天梯图表格行：交错 fadeInUp（delay 按行索引递增 30ms）
  - 数据快报卡片：滚动进入视口时 fadeInUp（IntersectionObserver 触发）

### 6.2 交互微动效
  - 筛选按钮展开/收起：max-height transition 200ms ease
  - 排名变化箭头：轻微 bounce 动画（入场时）
  - 评分条：width transition 1s ease-out（从 0 到目标值）
  - 对比按钮点击：scale(0.9) → scale(1) 弹性反馈
  - 导航下拉菜单：opacity + translateY(-8px) → translateY(0) 150ms

### 6.3 减弱动效偏好
  - `prefers-reduced-motion: reduce` 时：禁用所有动画，仅保留 opacity 过渡
  - 使用 CSS media query 或 next-themes 库支持
