# 操作手册（主站 Web）

> 本文仅描述主站（Next.js Web 应用）的启动与部署方式，不包含 RAGFlow。

---

## 1. 环境要求

- Node.js：建议 20.x
- 包管理器：npm
- Docker：Docker Desktop（Windows）或等价运行时

---

## 2. 开发环境（推荐）

### 2.1 本机启动

1. 安装依赖

```bash
npm install
```

2. 启动开发服务

```bash
npm run dev
```

3. 访问

- http://localhost:3000

---

## 3. 生产环境（最简单一键部署）

### 3.1 Docker Compose 一键启动（默认生产）

在仓库根目录执行：

```bash
docker compose up -d
```

访问：

- http://localhost:3000

停止：

```bash
docker compose down
```

### 3.2 开发/生产切换（尽量短命令）

- **生产（默认）**：`docker compose up -d`
- **开发（容器内 next dev）**：

```bash
docker compose -f docker-compose.yml -f docker-compose.dev.yml up -d
```

说明：
- `docker-compose.yml` 以生产方式构建并运行（`next build` + `next start`）
- `docker-compose.dev.yml` 覆盖为开发模式（容器内 `next dev` + 挂载源码）

---

## 4. 域名部署（反向代理）

你可以把主站容器（默认监听 `3000`）放到任意反向代理之后。下面给出最常用的两种配置参考。

### 4.1 Nginx 示例

> 将 `example.com` 替换为你的域名，并准备好 TLS 证书（或用 Certbot）。

```nginx
server {
  listen 80;
  server_name example.com;

  location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
  }
}
```

如需 HTTPS：新增 `listen 443 ssl;` 并配置 `ssl_certificate` 与 `ssl_certificate_key`。

### 4.2 Caddy（更省事）示例

```caddy
example.com {
  reverse_proxy 127.0.0.1:3000
}
```

Caddy 会自动申请与续期证书（前提：域名解析正确、80/443 可用）。
