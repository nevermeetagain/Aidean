### 1.2 Demo 演示页交互约定（demo4-5）

#### 列表页 → 详情页（可点击单元格）

| Demo | 列表页路由 | 可点击单元格 | 跳转路由 |
|---|---|---|---|
| Demo4 | `/demo/demo4` | **模型名**（矩阵单元格中的模型名） | `/demo/demo4/models/:id` |
| Demo5 | `/demo/demo5` | **模型名**（矩阵单元格中的模型名） | `/demo/demo5/models/:id` |

#### 自动化验证口径（CDP）

- 入口脚本：`scripts/cdp-smoke.mjs`
- 运行前置：`npm run build`（standalone 模式）
- 执行命令：`node scripts/cdp-smoke.mjs`
- 深度巡检命令：`node scripts/cdp-smoke.mjs --deep`
- 浏览器要求：Chrome 需开启 9222 调试端口（CDP）
- 验收标准：demo4-5 均通过
  - `console.error=0`
  - `Runtime.exceptionThrown=0`
  - `Log.error=0`
- 深度巡检补充口径：
  - `Network.failed=0`（真实网络失败）
  - `Network.aborted` 单独统计（`net::ERR_ABORTED` / `canceled=true`，通常由页面导航/回退触发，不计入失败）

**CDP 脚本依赖的 DOM 约定（用于稳定定位）**：

- **搜索框**：
  - demo4：`#demo4-search`
  - demo5：`#demo5-search`
- **排序选择器**：`select[aria-label="排序方式"]`
  - demo2 额外支持：`#demo2-sort`
- **厂商选择器（demo2）**：`#demo2-vendor`
- **详情跳转 Link**：`a[aria-label^="查看模型详情："]`
- 截图输出目录：`.tmp/cdp-smoke/screens`
- 深度巡检输出目录：`.tmp/cdp-smoke/deep/<demoName>/`
  - 动作日志：`actions.jsonl`
  - 列表页截图：`list/*.png`
  - 详情页截图：`detail/*.png`

#### 手动巡检（standalone 固定端口）

- 运行前置：`npm run build`
- 启动命令：`node scripts/start-standalone.mjs --port 3211`
- 手动巡检入口：
  - `http://127.0.0.1:3211/demo/demo4`
  - `http://127.0.0.1:3211/demo/demo5`

## 二、导航栏设计

### 2.1 整体布局

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ [Logo]  首页    模型 ▾    资源 ▾    产品 ▾    关于 ▾    文档 ▾   [搜索框]  [🌐] [🌓] [登录/注册] │
└──────────────────────────────────────────────────────────────────────────────┘
```

- **Logo**：最左侧，固定大小，点击返回首页
- **一级导航**：居左，与Logo保持一定间距
- **默认主题**：浅色背景（light），用户可通过主题切换按钮手动切换暗色/跟随系统
- **搜索框**：导航栏与用户设置之间（搜索框仅存在于顶部导航栏，筛选栏区域不包含搜索框）
- **用户设置**：居右（语言切换🌐 / 主题切换🌓 / **余额显示** / 登录注册）

补充（实现约定）：

- 顶部导航栏采用固定吸顶（`position: fixed; top: 0; left: 0;`），页面主体需预留 `h-16` 的顶部占位，避免内容被遮挡
- 一级导航下拉菜单应可稳定移动到二级菜单点击，避免因按钮与面板之间存在间隙导致鼠标移出触发收起

#### 3.1.1 轮播图点击跳转

首页轮播图支持点击跳转，各图片对应目标：

| 图片 | 目标页面 | 路由/链接 | 跳转方式 |
|---|---|---|---|

> 图三/图四的标题说明采用**图片素材内置文字**，不使用前端叠加层。

### 3.2 天梯图区域

> **默认主题**：页面默认使用浅色背景。深色主题仅为可选切换，非默认状态。

#### 3.2.1 版本与视图切换

- 顶部左侧：版本切换按钮「专业版 / 应用版」
- 顶部右侧：视图切换「排行榜表格 / 柱状图」，默认排行榜表格

#### 3.2.2 筛选栏与排序栏

- 筛选栏：6个筛选按钮横向排列（类型/协议/开源/测评集/标签/时间）
- 排序栏：**位于筛选栏最右侧**，与筛选按钮同行排列
- **筛选栏不包含搜索框**：搜索框仅存在于顶部导航栏（见 §2.1），筛选栏仅包含筛选按钮和排序栏
- 点击展开/收起当前选项（互斥行为）
- 每个筛选按钮展开高度不超过200px，超出部分滚动
- 筛选按钮之间间距8px

**筛选交互细则**：
1. 初始状态：所有筛选按钮收起
2. 点击按钮A → 展开A的选项面板
3. 点击按钮B → 收起A，展开B的选项面板
4. 点击按钮A（已展开）→ 收起A
5. 多选项「全部」：第一次点击 = 全选，第二次点击 = 全不选，第三次 = 全选（循环）
6. 选择任意选项后立即生效，无确认按钮

**排序栏设计**：
```
┌──────────────────────┐
│  排序：基准排序    ↕ │
├──────────────────────┤
│  ✓ 基准排序（默认） │
│    上下文长度排序   │
│    响应速度排序     │
│    价格排序         │
│    ─────────────── │
│    自定义排序       │
│    [公式输入框...]  │
└──────────────────────┘
```

| 排序选项 | 行为 |
|---|---|
| 基准排序 | 点击即选中收起，默认高亮 |
| 上下文长度排序 | 点击即选中收起 |
| 响应速度排序 | 点击即选中收起 |
| 价格排序 | 点击即选中收起 |
| 自定义排序 | 点击展开公式输入框 |
| 公式输入框 | 实时解析，支持变量 `${综合评分}` `${上下文长度}` `${响应速度}` `${价格}`，支持运算符 `+*-/^()` |

> 排序栏宽度：180px，与6个筛选按钮视觉平衡。
> 点击排序栏外部区域：收起排序面板，保留当前排序结果。

#### 3.2.3 排行榜表格视图（矩阵式）

> ⚠️ v1.4 重大变更：表格从「每模型一行」改为「矩阵式」——行=评分（从高到低），列=厂商，单元格=模型名。

```

|------------------|--------|-----------|--------|-----|------|-----|
| 100              |        | claude 4.6 ops thinking |        |         |         |         |
| 99               |        | claude 4.6 ops           |        |         |         |         |
```

| 特征 | 说明 |
|------|------|

#### 3.2.4 柱状图视图

- 横轴：模型厂商（不同厂商颜色区分）

- 点击柱体：跳转模型详情页
- 网格线：横向虚线，间隔10分

## 四、模型详情页

### 4.1 左侧目录导航

固定在页面左侧，高度100vh，可随页面滚动，内容为：

```
┌──────────────┐
│ 基本介绍     │  ← 点击平滑滚动
├──────────────┤
│ 参数信息     │  ← 点击平滑滚动
├──────────────┤
│ 基准测试     │  ← 点击平滑滚动
├──────────────┤
│ 测评示例     │  ← 点击平滑滚动
└──────────────┘
```

- 当前可视区块对应的目录项高亮
- 点击目录项：平滑滚动（scroll-behavior: smooth）到对应内容区块
- 目录宽度：固定200px，最小高度100vh

### 4.2 参数信息表格

- 表格样式：左右两列（左列字段名，右列值），交替行背景色
- 「基准测试」字段：按钮样式，点击弹出Modal
- 「开源」字段：✓ 或 ✗ 图标
- 「价格」字段：三行小字显示
- 「链接」字段：按钮样式，新窗口打开

### 4.3 基准测试弹窗（Modal）

- 遮罩层：黑色50%透明
- 弹窗居中，最大宽度600px
- 显示该模型所有基准测试记录（来源、各项分数、综合分、测试时间）
- 关闭按钮：右上角 ✕
- 也可通过点击遮罩关闭
