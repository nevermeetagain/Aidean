# Aidean 界面交互文档（核心闭环优先）

> 文档版本：v1.0  
> 更新日期：2026-05-06  
> 目标：先定义交互规则与主路径，不输出视觉稿实现细节。

## 1. 交互设计范围
- 覆盖三产品：Aidean / AideanSpace / Sphere。
- 覆盖全局入口、核心任务流、关键反馈、异常分支。
- 本文档优先定义“怎么走通”，不是“怎么画得漂亮”。

## 2. 全局交互原则
### 2.1 首屏原则
- 用户首次进入首页，必须立即看到三产品入口与差异化一句话价值。
- 每个入口只保留一个主 CTA，避免多按钮分散注意力。

### 2.2 导航原则
- 顶部导航固定，一级信息架构稳定，不随页面变化频繁重排。
- 搜索入口与筛选入口语义分离：全站搜索用于找内容，页面筛选用于收敛结果。

### 2.3 反馈原则
- 所有关键操作必须有即时状态反馈：加载中、成功、失败、可重试。
- 失败文案必须可操作，不允许仅显示“请求失败”。

## 3. 首页（/）交互定义
### 3.1 目标
- 10 秒内让用户理解三产品定位并进入其中一个产品。

### 3.2 首屏结构
- 区块1：品牌主叙事（Aidean 是什么）。
- 区块2：三产品卡片（Aidean / AideanSpace / Sphere）。
- 区块3：每卡片一个主按钮“进入产品体验”。

### 3.3 卡片交互
- 悬停：显示轻量高亮和简短能力摘要。
- 点击：进入对应产品首页，不经二次确认。
- 返回：产品页统一支持返回首页入口。

## 4. Aidean（模型天梯图）交互
### 4.1 主路径
- 进入天梯图 -> 选择榜单 -> 筛选 -> 排序 -> 查看模型详情 -> 加入对比或收藏。

### 4.2 必要交互
- 榜单切换：切换后保持可见筛选条件，避免上下文丢失。
- 筛选面板：多选与单选行为可预期，支持清空。
- 排序：默认基准排序，自定义公式需有语法校验与错误提示。
- 详情跳转：从榜单任意项进入详情，返回后保留榜单状态。

### 4.3 关键反馈
- 数据加载骨架屏。
- 空数据提示（包含建议调整筛选）。
- 接口失败提示（带重试按钮）。

## 5. AideanSpace（工具管理）交互
### 5.1 主路径
- 进入工具首页 -> 选择 Skills/MCP/Agent -> 搜索筛选 -> 查看详情 -> 触发试用。

### 5.2 试用交互
- 登录校验：未登录先引导登录。
- 余额校验：余额不足弹出充值引导，不中断当前上下文。
- 执行反馈：试用开始、进行中、完成/失败状态可见。

### 5.3 结果沉淀
- 自动写入消费记录与操作记录，用户可在个人中心追溯。

## 6. Sphere（知识库+数字分身）交互
### 6.1 主路径
- 创建知识库 -> 上传文档 -> 解析向量化 -> 检索测试 -> 绑定数字分身。

### 6.2 状态流转
- 上传状态：待处理、处理中、成功、失败。
- 向量化状态：可重试与失败原因可见。
- 绑定状态：绑定成功后可直接发起对话验证。

### 6.3 异常处理
- 文档格式不支持：给出支持格式与大小上限。
- 向量化失败：保留原文档，允许重试。

## 7. 个人中心与支付交互
### 7.1 个人中心
- 我的收藏、我的交易、我的余额三入口固定可见。
- 核心记录默认按时间倒序，支持筛选和分页。

### 7.2 充值与扣费
- 充值页展示档位、赠送规则、到账金额。
- 所有扣费操作先校验余额，再执行动作，再入账记录。

## 8. 交互验收清单
- 首页到三产品入口点击链路 100% 可达。
- 三产品主路径均可在 3 步内进入核心任务页。
- 关键异常（无数据、接口失败、余额不足）均有可操作反馈。
- 返回行为不丢上下文（筛选、排序、分页状态）。
- 移动端与桌面端交互语义一致。
