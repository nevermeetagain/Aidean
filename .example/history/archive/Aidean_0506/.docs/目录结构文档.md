## 8. 结构约束说明
- 所有项目文档统一维护在根目录 `.docs/`。
- `project_oldversion/` 仅作为历史参考，不作为新一轮重构事实来源。
- Docker 配置需优先满足国内镜像可拉取与可复现启动。
- 结构变更后必须同步更新本文件与相关文档引用关系。
