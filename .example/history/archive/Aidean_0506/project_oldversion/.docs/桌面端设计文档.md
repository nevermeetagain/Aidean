## 一、产品定位

### 1.1 产品概述

Aidean Desktop 是**AI Skills & MCP 生态控制中枢**，是本平台（AI模型天梯图）的配套桌面端工具。

| 维度 | 说明 |
|---|---|
| **产品名称** | Aidean Desktop |
| **定位** | AI编程工具的Skills/MCP/Agent统一管理桌面端 |
| **平台** | Windows / macOS / Linux 全平台 |
| **与网页端关系** | 配套产品，共享账号体系、会员订阅、商城数据 |
| **核心价值** | 一键安装、自动同步到38+AI工具、任务环境管理 |

### 1.2 与网页端的关系

```
网页端（AI模型天梯图）              桌面端（Aidean Desktop）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━     ━━━━━━━━━━━━━━━━━━━━━━━━━━━
• AI模型天梯图、测评、对比     ←→   • Skills/MCP/Agent 安装管理
• 资源发现（Skills/MCP展示）   ←→   • 一键同步到本地IDE工具
• 君子订阅会员                 ←→   • 会员权益（私有仓库/AI推荐）
• 用户账号系统                 ←→   • 同一账号，Deep Link登录
• 商城数据（平台维护）         ←→   • 本地安装执行
• API Routes                   ←→   • 桌面端调用网页API
• 公众号触发                   ←→   • WebSocket接收，执行本地操作
```

```typescript
  environment: {

    delete: (id: string) => Promise<void>;
  };
  marketplace: {
    getFeatured: () => Promise<MarketItem[]>;
    search: (query: string) => Promise<MarketItem[]>;
    install: (item: MarketItem) => Promise<void>;
  };
  auth: {
    login: (token: string) => Promise<UserInfo>;
    logout: () => Promise<void>;
    getStatus: () => Promise<AuthStatus>;
  };
  subscription: {
    getStatus: () => Promise<SubStatus>;

  };
  settings: {
    get: (key: string) => Promise<string>;

  };

    getDetail: (name) => invoke<SkillDetail>('get_skill_detail', { name }),
  };
  // ... 其余实现
}

export const api: AideanAPI = new TauriAideanAPI();
```

#### 3.1.2 Skills同步引擎（直接复用skills-hub MIT代码）

```rust
// 三级fallback同步策略
// src-tauri/src/modules/skills/sync_engine.rs

pub fn sync_to_tool(source: &Path, adapter: &ToolAdapter) -> Result<SyncMode> {
  let target = home_dir().join(&adapter.skills_dir).join(source.file_name()?);

  // Cursor强制copy（已知symlink bug）
  if adapter.force_copy {
    return copy_dir_recursive(source, &target).map(|_| SyncMode::Copy);
  }

  // 优先symlink（macOS/Linux）
  if let Ok(_) = std::fs::soft_link(source, &target) {
    return Ok(SyncMode::Symlink);
  }

  // Windows fallback: Junction点
  #[cfg(windows)]
  if let Ok(_) = junction::create(source, &target) {
    return Ok(SyncMode::Junction);
  }

  // 最终fallback: 完整复制
  copy_dir_recursive(source, &target).map(|_| SyncMode::Copy)
}
```

## 五、数据库Schema

```sql
-- SQLite数据库（本地，路径：~/.local/share/aidean/aidean.db）
-- Windows：%APPDATA%\aidean\aidean.db

-- Skills表（继承并扩展skills-hub）
CREATE TABLE skills (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL UNIQUE,
  source_type TEXT NOT NULL, -- local|git|github|platform
  source_ref TEXT,           -- Git URL / GitHub路径 / 平台ID
  source_revision TEXT,      -- Git commit hash
```

## 十二、双协议完整实现规范

> 本章为 Aidean Desktop Skills双协议实现的权威技术规范。

### 12.1 两套协议的本质区别

| 维度 | Anthropic SKILL.md协议 | OpenAI/通用 AGENTS.md协议 |
|---|---|---|
| **发起方** | Anthropic（Claude Code）| OpenAI Codex / 社区通用 |
| **核心文件** | 每个Skill一个独立目录（含`SKILL.md`）| 所有Skills汇总写入`AGENTS.md`单文件 |
| **发现方式** | Agent扫描`skills/`目录读取frontmatter | Agent读取`AGENTS.md`的`<available_skills>` XML块 |
| **加载方式** | **渐进式**：按需加载Skill全文 | **全量**：启动时全部注入Context |
| **Context效率** | 高（只加载需要的Skill）| 低（Skills越多越臃肿）|
| **适用Agent** | Claude Code/OpenCode/Cursor/Windsurf | Codex/通用Agent（任何能读Markdown的工具）|
| **优势** | Progressive Disclosure，Context效率高 | 兼容性广，任何工具均可用 |
| **劣势** | 需要Agent主动支持Skill加载机制 | Context消耗大 |

### 12.2 Anthropic协议文件结构

```
~/.claude/skills/pdf/           # 每个Skill独立目录
├── SKILL.md                    # 主文件（YAML frontmatter + Markdown正文）
│   内容示例：
│   ---
│   name: pdf
│   description: Comprehensive PDF toolkit...
│   ---
│   # PDF Skill 内容...
├── references/                 # 可选：细分子文档
│   ├── extraction.md
│   └── forms.md
└── scripts/                    # 可选：可执行脚本
    └── convert.js
```

**Anthropic协议工作机制**：
1. Agent启动时扫描`skills/`目录，读取每个`SKILL.md`的frontmatter
2. 将`name + description`注入系统提示的`<available_skills>`块（仅描述，不含全文）
3. 用户提问时，Agent判断是否需要加载某Skill
4. 需要时执行`npx openskills read <skill-name>`（或等效操作）加载全文
5. 全文内容注入当前对话Context（Progressive Disclosure）

### 12.3 OpenAI/通用协议文件结构

```
项目根目录/
└── AGENTS.md                   # 单文件，汇总所有Skills的XML块

~/.agent/skills/                # 全局通用路径（Skill文件仍以目录形式存储）
└── pdf/
    └── SKILL.md
```

**AGENTS.md标准格式**：
```xml
<!-- 由 openskills sync / Aidean Desktop 自动生成 -->
<skills_system priority="1">
  <usage>
    When users ask you to perform tasks, check if any of the
    available skills below can help...
    How to use skills:
    - Invoke: Bash("npx openskills read <skill-name>")
  </usage>
  <available_skills>
    <skill>
      <name>pdf</name>
      <description>Comprehensive PDF toolkit...</description>
      <location>project</location>  <!-- project | global -->
    </skill>
    <skill>
      <name>fetch</name>
      <description>Web data fetching...</description>
      <location>global</location>
    </skill>
  </available_skills>
</skills_system>
```

**OpenAI协议工作机制**：
1. Agent启动时读取`AGENTS.md`文件
2. 解析`<available_skills>`块，**全量**注入所有Skill描述到Context
3. 注意：`<usage>`块中指定了`npx openskills read`作为加载命令，支持渐进式加载（但需Agent配合）
4. 无`<usage>`块时：全量注入，无渐进式加载能力

### 12.4 Aidean Desktop双协议实现代码

#### 12.4.1 Anthropic协议发现逻辑（TypeScript前端）

```typescript
// src/platform-api/skills.ts
```

```rust
// src-tauri/src/modules/skills/skill_store.rs

pub fn list_skills(central_path: &Path) -> Vec<SkillRecord> {
  let mut skills = Vec::new();

  if let Ok(entries) = fs::read_dir(central_path) {
    for entry in entries.flatten() {
      let skill_md = entry.path().join("SKILL.md");
      if skill_md.exists() {
        if let Ok(content) = fs::read_to_string(&skill_md) {
          // 解析YAML frontmatter
          if let Some(fm) = parse_frontmatter(&content) {
            skills.push(SkillRecord {
              name: fm.name,
              description: fm.description,
              central_path: entry.path(),
              // content_hash用于变更检测
              content_hash: hash_file(&skill_md),
            });
          }
        }
      }
    }
  }
  skills
}

// YAML frontmatter解析
fn parse_frontmatter(content: &str) -> Option<SkillFrontmatter> {
  let re = Regex::new(r"(?s)^---\n(.*?)\n---").unwrap();
  if let Some(caps) = re.captures(content) {
    let yaml_str = caps.get(1)?.as_str();
    return serde_yaml::from_str(yaml_str).ok();
  }
  None
}
```

```rust
// src-tauri/src/modules/skills/agents_md_writer.rs
// 参考 openskills/src/utils/agents-md.ts 的Rust实现

pub fn generate_skills_xml(skills: &[SkillRecord]) -> String {
  let skill_tags: String = skills.iter().map(|s| {
    format!(
      "    <skill>\n      <name>{}</name>\n      <description>{}</description>\n      <location>{}</location>\n    </skill>",
      s.name,
      s.description,
      if s.is_project_scope { "project" } else { "global" }
    )
  }).collect::<Vec<_>>().join("\n");

  format!(
    r#"<skills_system priority="1">
  <usage>
When users ask you to perform tasks, check if any of the available skills
below can help complete the task more effectively.

How to use skills:
- Invoke: Bash("npx openskills read <skill-name>")
- Or: Ask Aidean Desktop to load the skill
  </usage>
  <available_skills>
{}
  </available_skills>
</skills_system>""",
    skill_tags
  )
}

pub fn update_agents_md(agents_md_path: &Path, skills: &[SkillRecord]) -> Result<()> {
  // 读取现有AGENTS.md（保留用户自定义内容）
  let existing = if agents_md_path.exists() {
    fs::read_to_string(agents_md_path)?
  } else {
    String::new()
  };

  let new_xml = generate_skills_xml(skills);

  // 替换已有的skills_system块，或追加到末尾
  let skills_block_re = Regex::new(r"(?s)<skills_system[^>]*>.*?</skills_system>").unwrap();
  let updated = if skills_block_re.is_match(&existing) {
    skills_block_re.replace(&existing, new_xml.as_str()).to_string()
  } else {
    format!("{}\n\n{}", existing.trim_end(), new_xml)
  };

  // 原子写入（防止写入中途损坏）
  let tmp_path = agents_md_path.with_extension("md.tmp");
  fs::write(&tmp_path, &updated)?;
  fs::rename(&tmp_path, agents_md_path)?;
  Ok(())
}
```

#### 12.4.4 双协议同步核心逻辑（Rust后端）

```rust
// src-tauri/src/modules/skills/sync_engine.rs

pub async fn sync_skill_dual_protocol(
  skill: &Skill,
  settings: &AppSettings,
) -> Result<SyncReport> {
  let mut report = SyncReport::new(&skill.name);

  // ① 安装到中心仓库（单一真相来源）
  let central_path = settings.central_repo_path
    .join(&skill.name);
  install_to_central(skill, &central_path).await?;

  // ② Anthropic协议路径同步（38+工具）
  for adapter in get_detected_tool_adapters() {
    let target = home_dir().join(&adapter.skills_dir).join(&skill.name);

    // Cursor必须copy，其他工具优先symlink
    let mode = sync_to_target(
      &central_path,
      &target,
      adapter.force_copy,
    )?;
    report.add_sync_result(&adapter.key, mode);
  }

  // ③ OpenAI通用协议路径（openskills兼容）
  let universal_target = home_dir().join(".agent/skills").join(&skill.name);
  let mode = sync_to_target(&central_path, &universal_target, false)?;
  report.add_sync_result("universal", mode);

  // ④ AGENTS.md自动更新（可选，根据用户设置）
  if settings.auto_update_agents_md {
    let agents_md = PathBuf::from("./AGENTS.md");
    let all_skills = skill_store::list_skills(&settings.central_repo_path);
    update_agents_md(&agents_md, &all_skills)?;
    report.agents_md_updated = true;
  }

  Ok(report)
}

// 三级fallback同步（来自skills-hub）
fn sync_to_target(
  source: &Path,
  target: &Path,
  force_copy: bool,
) -> Result<SyncMode> {
  // 如果目标已存在且是最新版本，跳过
  if target.exists() && is_up_to_date(source, target) {
    return Ok(SyncMode::UpToDate);
  }

  // 清理旧目标
  if target.exists() {
    remove_target(target)?;
  }

  if force_copy {
    copy_dir_recursive(source, target)?;
    return Ok(SyncMode::Copy);
  }

  // macOS/Linux: symlink
  #[cfg(unix)]
  if std::os::unix::fs::symlink(source, target).is_ok() {
    return Ok(SyncMode::Symlink);
  }

  // Windows: Junction点（不需要管理员权限）
  #[cfg(windows)]
  if junction::create(source, target).is_ok() {
    return Ok(SyncMode::Junction);
  }

  // 最终fallback: 完整复制
  copy_dir_recursive(source, target)?;
  Ok(SyncMode::Copy)
}
```

### 12.7 关键实现原则

```
原则1：存储与协议分离
  中心仓库始终以Anthropic格式存储（独立目录+SKILL.md）
  同步时根据目标工具的协议自动生成对应格式
  → 不因协议不同而维护两套数据

原则2：AGENTS.md只是索引，不是数据源
  AGENTS.md由Aidean Desktop自动生成和维护
  数据源始终是中心仓库的SKILL.md文件
  → 用户不应手动编辑AGENTS.md中的<available_skills>块

原则3：Cursor强制Copy，不可妥协
  Cursor扫描skills目录时不跟随符号链接
  即使使用Junction点也无效
  → tool_adapters中Cursor的force_copy必须为true

原则4：AGENTS.md增量更新，保留用户内容
  只替换<skills_system>...</skills_system>块
  块外的用户自定义内容（项目规则、其他配置）保持不变
  → 使用正则精确替换，不重写整个文件

原则5：openskills CLI兼容
  ~/.agent/skills/路径与openskills --universal一致
  AGENTS.md格式与openskills sync生成的格式一致
  → 用户可以同时使用openskills CLI和Aidean Desktop
```
