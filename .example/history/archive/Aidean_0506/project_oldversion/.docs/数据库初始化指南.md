## 一、初始化脚本说明

### 1.1 文件结构

```
docker/sql/
├── aidean_full_init.sql          # 【总表】完整初始化脚本（生成文件）
├── generate_full_init.ps1        # SQL合并生成脚本
└── init/                         # 【分段表】原始SQL文件目录
    ├── 01_create_extensions.sql  # 扩展安装
    ├── 02_create_schemas.sql     # Schema创建
    ├── 03_create_tables.sql      # 表结构（89张表）
    ├── 04_create_indexes.sql     # 索引
    ├── 05_create_constraints.sql # 外键约束
    ├── 06_create_triggers.sql    # 触发器
    ├── 07_create_functions.sql   # 函数
    ├── 08_create_views.sql       # 视图
    ├── 09_create_policies.sql    # 行级安全策略
    ├── 10_create_partitions.sql  # 分区策略
    ├── 11_seed_data.sql          # 基础数据
    ├── 12_seed_models.sql        # 模型数据
    └── 13_seed_agent_data.sql    # Agent系统数据
```

### 1.2 脚本特点

- ✅ **幂等执行**：所有 `CREATE` 语句使用 `IF NOT EXISTS`
- ✅ **事务安全**：支持 `BEGIN/COMMIT` 包裹
- ✅ **UTF-8编码**：全程使用UTF-8无BOM编码
- ✅ **中文支持**：所有注释和说明支持中文
- ✅ **错误处理**：包含约束检查和校验

## 二、初始化方法

### 方法1：使用总表脚本（推荐）

```bash
# 全新安装
psql -U postgres -d aidean -f docker/sql/aidean_full_init.sql

# 指定编码
psql -U postgres -d aidean -c "SET client_encoding = 'UTF8';" -f docker/sql/aidean_full_init.sql
```

### 方法2：分段执行（调试使用）

```bash
# 1. 创建扩展
cd docker/sql/init
psql -U postgres -d aidean -f 01_create_extensions.sql

# 2. 创建Schema
psql -U postgres -d aidean -f 02_create_schemas.sql

# 3. 创建表
psql -U postgres -d aidean -f 03_create_tables.sql

psql -U postgres -d aidean -f 04_create_indexes.sql

# 5. 创建约束

psql -U postgres -d aidean -f 06_create_triggers.sql

psql -U postgres -d aidean -f 11_seed_data.sql
```

## 三、常见场景处理

### 3.1 数据库不存在

```sql
-- 创建数据库
CREATE DATABASE aidean
    WITH 
    ENCODING = 'UTF8'
    LC_COLLATE = 'zh_CN.UTF-8'
    LC_CTYPE = 'zh_CN.UTF-8'
    TEMPLATE = template0;

-- 切换到数据库执行初始化脚本
\c aidean
-- 然后执行 aidean_full_init.sql
```

### 3.2 数据表已存在

脚本已内置幂等处理：

```sql
-- 所有CREATE TABLE使用 IF NOT EXISTS
CREATE TABLE IF NOT EXISTS users (...);

-- 所有CREATE INDEX使用 IF NOT EXISTS  
CREATE INDEX IF NOT EXISTS idx_users_email ON users(email);

-- 所有ALTER TABLE使用条件判断
DO $$
BEGIN
    IF NOT EXISTS (
        SELECT 1 FROM information_schema.columns 
        WHERE table_name='users' AND column_name='new_field'
    ) THEN
        ALTER TABLE users ADD COLUMN new_field VARCHAR(255);
    END IF;
END $$;
```

### 3.3 数据库字段异常

```sql
-- 查看表结构
\d users

-- 对比期望结构
SELECT column_name, data_type, is_nullable
FROM information_schema.columns
WHERE table_name = 'users'
ORDER BY ordinal_position;

-- 修复缺失字段
ALTER TABLE users ADD COLUMN IF NOT EXISTS missing_field VARCHAR(255);

-- 修复错误类型
ALTER TABLE users ALTER COLUMN phone TYPE VARCHAR(20);
```

### 3.4 中文编码异常

```sql
-- 检查当前编码
SHOW client_encoding;
SHOW server_encoding;

-- 修复编码问题
SET client_encoding = 'UTF8';

-- 如果数据库编码错误，需要重建
-- 1. 导出数据
pg_dump -E UTF8 -f backup.sql aidean

-- 2. 删除并重建数据库
DROP DATABASE aidean;
CREATE DATABASE aidean ENCODING 'UTF8' LC_COLLATE 'zh_CN.UTF-8';

-- 3. 重新导入
psql -d aidean -f backup.sql
```

## 四、验证安装

### 4.1 表数量验证

```sql
-- 统计表数量（应返回89）
SELECT COUNT(*) as table_count
FROM information_schema.tables
WHERE table_schema = 'public'
  AND table_type = 'BASE TABLE';
```

### 4.2 核心表验证

```sql
-- 验证核心表存在
SELECT table_name
FROM information_schema.tables
WHERE table_schema = 'public'
  AND table_name IN (
    'users', 'ai_models', 'vendors', 'ladder_rankings',
    'evaluations', 'skills', 'mcp_servers', 'personas',
    'tasks', 'sync_batches', 'custom_metrics'
  )
ORDER BY table_name;
```

### 4.3 约束验证

```sql
-- 查看外键约束
SELECT
    tc.table_name,
    kcu.column_name,
    ccu.table_name AS foreign_table,
    ccu.column_name AS foreign_column
FROM information_schema.table_constraints tc
JOIN information_schema.key_column_usage kcu 
    ON tc.constraint_name = kcu.constraint_name
JOIN information_schema.constraint_column_usage ccu 
    ON ccu.constraint_name = tc.constraint_name
WHERE tc.constraint_type = 'FOREIGN KEY'
  AND tc.table_schema = 'public';
```

### 4.4 触发器验证

```sql
-- 查看触发器
SELECT trigger_name, event_object_table, action_timing, event_manipulation
FROM information_schema.triggers
WHERE trigger_schema = 'public'
ORDER BY event_object_table;
```

## 五、增量更新

### 5.1 添加新表

```sql
-- 在 init/03_create_tables.sql 中添加新表定义
-- 然后执行：
psql -d aidean -f docker/sql/init/03_create_tables.sql

-- 或者直接执行新增表SQL
```

### 5.2 修改表结构

```sql
-- 添加字段（幂等）
DO $$
BEGIN
    IF NOT EXISTS (
        SELECT 1 FROM information_schema.columns 
        WHERE table_name='users' AND column_name='avatar_url'
    ) THEN
        ALTER TABLE users ADD COLUMN avatar_url VARCHAR(500);
        COMMENT ON COLUMN users.avatar_url IS '头像URL';
    END IF;
END $$;
```

### 5.3 重建总表脚本

```powershell
# PowerShell 执行
cd docker/sql
Remove-Item aidean_full_init.sql -ErrorAction SilentlyContinue

# 合并所有文件
$files = Get-ChildItem -Path init\*.sql | Sort-Object Name
$content = @()
foreach($file in $files) {
    $content += "-- FILE: $($file.Name)"
    $content += "-- ----------------------------------------"
    $content += Get-Content -Raw $file.FullName
    $content += ""
}
$content += "COMMIT;"
$content += "SELECT 'Initialization complete' as status;"

# 写入文件（UTF8无BOM）
$Utf8NoBom = New-Object System.Text.UTF8Encoding($false)
[System.IO.File]::WriteAllLines("aidean_full_init.sql", $content, $Utf8NoBom)

Write-Host "Generated aidean_full_init.sql with $($files.Count) files"
```

## 六、故障排查

### 6.1 连接错误

```bash
# 检查服务状态
pg_isready -h localhost -p 5432

# 查看日志
docker logs aidean-postgres
```

### 6.2 权限错误

```sql
-- 检查当前用户权限
SELECT current_user;
\du

-- 授予权限
GRANT ALL PRIVILEGES ON DATABASE aidean TO app_user;
GRANT ALL PRIVILEGES ON ALL TABLES IN SCHEMA public TO app_user;
```

### 6.3 编码错误

```bash
# 检查客户端编码
echo $PGCLIENTENCODING

# 设置环境变量
export PGCLIENTENCODING=UTF8

# Windows PowerShell
$env:PGCLIENTENCODING = "UTF8"
```
