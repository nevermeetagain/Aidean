- 入口脚本：`scripts/cdp-smoke.mjs`
- 运行前置：`npm run build`（standalone 模式）
- 执行命令：`node scripts/cdp-smoke.mjs`

- 浏览器要求：Chrome 需开启 9222 调试端口（CDP）
- 验收标准：demo4-5 均通过
  - `console.error=0`
  - `Runtime.exceptionThrown=0`
  - `Log.error=0`
- 深度巡检补充口径：
  - `Network.failed=0`（真实网络失败）
  - `Network.aborted` 单独统计（`net::ERR_ABORTED` / `canceled=true`，通常由页面导航/回退触发，不计入失败）

- 截图输出目录：`.tmp/cdp-smoke/screens`
- 深度巡检输出目录：`.tmp/cdp-smoke/deep/<demoName>/`
  - 动作日志：`actions.jsonl`
  - 列表页截图：`list/*.png`
  - 详情页截图：`detail/*.png`

#### 3.1.4 Banner高度优化（v2026-04-20 中间值方案）

**优化方案**：采用CSS clamp()实现流式响应式高度（中间值方案）

**实施代码**：
```tsx
style={{
  height: 'clamp(235px, 20vw, 255px)',
  maxHeight: '255px',
}}
```

**响应式表现**：
| 设备类型 | 屏幕宽度 | Banner高度 | 优化前高度 | 降低幅度 |
|---------|---------|-----------|-----------|---------|
| 手机 | 375px | 235px | 280px | 16% ↓ |
| 平板 | 768px | 235px | 280px | 16% ↓ |
| 桌面 | 1920px | 255px | 280px | 9% ↓ |
| 4K | 3840px | 255px | 280px | 9% ↓ |

**优化效果**：
- 首屏信息展示量提升约15%
- 保持图片完整性和视觉美观
- 所有设备响应式兼容性良好
- 视觉变化温和，用户体验友好

**方案说明**：
- 采用原始高度（280px）与优化高度（190-230px）的中间值
- 手机端：(280 + 190) / 2 = 235px
- 桌面端：(280 + 230) / 2 = 255px
- 使用clamp()实现流式响应，避免断点跳跃

#### 3.1.5 Banner高度vh响应式方案（v2026-04-21）

**优化方案**：采用Tailwind CSS vh单位实现视口比例响应式高度

**实施代码**：
```tsx
<div className="relative h-[45vh] min-h-[320px] max-h-[500px] w-full overflow-hidden transition-all duration-300 ease-in-out md:h-[55vh] md:min-h-[400px] md:max-h-[650px] lg:h-[66.67vh] lg:min-h-[500px] lg:max-h-[800px]">
  {/* Banner内容 */}
</div>
```

**响应式表现**：
| 设备类型 | 屏幕宽度 | Banner高度 | 最小高度 | 最大高度 | 下方内容 |
|---------|---------|-----------|---------|---------|---------|
| 移动端 | <768px | 45vh | 320px | 500px | 55vh |
| 平板端 | 768-1024px | 55vh | 400px | 650px | 45vh |
| 桌面端 | >1024px | 66.67vh | 500px | 800px | 33.33vh |

**实现细节**：
- Banner占视口2/3，下方内容占1/3
- 使用Flexbox垂直居中布局 (items-center justify-center)
- 背景使用三色渐变 (from-indigo-50 via-blue-50 to-purple-50)
- 添加过渡动画 (transition-all duration-300 ease-in-out)

**优化效果**：
- Banner高度随视口自适应，比例协调
- 最小/最大高度限制确保极端设备体验
- 平滑过渡动画，无布局抖动
- 内容区与Banner高度互补，始终占据合理空间

#### 3.2.2 筛选栏与排序栏

- 筛选栏：6个筛选按钮横向排列（类型/协议/开源/测评集/标签/时间）
- 排序栏：**位于筛选栏最右侧**，与筛选按钮同行排列
- **筛选栏不包含搜索框**：搜索框仅存在于顶部导航栏（见 §2.1），筛选栏仅包含筛选按钮和排序栏
- 点击展开/收起当前选项（互斥行为）
- 每个筛选按钮展开高度不超过200px，超出部分滚动
- 筛选按钮之间间距8px

**筛选交互细则**：
1. 初始状态：所有筛选按钮收起
2. 点击按钮A → 展开A的选项面板
3. 点击按钮B → 收起A，展开B的选项面板
4. 点击按钮A（已展开）→ 收起A
5. 多选项「全部」：第一次点击 = 全选，第二次点击 = 全不选，第三次 = 全选（循环）
6. 选择任意选项后立即生效，无确认按钮
