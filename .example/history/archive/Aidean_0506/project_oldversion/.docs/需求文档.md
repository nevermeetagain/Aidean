## 一、项目概述

### 1.1 项目背景

AI大模型数量快速增长，开发者和企业用户难以快速了解各模型的性能差异、价格区间和适用场景。市场上缺乏一个系统化、直观化的模型横向对比平台。

### 1.2 项目目标

| 目标 | 说明 |
|---|---|
| 核心目标 | 提供AI模型与工具的「天梯图」评测平台，让用户扫一眼即完成选型决策 |
| 商业目标 | 余额制预付费：基础数据免费，对比测评/工具试用/线上开发环境按次从余额扣除 |
| 生态目标 | 聚合MCP工具与Skill资源，成为AI工具发现与试用平台 |
| 渠道目标 | SEO导流 + AI开发者社群推广 |

> **详细商业设计**：见 `.docs/商业设计文档.md`

### 1.3 参考对标

- 主要参考：https://ai-bot.cn/
- 核心差异：以天梯图为核心（可视化评分对比），而非简单工具导航

#### 3.1.5 排序算法

排序功能位于筛选栏最右侧，具体设计如下：

##### 排序方式

| 排序方式 | 说明 | 默认值 |
|---|---|---|
| 基准排序（综合评分） | 按四维加权综合得分降序（官方25%+实际25%+风评25%+自测25%） | **默认** |
| 上下文长度排序 | 按上下文窗口大小降序（单位：K tokens） | 否 |
| 响应速度排序 | 按输出速度降序（单位：tokens/秒） | 否 |
| 价格排序 | 按输入价格升序（单位：￥/M Tokens） | 否 |
| 自定义排序 | 用户输入计算公式进行排序 | 否 |

##### 自定义排序公式

- 用户在输入框中填入计算公式，使用变量引用各排序维度
- 支持的变量：
  - `${综合评分}` 或 `${benchmark}`
  - `${上下文长度}` 或 `${context}`
  - `${响应速度}` 或 `${speed}`
  - `${价格}` 或 `${price}`
- 支持基本运算符：`+`、`-`、`*`、`/`、`()`、`^`（幂）
- 支持比较运算符：`<`（升序）、`>`（降序），决定最终排序方向
- **公式示例**：`${价格}/1000000*${响应速度}`
  - 含义：价格越低 × 响应越快，得分越高，排名越前
- 公式实时解析，填写后立即生效
- 公式错误时显示友好错误提示，不影响其他排序

##### 公式变量说明

| 变量名 | 别名 | 单位 | 说明 |
|---|---|---|---|
| `${综合评分}` | `${benchmark}` | 分（0-100） | 四维加权综合得分 |
| `${上下文长度}` | `${context}` | K tokens | 模型上下文窗口大小 |
| `${响应速度}` | `${speed}` | tokens/秒 | 模型输出速度 |
| `${价格}` | `${price}` | ￥/M Tokens | 输入价格（已统一换算） |

##### 排序交互规则

- 切换排序方式后，排行榜立即重新排列，无需确认
- 选择自定义排序后，显示公式输入框
- 其他排序方式点击后隐藏公式输入框
- 筛选条件变更后，保留当前排序方式
- 首页数据调用缓存时，同步缓存排序结果

## 四、排名算法需求

### 4.1 算法维度

四种评测维度（可后台独立调整权重）：

| 维度 | 说明 | 默认权重 |
|---|---|---|
| 官方评测基准 | 模型厂商官方公布的测试分数 | 25% |
| 实际评测基准 | 第三方平台实际测试分数 | 25% |
| 风评 | 用户社区/网络使用评价 | 25% |
| 自测 | 平台自主测试结果 | 25% |

### 4.2 算法规则

- 默认每种维度满分100分，相加后除以4得出综合得分
- 算法参数可在后台调整
- 排名按综合得分降序

## 五、非功能性需求

### 5.1 性能要求

- 页面首屏加载时间 ≤ 2秒
- 天梯图筛选响应时间 ≤ 500ms（使用缓存）
- 支持100+模型同时展示

### 5.2 可用性要求

- 支持中英文切换
- **默认浅色主题**：界面默认使用浅色背景（light mode），深色主题为用户可选切换，非默认状态
- 支持明暗主题切换
- 响应式设计，适配桌面和移动端
- **搜索框位置**：搜索框仅存在于顶部导航栏（见界面交互文档 §2.1），筛选栏等其他区域不包含搜索框

### 5.3 数据管理要求

- MCP数据采集由管理员配置脚本参数和执行周期
- 模型数据支持手动录入和脚本导入
- 用户提交数据需管理员审核后入库

| 线上开发环境 | 在线IDE | ¥0.5~2/分钟，余额扣除 |

### 9.2 试用流程

1. 用户浏览工具详情页，免费查看工具介绍/文档
2. 点击「试用」按钮，系统检查用户余额是否充足
3. 余额充足 → 进入试用环境，开始扣费
4. 余额不足 → 弹出充值引导
5. 试用完成 → 扣费确认，消费记录更新

### 9.3 购买流程

1. 用户浏览工具详情页
2. 点击「购买」按钮，查看价格和授权信息
3. 确认购买 → 从余额扣除
4. 购买成功 → 工具加入「已购」列表
