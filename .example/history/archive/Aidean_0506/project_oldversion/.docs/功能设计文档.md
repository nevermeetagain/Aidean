## 一、系统架构

> **架构决策 v1.1**：采用 Option B — 纯 Next.js 14 全栈方案。原 `web/`（Vite+React 独立前端）合并入 Next.js，利用 Server Components + ISR 实现 SEO 优化和首屏加速，API Routes 继续对外提供接口供桌面端/移动端调用。

### 1.1 技术选型

| 模块 | 技术选型 | 说明 |
|---|---|---|
| **全栈框架** | Next.js 14 (App Router) | 前后端统一，Server/Client Components 混合渲染 |
| **语言** | TypeScript 5.x | 前后端共享类型定义 |
| **样式** | Tailwind CSS 3.x | 原子化 CSS |
| **状态管理** | Zustand 4.x | 仅用于 Client Components |
| **图表** | ECharts 5.x | Client Component，天梯图可视化 |
| **ORM** | Prisma 5.x | 类型安全，前后端共享模型类型 |
| **数据库** | PostgreSQL 15.x | 主数据库 |
| **缓存** | Redis 7.x / ioredis | API 响应缓存、ISR 数据缓存 |
| **定时任务** | node-cron | 管理员可配置执行参数和周期 |
| **认证** | JWT + bcryptjs | 用户认证 |
| **微信公众号** | 微信 JS-SDK | 公众号集成 |
| **部署** | Docker + Docker Compose + Nginx | 容器化部署 |

### 1.3 Server Component / Client Component 边界规则

| 组件类型 | 标记 | 适用场景 | 示例 |
|---|---|---|---|
| **Server Component** | 默认（无标记） | 数据库查询、SEO 元数据、静态内容 | 天梯图榜单、模型详情页框架、资源列表 |
| **Client Component** | `'use client'` | 交互事件、useState/useEffect、第三方 UI 库 | ECharts图表、筛选栏、测评车、搜索框 |

**核心原则**：
- Server Component 直接 `import { prisma }` 查询数据库，零 API Round-trip
- Client Component 通过 `fetch('/api/...')` 获取动态数据
- Zustand store 仅在 Client Component 中使用
- `lib/` 工具库（Prisma、Redis、JWT）只在 Server

## 三、排名算法设计

### 3.1 四维评分体系

| 维度 | 来源 | 默认满分 | 权重 |
|---|---|---|---|
| 官方评测基准 | 模型官方/评测机构公布数据 | 100 | 可配置 |
| 实际评测基准 | 第三方平台实测数据 | 100 | 可配置 |
| 风评 | 用户社区/网络评价 | 100 | 可配置 |
| 自测 | 平台自主测试 | 100 | 可配置 |

**综合得分计算公式**：
```
综合得分 = (官方得分 × 官方权重 + 实际得分 × 实际权重 + 风评得分 × 风评权重 + 自测得分 × 自测权重) / 100
```

### 3.2 WeightManager（权重管理）

- 管理员可在后台调整各维度权重（0~100%）
- 权重总和自动归一化为100%
- 调整后自动触发重新计算所有模型得分

### 3.3 天梯图排序算法

#### 3.3.1 排序维度变量

| 变量名 | 别名 | 单位 | 说明 |
|---|---|---|---|
| `benchmark` | 综合评分 | 分（0-100） | 四维加权综合得分 |
| `context` | 上下文长度 | K tokens | 模型上下文窗口大小 |
| `speed` | 响应速度 | tokens/秒 | 模型输出速度 |
| `price` | 价格 | ￥/M Tokens | 输入价格（已统一换算） |

#### 3.3.2 预置排序方式

| 排序键值 | 排序逻辑 |
|---|---|
| `benchmark_desc` | 综合得分降序（**默认**） |
| `context_desc` | 上下文长度降序 |
| `speed_desc` | 响应速度降序 |
| `price_asc` | 输入价格升序（越便宜越前） |

#### 3.3.3 自定义排序公式解析

支持公式语法：

```
expression := term (('+' | '-') term)*
term       := factor (('*' | '/') factor)*
factor     := base ('^' exponent)?
base       := variable | number | '(' expression ')'
variable   := '$' '{' NAME '}'
NAME       := '综合评分' | '上下文长度' | '响应速度' | '价格'
           | 'benchmark' | 'context' | 'speed' | 'price'
```

**示例公式及语义**：

| 公式 | 语义 | 排序方向 |
|---|---|---|
| `${价格排序}/1000000*${响应速度排序}` | 价格越低×速度越快得分越高 | 升序 |
| `${综合评分}/${价格排序}` | 得分高且价格低优先 | 降序 |
| `${上下文长度排序}*0.5+${综合评分}*0.5` | 上下文与得分均衡 | 降序 |

#### 3.3.4 公式解析器实现

```typescript
// services/ranking/FormulaParser.ts
interface FormulaContext {
  benchmark: number;  // 0-100
  context: number;     // K tokens
  speed: number;      // tokens/s
  price: number;      // ¥/M Tokens
}

function parseFormula(formula: string, ctx: FormulaContext): number {
  const variables = {
    '综合评分': ctx.benchmark, 'benchmark': ctx.benchmark,
    '上下文长度': ctx.context, 'context': ctx.context,
    '响应速度': ctx.speed, 'speed': ctx.speed,
    '价格': ctx.price, 'price': ctx.price,
  };
  // 替换变量为实际值
  let expr = formula.replace(/\$\{([^}]+)\}/g, (_, name) =>
    String(variables[name.trim()] ?? 0)
  );
  // 安全计算（使用数学表达式解析库）
  return safeEval(expr);
}
```

#### 3.3.5 缓存策略

- 排名结果缓存至Redis，过期时间1小时
- 首页调用缓存，筛选/排序实时计算
- 缓存Key格式：`ranking:v1:{category}:{sort_key}:{filters_hash}`
- 自定义公式缓存：`ranking:v1:custom:{formula_hash}:{filters_hash}`

```typescript
// lib/feature-flags.ts
export async function checkFeatureEnabled(
  key: string,
  user?: User
): Promise<boolean> {
  // 1. 获取全局配置
  const globalFlag = await prisma.featureFlag.findUnique({ where: { key } });
  if (!globalFlag) return false;
  if (!globalFlag.enabled) return false;
  
  // 2. 检查权限要求
  if (globalFlag.requireAuth && !user) return false;
  if (globalFlag.requireRole && user?.role !== globalFlag.requireRole) return false;
  if (globalFlag.requireSubscription && !user?.subscription) return false;
  
  // 3. 检查用户覆盖
  if (user) {
    const userFlag = await prisma.userFeatureFlag.findUnique({
      where: { userId_featureKey: { userId: user.id, featureKey: key } }
    });
    if (userFlag) return userFlag.enabled;
  }
  
  return globalFlag.enabled;
}

// 前端Hook
export function useFeatureFlag(key: string) {
  const { data } = useSWR(`/api/features/${key}`, fetcher);
  return {
    enabled: data?.enabled ?? false,
    isLoading: !data
  };
}
```

### 13.2 余额服务核心逻辑

```typescript
// lib/wallet.ts

/**
 * 预扣费：操作开始前冻结金额
 * @returns transactionId 用于后续确认或退还
 */
export async function preDeduct(params: {
  userId: string;
  amount: number;
  description: string;
  refType: string;
  refId?: string;
}): Promise<{ transactionId: string; success: boolean; error?: string }> {
  // 1. 检查余额是否充足（使用 SELECT FOR UPDATE 行锁）
  const user = await prisma.$queryRaw`
    SELECT balance FROM "User" WHERE id = ${params.userId} FOR UPDATE
  `;
  
  if (user.balance < params.amount) {
    return { transactionId: '', success: false, error: 'INSUFFICIENT_BALANCE' };
  }
  
  // 2. 创建扣费记录（status: pending）
  const transaction = await prisma.transaction.create({
    data: {
      userId: params.userId,
      type: 'CHARGE',
      amount: -params.amount,
      balance: user.balance - params.amount, // 预计余额
      description: params.description,
      refType: params.refType,
      refId: params.refId,
    }
  });
  
  // 3. 扣减余额
  await prisma.user.update({
    where: { id: params.userId },
    data: { balance: { decrement: params.amount } }
  });
  
  return { transactionId: transaction.id, success: true };
}

/**
 * 确认扣费：操作成功，保持扣费
 */
export async function confirmDeduct(transactionId: string): Promise<void> {
  // 扣费已在 preDeduct 中完成，此处可更新状态或记录日志
  await prisma.transaction.update({
    where: { id: transactionId },
    data: { /* 可标记为 confirmed */ }
  });
}

/**
 * 退还扣费：操作失败，退回余额
 */
export async function refund(transactionId: string): Promise<void> {
  const transaction = await prisma.transaction.findUniqueOrThrow({
    where: { id: transactionId }
  });
  
  // 创建退款记录
  await prisma.transaction.create({
    data: {
      userId: transaction.userId,
      type: 'REFUND',
      amount: Math.abs(transaction.amount),
      balance: 0, // 将在下面更新
      description: `退还：${transaction.description}`,
      refType: transaction.refType,
      refId: transaction.refId,
    }
  });
  
  // 退回余额
  await prisma.user.update({
    where: { id: transaction.userId },
    data: { balance: { increment: Math.abs(transaction.amount) } }
  });
}

/**
 * 查询余额
 */
export async function getBalance(userId: string): Promise<number> {
  const user = await prisma.user.findUniqueOrThrow({
    where: { id: userId },
    select: { balance: true }
  });
  return user.balance;
}

/**
 * 充值到账
 */
export async function recharge(params: {
  userId: string;
  amount: number;
  bonusAmount: number;
  payMethod: string;
  transactionId: string; // 第三方支付交易号
}): Promise<void> {
  const totalAmount = params.amount + params.bonusAmount;
  
  // 使用事务确保原子性
  await prisma.$transaction(async (tx) => {
    // 更新充值订单状态
    await tx.rechargeOrder.updateMany({
      where: { transactionId: params.transactionId, status: 'PENDING' },
      data: { status: 'PAID', paidAt: new Date() }
    });
    
    // 增加用户余额
    await tx.user.update({
      where: { id: params.userId },
      data: { balance: { increment: totalAmount } }
    });
    
    // 创建充值记录
    await tx.transaction.create({
      data: {
        userId: params.userId,
        type: 'RECHARGE',
        amount: totalAmount,
        balance: await tx.user.findUniqueOrThrow({ where: { id: params.userId } }).then(u => u.balance),
        description: `充值 ¥${params.amount}${params.bonusAmount > 0 ? `（赠送 ¥${params.bonusAmount}）` : ''}`,
      }
    });
  });
}
```

### 13.3 充值流程

```
用户选择档位 → 创建充值订单（PENDING）→ 调起微信/支付宝支付
    ├─ 支付成功 → 支付网关回调 /api/payment/callback → 验签 → recharge() → 返回成功
    ├─ 支付失败 → 更新订单为 FAILED
    └─ 超时未支付 → 定时任务扫描过期订单 → 更新为 EXPIRED
```

// useApi.ts fetcher 兼容两种格式
const fetcher = async <T>(url: string): Promise<T> => {
  const res = await api.get<ApiResponse<T> | T>(url);
  // 格式1: { success: true, data: T }
  // 格式2: T 直接返回
  if (res && typeof res === "object" && "success" in res && "data" in res) {
    return (res as ApiResponse<T>).data;
  }
  return res as T;
};
