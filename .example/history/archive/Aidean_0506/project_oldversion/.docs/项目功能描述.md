## 二、天梯图模块（核心功能）

### 2.1 功能概览

天梯图是平台的核心差异化功能，提供**多维度模型评测可视化**，支持：
- **5类天梯图**：大模型、Skills、MCP、Agent、API站
- **2种版本**：专业版（面向开发者）、应用版（面向业务人员）
- **2种视图**：排行榜表格（矩阵式）、柱状图
- **6维筛选** + **5种排序**（含自定义公式）

### 2.2 视图与版本切换

#### 实现效果

- 顶部右侧：视图切换「排行榜表格 / 柱状图」，**默认排行榜表格**
- 顶部Banner采用三段式：中间主标题与副标题，右侧并列「表格设置」与「数据说明」卡片

- **位置**：天梯图Banner下方，与排序栏同行排列

- **排列方式**：从左到右依次为：类型、协议、开源、测评集、标签、时间

#### 前端实现逻辑（Zustand Store）

**状态存储**：
```typescript
// stores/filterStore.ts
interface FilterState {
  // 筛选条件
  type: string[];           // 类型：['CHAT', 'MULTIMODAL', ...]
  protocol: string[];       // 协议：['OPENAI', 'ANTHROPIC', ...]
  openSource: string[];     // 开源：['true', 'false'] 或空（不过滤）
  benchmark: string;        // 测评集：'INFERENCE' | 'BENCHMARK_X' 或 ''（单选）
  tags: string[];          // 标签：['免费', 'CodingPlan', '用户新增标签']
  timeRange: {            // 时间范围
    start: Date | null;
    end: Date | null;
  };
  
  // 方法
  toggleType: (t: string) => void;     // 切换类型选中状态
  toggleProtocol: (p: string) => void; // 切换协议选中状态
  setBenchmark: (b: string) => void;  // 设置测评集（单选）
  addTag: (tag: string) => void;        // 新增标签
  setTimeRange: (s: Date|null, e: Date|null) => void;
}
```

**筛选流程**：
1. 用户操作（如勾选"对话"类型）→ 调用`toggleType('CHAT')`
2. 更新`filterStore.type`状态 → 触发`useEffect`监听
3. 生成筛选参数hash：`filterHash = MD5(JSON.stringify({type, protocol, openSource, benchmark, tags, timeRange}))`
4. 调用API：`GET /api/v1/models?filters={filterHash}`
5. 更新模型列表：`modelStore.setModels(newModels)`
6. 缓存结果：Redis存储`models:v1:list:{filterHash}`，过期时间1小时

### 2.4 排序功能交互逻辑

- **位置**：位于6个筛选按钮的最右侧，与筛选按钮**同行排列**

##### 5. 自定义排序【公式输入】
| 属性 | 说明 |
|---|---|
| **排序逻辑** | 用户输入计算公式，系统解析后计算得分并排序 |
| **变量支持** | `${综合评分}`/`${benchmark}`、`${上下文长度}`/`${context}`、`${响应速度}`/`${speed}`、`${价格}`/`${price}` |
| **运算符** | `+`（加）、`-`（减）、`*`（乘）、`/`（除）、`()`（括号）、`^`（幂）、`<`（升序）、`>`（降序） |
| **默认值** | 否（非默认） |
| **交互** | 点击展开公式输入框，输入后立即解析生效 |

**公式语法规则**：
```
expression := term (('+' | '-') term)*
term       := factor (('*' | '/') factor)*
factor     := base ('^' exponent)?
base       := variable | number | '(' expression ')'
variable   := '$' '{' NAME '}'
NAME       := '综合评分' | '上下文长度' | '响应速度' | '价格' | 'benchmark' | 'context' | 'speed' | 'price'
```

**公式示例与语义**：
| 公式 | 语义 | 排序方向 |
|---|---|---|
| `${价格}/1000000*${响应速度}` | 价格越低×响应越快，得分越高 | 降序（>） |
| `${综合评分}/${价格}` | 得分高且价格低优先 | 降序（>） |
| `${上下文长度}*0.5+${综合评分}*0.5` | 上下文与得分均衡 | 降序（>） |
| `${价格}<100000` | 仅价格在100000内的模型，按价格升序 | 升序（<） |

**实时解析流程**：
1. 用户在输入框中填入公式（如`${价格}/1000000*${响应速度}`）
2. 系统检测输入变化（onChange事件）→ 触发解析函数`parseFormula(formula, ctx)`
3. 替换变量为实际值：`${(price / 1000000) * speed}`
4. 安全计算（使用`math.js`或`safe-eval`库）
5. 得到每个模型的自定义得分 → 按得分降序排列
6. 更新排行榜表格/柱状图
7. 公式错误时：显示红色错误提示"公式语法错误，请检查"，**不影响**当前排序结果

**前端实现**：
```typescript

interface SortState {
  currentSort: string;        // 'benchmark_desc' | 'context_desc' | 'speed_desc' | 'price_asc' | 'custom'
  customFormula: string;       // 用户自定义公式
  formulaError: string | null;  // 公式错误信息
  sortDirection: 'ASC' | 'DESC';  // 排序方向
}

// 解析公式函数
function parseFormula(formula: string, ctx: FormulaContext): number {
  const variables = {
    '综合评分': ctx.benchmark, 'benchmark': ctx.benchmark,
    '上下文长度': ctx.context, 'context': ctx.context,
    '响应速度': ctx.speed, 'speed': ctx.speed,
    '价格': ctx.price, 'price': ctx.price,
  };
  
  // 替换变量为实际值
  let expr = formula.replace(/\$\{([^}]+)\}/g, (_, name) =>
    String(variables[name.trim()] ?? 0)
  );
  
  // 安全计算（使用 math.js）
  try {
    return math.evaluate(expr);
  } catch (e) {
    throw new Error('公式语法错误');
  }
}
```

### 2.7 背后数据逻辑

#### 排名算法详解

##### 四维评分体系
| 维度 | 来源 | 默认满分 | 权重（可配置） | 数据字段（Prisma） |
|---|---|---|---|---|
| 官方评测基准 | 模型官方/评测机构公布数据 | 100 | 25% (可调) | `model_scores.official_score` |
| 实际评测基准 | 第三方平台实测数据（Arena等） | 100 | 25% (可调) | `model_scores.actual_score` |
| 风评 | 用户社区/网络评价 | 100 | 25% (可调) | `model_scores.review_score` |
| 自测 | 平台自主测试 | 100 | 25% (可调) | `model_scores.self_test_score` |

**综合得分计算公式**：
```
综合得分 = (官方得分 × 官方权重 + 实际得分 × 实际权重 + 风评得分 × 风评权重 + 自测得分 × 自测权重) / 100
```

**公式拆解**：
```
compositeScore = (
  officialScore * (officialWeight / 100) +
  actualScore * (actualWeight / 100) +
  reviewScore * (reviewWeight / 100) +
  selfTestScore * (selfTestWeight / 100)
)
```

##### 权重管理（后台可配置）
| 属性 | 说明 |
|---|---|
| **配置入口** | 后台「系统设置」→「排名权重」 |
| **可调范围** | 0~100%（整数） |
| **归一化** | 权重总和自动归一化为100%（如25%+25%+25%+25%=100%） |
| **实时生效** | 调整后自动触发重新计算所有模型得分 |
| **默认配置** | 官方25% + 实际25% + 风评25% + 自测25% |

**权重配置表**（数据库：`ranking_weights`）：
| dimension | weight | is_active | description |
|---|---|---|---|
| official | 25 | true | 官方评测基准 |
| actual | 25 | true | 实际评测基准 |
| review | 25 | true | 风评 |
| self | 25 | true | 自测 |

**权重调整流程**：
```
管理员在后台调整权重（如 official=30, actual=20, review=30, self=20)
  ↓
更新 `ranking_weights` 表
  ↓
触发重新计算：重新查询所有模型的四个维度得分
  ↓
按新权重计算 `compositeScore`
  ↓
更新 `model_scores.composite_score` 字段
  ↓
缓存失效：删除所有 `ranking:v1:*` 缓存
  ↓
前端刷新天梯图，显示新排名
```

##### 模型列表查询（天梯图）
```typescript
// app/api/v1/models/route.ts
export async function GET(request: Request) {
  const { searchParams } = new URL(request.url);
  const filterHash = searchParams.get('filters') || '';
  const sortKey = searchParams.get('sort') || 'benchmark_desc';
  
  // 1. 尝试从Redis获取缓存
  const cacheKey = `models:v1:list:${filterHash}`;
  const cached = await redis.get(cacheKey);
  if (cached) return Response.json(JSON.parse(cached));
  
  // 2. 构建筛选条件
  const where: any = { isActive: true, status: 'ACTIVE' };
  if (filterHash) {
    const filters = JSON.parse(decodeURIComponent(filterHash));
    if (filters.type?.length) where.modelType = { in: filters.type };
    if (filters.protocol?.length) where.protocol = { in: filters.protocol };
    if (filters.openSource?.length) where.isOpenSource = filters.openSource.includes('true');
    if (filters.benchmark) where.benchmarks = { some: { sourceType: filters.benchmark } };
    if (filters.tags?.length) where.tags = { hasSome: filters.tags };
    if (filters.timeRange?.start) where.publishedAt = { gte: new Date(filters.timeRange.start) };
    if (filters.timeRange?.end) where.publishedAt = { lte: new Date(filters.timeRange.end) };
  }
    
  // 3. 构建排序条件
  const orderBy: any = {};
  if (sortKey === 'benchmark_desc') orderBy.model_scores = { compositeScore: 'desc' };
  else if (sortKey === 'context_desc') orderBy.contextLength = 'desc';
  else if (sortKey === 'speed_desc') orderBy.benchmarks = { some: { totalScore: 'desc' } };  // 需解析速度
  else if (sortKey === 'price_asc') orderBy.model_prices = { some: { priceInput: 'asc' } };  // 需取当前价格
  else if (sortKey.startsWith('custom:')) {
    // 自定义排序：先查所有，再在前端按公式计算
  }
    
  // 4. 查询数据库
  const models = await prisma.aiModel.findMany({
    where,
    orderBy: Object.keys(orderBy).length ? orderBy : { model_scores: { compositeScore: 'desc' } },
    include: {
      vendor: true,
      model_scores: true,
      model_prices: { where: { isCurrent: true } },
      benchmarks: { take: 1, orderBy: { recordedAt: 'desc' } },
    },
    take: 100,  // 最大显示100个模型
  });
    
  // 5. 缓存结果
  await redis.setex(cacheKey, 3600, JSON.stringify(models));  // 1小时
    
  return Response.json(models);
}
```

##### 综合得分计算（定时任务）
```typescript
// scripts/ranking/update_ranking.ts
async function updateAllScores() {
  // 1. 获取权重配置
  const weights = await prisma.rankingWeight.findMany({ where: { isActive: true } });
  const totalWeight = weights.reduce((sum, w) => sum + w.weight, 0);
  const normalizedWeights = weights.map(w => ({
    dimension: w.dimension,
    weight: w.weight / totalWeight,  // 归一化
  }));
    
  // 2. 获取所有模型
  const models = await prisma.aiModel.findMany({
    include: { model_scores: true },
  });
    
  // 3. 计算每个模型的新得分
  for (const model of models) {
    const scores = model.model_scores[0];  // 最新一条
    if (!scores) continue;
      
    const officialScore = scores.officialScore || 0;
    const actualScore = scores.actualScore || 0;
    const reviewScore = scores.reviewScore || 0;
    const selfTestScore = scores.selfTestScore || 0;
      
    const compositeScore =
      officialScore * normalizedWeights.find(w => w.dimension === 'official')!.weight +
      actualScore * normalizedWeights.find(w => w.dimension === 'actual')!.weight +
      reviewScore * normalizedWeights.find(w => w.dimension === 'review')!.weight +
      selfTestScore * normalizedWeights.find(w => w.dimension === 'self')!.weight;
      
    // 4. 更新数据库
    await prisma.modelScore.update({
      where: { id: scores.id },
      data: { compositeScore, calcAt: new Date(), isCurrent: true },
    });
      
    // 5. 更新排名（按compositeScore降序）
    // ...（略）
  }
    
  // 6. 清除缓存
  await redis.delPattern('ranking:v1:*');
}
```

##### 缓存Key生成规则
**1. 筛选条件Hash**：
```typescript
function generateFilterHash(filters: FilterState): string {
  // 将筛选条件对象序列化为字符串
  const str = JSON.stringify({
    type: filters.type.sort(),
    protocol: filters.protocol.sort(),
    openSource: filters.openSource.sort(),
    benchmark: filters.benchmark,
    tags: filters.tags.sort(),
    timeRange: filters.timeRange,
  });
  // 生成MD5哈希（16进制字符串）
  return crypto.createHash('md5').update(str).digest('hex');  // 如 "a1b2c3d4e5f6..."
}
```

**2. 公式Hash**（自定义排序）：
```typescript
function generateFormulaHash(formula: string): string {
  return crypto.createHash('md5').update(formula).digest('hex');
}
```

```
  ↓

  ↓
```

#### 注册流程
| 步骤 | 说明 |
|---|---|
| **入口** | 导航栏「注册」按钮 / `/auth/register` |
| **必填字段** | 邮箱（唯一）、密码（6-20位）、确认密码 |
| **验证** | 邮箱格式校验（正则：`/^[^\s@]+@[^\s@]+\.[^\s@]+$/`）、密码强度提示 |
| **提交** | POST `/api/v1/auth/register` → 写入`users`表 → 自动登录（返回JWT） |
| **反馈** | 成功：跳转首页，Toast提示"注册成功"；失败：红色提示（邮箱已存在等） |

**前端实现**：
```typescript
// app/(web)/auth/register/page.tsx
'use client';

import { useState } from 'react';
import { useRouter } from 'next/navigation';

export default function RegisterPage() {
  const [email, setEmail] = useState('');
  const [password, setPassword] = useState('');
  const [confirm, setConfirm] = useState('');
  const [error, setError] = useState('');
  const router = useRouter();

  const handleSubmit = async (e: FormEvent) => {
    e.preventDefault();
    setError('');

    // 前端校验
    if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email)) {
      setError('邮箱格式不正确');
      return;
    }
    if (password.length < 6 || password.length > 20) {
      setError('密码长度6-20位');
      return;
    }
    if (password !== confirm) {
      setError('两次密码不一致');
      return;
    }

    // 提交注册
    const res = await fetch('/api/v1/auth/register', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ email, password }),
    });
    
    if (res.ok) {
      const { token, user } = await res.json();
      localStorage.setItem('token', token);  // 存储JWT
      router.push('/');  // 跳转首页
    } else {
      const { message } = await res.json();
      setError(message || '注册失败');
    }
  };

  return (
    <form onSubmit={handleSubmit}>
      <input type="email" value={email} onChange={e => setEmail(e.target.value)} placeholder="邮箱" />
      <input type="password" value={password} onChange={e => setPassword(e.target.value)} placeholder="密码" />
      <input type="password" value={confirm} onChange={e => setConfirm(e.target.value)} placeholder="确认密码" />
      {error && <p className="text-red-500">{error}</p>}
      <button type="submit">注册</button>
    </form>
  );
}
```

```typescript
// lib/auth/jwt.ts
import jose from 'jose';

export async function generateJWT(user: { id: string; email: string; role: string }) {
  const token = await new jose.SignJWT(
    { userId: user.id, email: user.email, role: user.role },
    new TextEncoder().encode(process.env.JWT_SECRET!)
  )
    .setExpirationTime('24h')  // Access Token 24小时
    .sign();

  const refreshToken = await new jose.SignJWT(
    { userId: user.id },
    new TextEncoder().encode(process.env.JWT_REFRESH_SECRET!)
  )
    .setExpirationTime('7d')  // Refresh Token 7天
    .sign();

  return { token, refreshToken };
}
```

```typescript
export async function POST(request: Request) {
  const { refreshToken } = await request.json();
    
  try {
    // 验证Refresh Token
    const { payload } = await jose.jwtVerify(
      refreshToken,
      new TextEncoder().encode(process.env.JWT_REFRESH_SECRET!)
    );
    
    // 查询用户
    const user = await prisma.user.findUnique({
      where: { id: (payload as any).userId },
    });
    if (!user) return Response.json({ error: '用户不存在' }, { status: 401 });
    
    // 生成新的Access Token
    const newToken = await generateAccessToken(user);
    return Response.json({ token: newToken });
  } catch (e) {
    return Response.json({ error: 'Token无效或已过期' }, { status: 401 });

}
```

```typescript
// lib/billing/charge.ts
export async function preCharge(userId: string, amount: number, refType: string, refId: string) {
  // 1. 检查余额
  const user = await prisma.user.findUnique({ where: { id: userId } });
  if (user!.balance < amount) {
    throw new Error('余额不足');
  }
  
  // 2. 预扣费
  await prisma.$transaction([
    prisma.user.update({
      where: { id: userId },
      data: { balance: { decrement: amount } },
    }),
    prisma.transaction.create({
      data: {
        userId,
        type: 'CHARGE',
        amount: -amount,
        balance: user!.balance - amount,
        description: `预扣费：${refType}`,
        refType,
        refId,
      },
    }),
  ]);
  
  return { success: true, balance: user!.balance - amount };
}
```

```typescript
export async function GET(request: Request) {
  const { searchParams } = new URL(request.url);
  const search = searchParams.get('search') || '';
  const category = searchParams.get('category') || '';
  const page = parseInt(searchParams.get('page') || '1');
  
  const where: any = {};
  if (search) where.OR = [

    { content: { path: ['summary'], string_contains: search } },

  if (category) where.source = category;
  
  const news = await prisma.news.findMany({

    orderBy: { publishedAt: 'desc' },
    skip: (page - 1) * 20,
    take: 20,
  });
```

```typescript
export function AIAssistant() {
  const [isOpen, setIsOpen] = useState(false);
  const [messages, setMessages] = useState<Message[]>([]);
  
  // 调用平台AI员工API
  const sendMessage = async (content: string) => {
    const response = await fetch('/api/v1/ai-employee/chat', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ 
        message: content,
        employeeType: 'customer_service', // 使用客服AI员工
        context: { page: window.location.pathname } // 传入当前页面上下文
      })
    });
    const data = await response.json();
    setMessages([...messages, { role: 'assistant', content: data.reply }]);
  };
  
  return (
    <div className="fixed bottom-4 right-4 z-50">
      {/* 浮动图标 */}
      <button 
        onClick={() => setIsOpen(!isOpen)}
        className="w-16 h-16 rounded-full bg-blue-600 text-white shadow-lg pulse-animation"
      >
        🤖
      </button>
      
      {/* 对话窗口 */}
      {isOpen && (
        <div className="absolute bottom-20 right-0 w-96 h-[500px] bg-white rounded-lg shadow-xl">
          {/* 对话内容 */}
        </div>
      )}
    </div>
  );
}
```
