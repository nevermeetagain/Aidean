## 一、测试概述

本文档记录如何使用 Chrome DevTools MCP 进行自动化浏览器测试，适用于 Next.js Web 应用的 UI 测试、交互验证、截图采集等场景。

### 1.1 核心能力

| 能力 | 说明 |
|------|------|
| 页面导航 | 自动打开 URL，支持无痕模式 |
| 元素交互 | 点击、悬停、填表、文件上传 |
| 快照获取 | 无障碍树快照（Accessibility Tree） |
| 截图 | 可见区域截图、全页面截图 |
| 控制台监控 | 错误/警告信息捕获 |
| 网络监控 | 请求/响应记录 |

### 1.2 测试环境

| 组件 | 版本/信息 |
|------|-----------|
| 开发服务器 | Next.js 14.2.5，端口 3001 |
| 数据库 | PostgreSQL 18.1 |
| 缓存 | Redis x64-5.0.14 |
| 浏览器 | Chrome（DevTools Protocol） |

## 三、测试命令手册

### 3.1 页面操作

| 命令 | 说明 |
|------|------|
| `chrome-devtools_new_page` | 打开新标签页 |
| `chrome-devtools_navigate_page` | 导航到指定 URL |
| `chrome-devtools_close_page` | 关闭页面 |
| `chrome-devtools_select_page` | 选择页面作为当前页 |

### 3.2 元素交互

| 命令 | 说明 |
|------|------|
| `chrome-devtools_click` | 点击元素 |
| `chrome-devtools_fill` | 填写输入框 |
| `chrome-devtools_hover` | 悬停 |
| `chrome-devtools_type_text` | 输入文本 |
| `chrome-devtools_press_key` | 按键（Enter/Escape 等） |
| `chrome-devtools_upload_file` | 上传文件 |

### 3.3 获取页面状态

| 命令 | 说明 |
|------|------|
| `chrome-devtools_take_snapshot` | 获取无障碍树快照 |
| `chrome-devtools_take_screenshot` | 截图 |
| `chrome-devtools_list_console_messages` | 获取控制台消息 |
| `chrome-devtools_list_network_requests` | 获取网络请求 |
| `chrome-devtools_get_network_request` | 获取指定请求详情 |

### 3.4 等待与条件

| 命令 | 说明 |
|------|------|
| `chrome-devtools_wait_for` | 等待指定文本出现 |
| `chrome-devtools_evaluate_script` | 执行 JavaScript |

## 四、测试流程示例

### 4.1 示例：测试 Demo 页面

#### 步骤 1：导航到页面

```python
# 打开 demo1 页面
chrome-devtools_navigate_page(type="url", url="http://localhost:3001/demo/demo1")
```

#### 步骤 2：获取页面快照

```python
# 获取无障碍树（用于分析元素结构）
chrome-devtools_take_snapshot()
```

返回示例：
```
uid=1_0 RootWebArea "AI 模型天梯图（示例）" url="http://localhost:3001/demo/demo1"
  uid=1_1 banner
    uid=1_2 link "AigcLadderDiagram" url="http://localhost:3001/"
      uid=1_3 image "AigcLadderDiagram"
    uid=1_5 navigation
      uid=1_6 link "首页"
      uid=1_8 button "模型" expandable haspopup="menu"
      uid=1_9 button "资源" expandable haspopup="menu"
```

#### 步骤 3：点击交互

```python
# 点击导航菜单
chrome-devtools_click(uid="1_8")  # "模型"按钮
```

#### 步骤 4：截图

```python
# 截图当前可见区域
chrome-devtools_take_screenshot(filePath=".tmp/screens/demo1.png")

# 截图整页
chrome-devtools_take_screenshot(filePath=".tmp/screens/demo1-full.png", fullPage=true)
```

## 五、页面元素 UID 识别

### 5.1 从快照中识别

页面快照中每个元素都有唯一 `uid`，格式为 `{数字}_{数字}`，例如：
- `1_0`：根元素
- `1_8`：第1页第8个元素
- `5_29`：第5页第29个元素

### 5.2 常见元素模式

| 元素类型 | UID 模式 | 示例 |
|----------|----------|------|
| 按钮 | `button` | `uid=1_8 button "模型"` |
| 链接 | `link` | `uid=1_2 link "AigcLadderDiagram"` |
| 输入框 | `textbox` | `uid=1_13 textbox "搜索"` |
| 下拉框 | `combobox` | `uid=1_48 combobox "排序方式"` |
| 标题 | `heading` | `uid=1_18 heading "大模型性能天梯图"` |

## 六、测试脚本模板

### 6.1 完整测试脚本示例

```python
# 1. 启动服务并等待就绪
# npm run dev（已在后台运行）

# 2. 打开测试页面
chrome-devtools_new_page(url="http://localhost:3001/demo/demo1")

# 3. 等待页面加载
chrome-devtools_wait_for(text=["大模型性能天梯图", "Demo1"])

# 4. 截图
chrome-devtools_take_screenshot(filePath=".tmp/screens/demo1-test.png")

# 5. 测试交互：点击筛选按钮
chrome-devtools_click(uid="1_40")  # OpenAI 筛选按钮

# 6. 等待结果更新
chrome-devtools_wait_for(text=["GPT-4o"])

# 7. 检查控制台错误
chrome-devtools_list_console_messages(types=["error"])

# 8. 清理
chrome-devtools_close_page(pageId=1)
```

### 6.2 批量测试多个页面

```python
# 测试所有 demo 页面
pages = [
    "/demo/demo1",
    "/demo/demo2", 
    "/demo/demo3",
    "/demo/demo4"
]

for page in pages:
    chrome-devtools_navigate_page(url=f"http://localhost:3001{page}")
    chrome-devtools_take_snapshot()
    chrome-devtools_take_screenshot(filePath=f".tmp/screens/{page}.png")
```

## 七、故障排查

### 7.1 常见错误

| 错误 | 原因 | 解决方案 |
|------|------|----------|
| `net::ERR_CONNECTION_REFUSED` | 服务未启动 | 启动 `npm run dev` |
| `Request timed out` | 页面加载超时 | 增加等待或检查服务状态 |
| 元素未找到 | UID 变化 | 重新获取快照 |

### 7.2 调试技巧

```python
# 1. 先获取快照查看当前页面结构
chrome-devtools_take_snapshot()

# 2. 检查控制台错误
chrome-devtools_list_console_messages(types=["error", "warn"])

# 3. 执行 JavaScript 调试
chrome-devtools_evaluate_script(function="() => document.title")
```
