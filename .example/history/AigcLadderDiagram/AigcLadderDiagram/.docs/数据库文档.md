## 1. 文档目的
- 用一份文档覆盖数据库设计规范、初始化方式、验证与排障。
- 默认适配 PostgreSQL 16+，主业务库为 `aidean`。

## 2. 设计基线
### 2.1 设计原则
- 命名统一：蛇形命名、复数表名、显式外键。
- 可扩展：支持 JSONB 扩展字段与预留字段。
- 可审计：统一 `created_at/updated_at/deleted_at`。
- 可维护：索引、约束、注释规范化。

### 2.2 通用字段建议
| 字段名 | 类型 | 说明 |
|---|---|---|
| `id` | CUID/String 或 BIGINT | 主键 |
| `created_at` | TIMESTAMPTZ | 创建时间 |
| `updated_at` | TIMESTAMPTZ | 更新时间 |
| `deleted_at` | TIMESTAMPTZ NULL | 软删除 |
| `is_active` | BOOLEAN | 激活状态 |
| `tenant_id` | BIGINT 或 String | 多租户标识 |

### 2.3 Schema 领域划分（摘要）
- `aidean_core`：用户、会话、认证、订阅。
- `aidean_models`：厂商、模型、价格、评分、榜单、评测。
- `aidean_tools`：Skills、MCP、Agent、API 站。
- `aidean_agent`：分身、知识文档、模板、对话。

## 3. 初始化脚本结构
```text
docker/sql/
├── aidean_full_init.sql
├── generate_full_init.ps1
└── init/
    ├── 01_create_extensions.sql
    ├── 02_create_schemas.sql
    ├── 03_create_tables.sql
    ├── ...
    └── 13_seed_agent_data.sql
```

## 4. 初始化方式
### 4.1 一次性初始化（推荐）
```bash
psql -U postgres -d aidean -f docker/sql/aidean_full_init.sql
```

### 4.2 分段初始化（调试）
```bash
cd docker/sql/init
psql -U postgres -d aidean -f 01_create_extensions.sql
psql -U postgres -d aidean -f 02_create_schemas.sql
psql -U postgres -d aidean -f 03_create_tables.sql
```

### 4.3 Docker 初始化（容器首启）
- 将 `aidean_full_init.sql` 挂载到 `/docker-entrypoint-initdb.d/init.sql`。
- 仅在数据库数据卷首次创建时自动执行。


### 6.3 编码检查
```sql

```

## 7. 常见故障
### 7.1 表已存在
- 使用幂等脚本（`IF NOT EXISTS`）。
- 增量修改采用条件 `DO $$ ... $$` 语句。

### 7.2 编码异常
- 会话强制 `SET client_encoding='UTF8'`。
- 必要时重建数据库并导出/导入 UTF-8 数据。

### 7.3 权限不足
```sql
GRANT ALL PRIVILEGES ON DATABASE aidean TO app_user;
GRANT ALL PRIVILEGES ON ALL TABLES IN SCHEMA public TO app_user;
```

## 8. 变更策略
- 结构变更优先走 Prisma 迁移流程。
- SQL 手工变更必须补齐文档与回滚说明。
- 涉及字段删除或类型变更时必须先做备份。
