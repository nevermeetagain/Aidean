# Aidean 操作手册（合并版）

> 版本：v2.0（合并版）  
> 更新日期：2026-05-07  
> 来源：合并 `操作手册.md` + `Docker配置文档.md` + `部署与运维文档.md` + `数据库初始化指南.md`

---

## 1. 适用范围
- 主站 Web（Next.js App Router）启动、部署、运维与数据库初始化。
- 当前文档为唯一操作入口，按“开发 -> 部署 -> 验证 -> 排障”执行。

## 2. 环境要求
- Node.js：20.x
- npm：10.x+
- Docker / Docker Compose
- PostgreSQL：16+
- Redis：7+

## 3. 开发环境启动
### 3.1 本机启动
```bash
npm install
npx prisma generate
npx prisma db push
npm run dev
```

### 3.2 访问地址
- `http://localhost:3000`

## 4. Docker 部署（生产默认）
### 4.1 一键启动
```bash
docker compose up -d
```

### 4.2 一键停止
```bash
docker compose down
```

### 4.3 国内镜像强约束
- 所有镜像默认优先国内源（如阿里云镜像仓）。
- 禁止在主流程中仅给出国外镜像拉取方式。

### 4.4 基线服务
- `postgres`：主数据库
- `redis`：缓存与会话辅助
- `web`：Next.js 应用
- `nginx`：反向代理与网关

## 5. 数据库初始化与种子
### 5.1 Prisma 方案（推荐）
```bash
npx prisma generate
npx prisma db push
npm run db:seed
```

### 5.2 SQL 全量方案
```bash
psql -U postgres -d aidean -f docker/sql/aidean_full_init.sql
```

### 5.3 默认管理员
| 角色 | 邮箱 | 密码 |
|---|---|---|
| 超级管理员 | `admin@aidean.com` | `Admin123!@#` |

## 6. 上线前验证
### 6.1 容器与服务
```bash
docker compose ps
```

### 6.2 健康检查
```bash
curl http://localhost:3000/api/v1/system/health
```

### 6.3 数据库连通
```bash
pg_isready -h localhost -p 5432
```

### 6.4 页面回归最小集
- 首页：`/`
- 模型页：`/aidean` 或 `/models`
- 资源页：`/space` 或 `/resources`
- 产品页：`/sphere` 或 `/products`

## 7. 运维巡检清单
- 数据库连接正常，迁移状态一致。
- Redis 可读写，缓存无明显堆积。
- Web 服务无启动级错误。
- Nginx 反向代理正常，静态资源可访问。
- 关键 API（`health/stats`）返回稳定。

## 8. 常见问题处理
### 8.1 镜像拉取失败
- 优先检查国内镜像仓前缀配置。

### 8.2 服务未就绪
- 检查 `postgres`、`redis` 健康状态，再看 `web` 启动日志。

### 8.3 接口超时
- 检查数据库连接池、Redis 连通与网络配置。

### 8.4 页面异常
- 检查 Next.js 构建日志与运行日志。

## 9. 安全与配置
- 真实密钥严禁入库，使用 `.env.example` 提供模板。
- 生产环境必须替换默认密码与密钥。
- 变更配置后必须同步更新 `.docs/文档索引.md` 与 `.memory.md`。
