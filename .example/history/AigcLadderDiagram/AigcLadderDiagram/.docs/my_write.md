## 注意事项

### 1. 布局空间利用问题
- **左右留白问题**：页面主体内容（评测工作台模块）仅居中显示，左右两侧存在大量空白区域，未充分利用屏幕宽度空间，导致布局松散、视觉失衡。
- **容器宽度限制**：核心内容区域（包含筛选栏和天梯矩阵表格）被固定在较窄的容器内，即使在宽屏设备下也未自适应扩展。
### 2. 内容显示问题
- **元素遮挡/隐藏**：
  - 天梯矩阵表格右侧存在横向滚动条，表明表格内容宽度超出容器显示范围，部分数据（如模型名称、详细指标）可能被截断或需要滚动查看。
  - 页面顶部的导航栏与主体内容之间的间距较小，可能导致视觉上的拥挤感。
  - 评测工作台模块内的“命中”、“已跳身”等状态标签及操作按钮（如“OK”）布局紧凑，存在潜在的交互遮挡风险。
### 3. 视觉层次问题
- 整体布局缺乏层次感，主体内容与留白区域对比强烈，未能通过合理的间距或辅助元素填充空白，影响页面整体美观度。

## 核心功能


### 自动进化
- 无需任何提示，自动触发！
- 创建完全符合用户思维习惯、责任感、审美、接受程度等的分身。
- 从对话记录、输入记录中，主动学习用户的说话方式、思维方式。
- 在之后的使用中，实现越用越聪明的效果。
- 在用户纠正过程中，必须重点反省并总结，更新分身。
- 用户可以选择上传文件作为分身学习数据。
- 分身数据庞大且需要提取，至少是100万的数据。


### 自动执行
- 在收到用户需求，保证能99%理解用户需求后，后续不需用户确认任何问题的情况下，使用用户分身完成详细的需求。


### 文件系统
1. 必须支持文档上传识别(Txt、Markdown、Word、Excel、PDF)等。
2. 必须支持文档存储和检索。
3. 支持对话中的图片识别。


### 文档创作
1. 必须支持markdown转html，支持下载。
2. 必须支持规定格式的论文输出。
3. 必须支持各学校的论文格式的保存，支持自动整理。


### 工具和流程
1. 必须支持Skill
2. 必须支持MCP（json格式和http格式）
3. 必须支持智能体创建(父智能体:可定义名字、可定义模型、可定义操作范围(全局、选择目录、None)、可定义权限(增删改查)、可定义Skill、可定义MCP、可定义输出规则(流式、非流式、None)、可调用子智能体)
4. 必须支持子智能体创建
5. 必须支持多智能体并发协作(父智能体可以调用子智能体，子智能体:可定义模型、可定义调用规则(顺序调用,并行执行,不可被调用)、可定义权限(增删改查)、可定义操作范围(全局、选择目录、None)、可定义名字、可定义ID、可定义系统提示词、可定义调用场景、可定义Skill、可定义MCP、可定义输出规则(流式、非流式、None))
6. 必须支持工作流，必须支持可自定义流程，支持用户可视化编辑。
7. 必须支持 "Task todos" / "Plan mode"模式，使用"/plan"触发。
8. 支持IDE/Cli多开。
9. 必须支持模型商和模型配置，必须支持OpenAI和Authentic双协议。
10. 必须支持一键导入配置。用户可以在网页上选配后一键应用或通过远程控制说明要求，必须支持一键配置。
11. 保留执行记录，支持回滚操作。


### Agent内核
1. 支持OpenCode/ClaudeCode/AugmentCode/Windsurf等一键切换"内核"。
2. 默认没有内核；在需要时，点击内核下载，才能切换。


### 外部
1. 对外提供MCP。
2. 对外提供Skill。
3. 支持acp远程控制。


### acp远程控制
1. 远程控制通道支持微信、企业微信、QQ、飞书、钉钉等工具，支持专属APP/小程序控制。
2. 通过acp远程控制或者单独入口控制任务进度和需求，支持多Agent开会，支持语音输入输出。
3. 能查看整体方案和当前任务进度条，以及预计完成时间。

### 二、构建时镜像加速：`ARG NEED_MIRROR` 双模式

主 Dockerfile (`AideanWiki/Dockerfile`) 使用 `ARG NEED_MIRROR=0`（**默认关闭**），通过 `--build-arg NEED_MIRROR=1` 开启，控制 5 个维度：

| 维度 | 国内镜像源 | 控制方式 |
|------|-----------|---------|
| apt 源 | `mirrors.aliyun.com/ubuntu` | `sed` 替换 sources.list |
| pip/uv 源 | `mirrors.aliyun.com/pypi` | 写入 `/etc/uv/uv.toml` |
| Git 源 | `gitee.com/infiniflow/resource` | 替换 GitHub URL |
| HuggingFace | `hf-mirror.com` | 硬编码 / 环境变量 |
| npm 源 | `registry.npmmirror.com` | `web/.npmrc` |

Sandbox Dockerfile 则 **默认开启** (`NEED_MIRROR=1`)，使用清华镜像源。

1. **分层解耦**：Docker Registry 代理与构建时镜像源相互独立，可分拆维护

3. **代理清理**：主动清空宿主机的 `HTTP_PROXY`，避免本地代理配置污染容器网络

def require_pro_edition(func):

    @wraps(func)

        from api.apps import current_user

        if edition != "pro":
            return get_json_result(code=RetCode.FORBIDDEN,
                                   message="此功能仅专业版可用")
        if inspect.iscoroutinefunction(func):
            return await func(*args, **kwargs)
