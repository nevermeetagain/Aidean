# Aidean 测试与验收文档（全量重构）

> 文档版本：v1.0  
> 更新日期：2026-05-06

## 1. 测试目标
- 验证三产品核心闭环可用、稳定、可回归。
- 验证 UI/UX 优化后关键任务成功率与可理解性。
- 验证 Docker 部署链路与基础服务可用性。

## 2. 测试范围
- 前端页面：首页、三产品首页、核心任务页、个人中心页。
- 后端接口：核心公开接口、鉴权接口、核心业务接口。
- 部署链路：容器拉起、服务健康、基本连通性。
- 用户测试：关键路径任务完成与反馈收集。

## 3. 测试分层
### 3.1 冒烟测试
- 页面可访问、接口可响应、核心按钮可点击。

### 3.2 功能测试
- Aidean：榜单筛选排序、详情、对比收藏。
- AideanSpace：工具检索、详情、试用扣费链路。
- Sphere：知识库创建、上传、向量化、绑定分身。

### 3.3 回归测试
- 每次迭代必须回归三产品核心闭环。
- 回归失败阻断上线。

### 3.4 用户测试
- 典型用户任务脚本执行。
- 记录任务耗时、失败点、主观满意度。

## 4. 核心验收项
- 首页可在短时间内理解三产品并进入任一产品。
- 三产品核心闭环任务均可执行完毕。
- 余额相关流程提示明确、记录完整、状态正确。
- 关键异常均有可操作反馈（重试、返回、引导）。
- Docker 国内镜像部署可成功拉起并通过健康检查。

## 5. 交付物
- 测试执行记录（时间、环境、结果）。
- 缺陷清单（优先级、复现步骤、修复状态）。
- 用户测试结论（主要问题、建议、已采纳项）。
- 最终验收报告（是否可上线）。

## 6. 上线门禁
- P0 问题为 0。
- P1 问题有明确规避方案并评审通过。
- 文档状态与实现状态一致。
- 运维验证通过且可回滚。
