## ⚠️ 注意事项

### 1. API限流处理
- OpenRouter API可能有请求频率限制
- 实现请求间隔控制（100ms/请求）
- 使用指数退避重试策略

### 2. 数据一致性
- 使用数据库事务保证原子性
- 同步失败时不更新部分数据
- 保留上一次成功的数据

### 3. 性能优化
- 使用批量插入减少数据库操作
- 对查询字段建立索引
- 前端使用分页和虚拟滚动

### 4. 错误处理
- 记录详细的错误日志
- 同步失败时发送告警通知
- 提供手动重试机制

### 5. 安全性
- API Key存储在环境变量
- 管理后台添加身份验证
- 防止SQL注入攻击
