#### 审查Agent 2: Constraint Guardian（约束守护者）

> **🔴 华为味**：力出一孔，压强集中。所有设计必须符合以下约束。

2. **安全约束**：
   - `isVerified` 必须有人工审核流程支撑

   - 敏感操作必须有审计日志

3. **可扩展性约束**：
   - 所有表必须预留JSON扩展字段 `extJson`
   - 预留属性字段 `attr_01` - `attr_05`
   - 多租户支持 `tenantId`（虽然当前单租户，但预留）

4. **国际化约束**：
   - 所有名称类字段必须同时有中文/英文版本
   - 描述字段支持多语言
   - 分类和标签支持国际化枚举

5. **运维约束**：
   - 需要有`syncStatus`同步状态字段（用于数据采集）
   - `syncSource`数据来源（官方/第三方/用户提交）

#### 审查Agent 3: User Advocate（用户代言人）

> **🔶 Amazon味**：Customer Obsession — are you working backwards from the customer?

**用户视角问题**：

1. **MCP用户场景**：
   - 用户想搜索MCP工具，需要`searchKeywords`字段优化搜索
   - 用户想知道是否适合自己的系统，需要`compatibility`兼容性情报

2. **Agent用户场景**：
   - 用户想了解Agent能做什么，需要`demoVideoUrl`演示视频
   - 用户想试用，需要`trialEnabled`试用开关和`trialConfig`试用配置
   - 用户想对比不同Agent，需要`comparisonFields`可对比字段清单

3. **Skills用户场景**：
   - 用户想学技能，需要`learningPath`学习路径（JSON）
   - 用户想知道证书，需要`certificationAvailable`是否有认证
   - 用户想评价，需要`userReviews`关联表 + `ratingBreakdown`评分细项

4. **News用户场景**：
   - 用户想按主题浏览，需要`topic`主题字段（AI绘画/大模型/机器人）
   - 用户想收藏，需要与`favorites`表关联
   - 用户想分享，需要`shareCount`分享统计
   - 用户想评论，需要`comments`关联表
   - 用户想点赞，需要`likeCount`点赞数

**管理员场景需求**：

   - `recommendStartAt`/`recommendEndAt`推荐时段
   - `promotionBadge`推广标签（热门/新品/编辑精选）

3. **数据质量**：
   - `dataQualityScore`数据质量评分
   - `completenessRate`字段完整度百分比
   - `lastVerifiedAt`最后验证时间
   - `nextVerifyAt`下次验证时间

   - `crawlerId`采集器ID

   - `lastCrawlAt`最后采集时间
